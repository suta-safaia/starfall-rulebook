# 游荡者

守夜的士兵打了个哈欠。就这一次。

阴影从墙头滑落，落地无声。巡逻队刚走过拐角，火把的光还留在走廊尽头，他已经贴在了目标身后。守卫至死没有发出声音——匕首从肋骨的缝隙间精确地送入心脏，他甚至没来得及低头看一眼伤口。尸体被轻轻放回阴影里，像放下一件行李。等换岗的人发觉不对时，走廊尽头的窗户正随风轻晃，而那人早已消失在夜色深处，仿佛从未存在过。

游荡者是隐匿与灵活的大师。他们不穿重甲，不与敌人正面角力——对他们而言，最好的战斗是敌人根本来不及还手的战斗。游荡者像战场上的一股风：身形灵巧，总能从刀光剑影的缝隙中穿过，连爆裂的法术都能片叶不沾身地躲开。他们出手不多，但每一击都直指要害——当敌人露出破绽、或首尾难顾之时，游荡者的利刃会精准地找到心脏、咽喉与肌腱，一击毙命。他们同样精通机关与陷阱的拆解，脚步快过追兵，连惑控心智的魔法都很难长久束缚他们。

战场上最危险的敌人，往往是你根本没有看见的那一个。

生命值：每等级15点

**偷袭：** 只要对方失去了AC上的敏捷加值（无论目标是否有敏捷加值），或者当目标身边5尺内有未失能的敌方生物时，且游荡者使用的是灵巧武器或者远程武器时，可以造成和武器同类型的额外1d6伤害，伤害会随着游荡者等级提升而提升，该能力一回合只能使用一次。

**反射闪避：** 你可以灵敏地躲避特定的危险。当你受到一个允许你进行敏捷豁免来只承受一半伤害的效应影响时，你在豁免成功时不受伤害，豁免失败时只承受一半伤害。你无法在失能状态下使用此特性。

**乘势攻击：** 一回合一次，当你使用武器攻击对一个敌人造成伤害时，你可以选择将进行一次借机攻击使用相同的武器再次攻击该名敌人，且本次攻击附加偷袭效果。

**心智灵活：** 此能力可以让游荡者从那些控制或强迫他的魔法效果中挣脱出来。如果有此能力的游荡者受到惑控系法术或效果影响并在豁免检定中失败，其可以立即重新尝试豁免检定。该能力在使用后需要进行短休后才能再次使用。
