# 神官

晨光神殿的祭司跪在伤者榻前祷告，求神赐她治愈之手；铁与火神殿的祭司在兵器架前祷告，求神赐他破敌之力；墓园神殿的祭司在亡者之间祷告，求神赐她统御亡灵的权柄。他们诵读的祷词不同，跪拜的神像不同，祈祷之后要走的路也不同——但烛火燃起时眼底的那份虔诚，一模一样。日出时分，他们各自起身，走出殿门，去践行各自理解的神的旨意。

神官是虔诚的信徒与神术施法者，以传播神的旨意为毕生使命。无论侍奉哪位神明，神官都拥有同样的根基：真挚的信仰、施行神术的权柄，以及引导神圣能量的天赋——这股能量可以治愈伤痛，也可以化作伤害敌人的怒焰；可以为盟友施加祝福与庇护，也可以给敌人降下诅咒与枷锁。而神官最具特色之处在于：践行神的旨意并无定式。神指明方向，走哪条路由神官自己的意愿决定——你可以披上重甲带着加护冲锋陷阵，也可以稳居后排做队伍的支柱；可以斥责亡者令其溃散，也可以操控亡者为你而战，甚至将这些道路融合为一。同一位神的一千个信徒，可以走出一千条不同的路。

信仰是共同的起点，路是自己选的。

生命值：每等级18点

**领域选择：** 一位神官一般都会追随一位神明，但不追随特定的神明或者追随多个神明的情况也并不罕见。但每一个神官都有自己更加倾向的领域，并从中获得力量。神和领域具体见[神和领域](../../神和领域.md)。

在选择领域的同时，你也将选择自己身上所有的灵光，是代表温暖或包容的治愈灵光，还是代表邪恶或秩序的惩戒灵光，在选择后不可轻易更改。这决定了你的自发施法与对亡灵的干预效果。

**领域法术：** 每个领域在你拥有对应法术环阶时，会给予你一个领域法术，领域法术不需要记忆也无法记忆，每次长休前你可以免费释放你不同的领域法术各一次。

**施法（神官）：** 神官是与法师一样的记忆施法者，见法师的施法规则。神官初始获得所有记载在神术表的法术。

**自发施法：** 神官可以放弃自己一个准备好的法术，转而释放同级后者更低等级的自发法术。

如果是治愈灵光，自发法术则是带有**治疗**（例如治疗轻伤）字段的神术，如果是惩戒灵光，自发法术则是带有**造成**（例如造成轻伤）字段的神术。

**引导神力：** 根据你选择领域的不同，你拥有独特的神力馈赠的力量，在释放该力量后，你必须完成一次长休才能再次使用。

**神圣干预：** 在你迫切神明的帮助的时候，你可以以一个整轮动作祈祷某位神明的帮助，投掷1d100，若投掷的值小于你的神官等级x3，神明将回应你的祈祷。无论无何，在一次长休前你只能使用一次该能力。

通常来说，神圣干预类似于法师的祈愿术，但是除了一些恶趣味的神明，你的祈祷通常不会因为描述不够精确而被曲解。

若你的请求只是释放一个时长不超过1分钟并且环阶不超过你最大环阶的法术时或一些很小的请求时（由DM裁定），你的请求将会自动通过。

否则，作为神力干预的代价，在30日内，你无法再次使用神圣干预能力，当然神明也可以直接拒绝你的请求。

**强效神圣干预：** 你进行神圣干预时，投掷1d100，若投掷的值小于你的神官等级x5，即可回应你的祈祷。
