# 四环艺术

# 灭世高音

*四环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 120尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

你拔出一个超越人耳极限的高音，声波凝成一线，贯穿目标的躯体。对120尺内一个目标造成 1d10 / 每吟游诗人等级（最高12d10）点音波伤害，目标进行强韧豁免，成功则伤害减半。此伤害无视音波抗性与音波免疫——共振的是目标的骨骼与脏器，而非空气，因此对聋者同样有效。

# 崩城咏叹

*四环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 60尺（30尺半径）

**演艺成分：** 歌唱、乐器

**持续时间：** 立即

**法术抗力：** 可

你唱出一段低沉而恢弘的咏叹调，声波如巨锤般砸向大地。以60尺内一点为中心、30尺半径范围内的所有生物受到 1d6 / 每吟游诗人等级（最高12d6）点音波伤害，反射豁免成功则伤害减半。此艺术对建筑、工事与非魔法物件造成双倍伤害。

**演艺成分：** 歌唱

**持续时间：** 立即

你的歌声在某个频率上颤动不休，目标体表的水分与尘屑随之共振，凝结成晶。60尺内一个目标受到 1d10 / 每吟游诗人等级（最高12d10）点音波伤害，强韧豁免成功则伤害减半。豁免失败的目标体表结晶，被束缚1轮：无法移动，直至其下个回合结束时结晶碎裂。

# 战吼变奏

*四环 变奏曲*

**演艺时间：** 2 AP

**演艺距离：** 自身（30尺半径）

**演艺成分：** 歌唱

**持续时间：** 专注、1分钟

**法术抗力：** 无

你在当前演艺之上叠入一段嘹亮的战吼变调，每一次兵刃起落都与节拍相合。维持期间，30尺内所有盟友的武器攻击命中时，额外造成2d6点音波伤害。此变奏曲不中断当前演艺，效果持续到你主动停止、失去专注为止（最长1分钟）。

# 无声之死

*四环 谢幕曲*

**演艺时间：** 2 AP

**演艺距离：** 60尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

只有当你正在维持演艺时才能使用。你中断当前的演艺，将旋律推向高潮后骤然收束——歌声止息的一瞬，死亡的寂静降临。对60尺内一个目标造成 1d10 / 每吟游诗人等级（最高12d10）点音波伤害，意志豁免成功则伤害减半。随后以该目标为中心、20尺半径的区域陷入绝对的沉默，持续1轮：区域内无法发出任何声音，需要语言成分的能力无法使用。被中断的演艺立即结束。

**演艺成分：** 歌唱、乐器

**法术抗力：** 可

# 万物共鸣

*四环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 触及

**演艺成分：** 歌唱

**持续时间：** 1分钟

**法术抗力：** 无

你的歌声唤醒万物沉睡的记忆，让沉默者开口。你触碰的一件物件、一具尸体或一块石头获得短暂的言语能力，如实回答你提出的三个关于它所见证之事的问题。它的认知仅限于自身亲历的见闻，答毕复归沉寂。
