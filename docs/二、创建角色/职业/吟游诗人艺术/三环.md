# 三环艺术

# 雷霆副歌

*三环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 60尺（20尺半径）

**演艺成分：** 歌唱、乐器

**持续时间：** 立即

**法术抗力：** 可

你唱出炸裂般的副歌，声浪如惊雷在指定点轰然炸开。60尺内一点周围20尺半径范围内的所有生物受到 `1d6 / 每吟游诗人等级（最高10d6）` 点音波伤害，反射豁免成功伤害减半。豁免失败的生物耳聋1分钟。

**演艺成分：** 歌唱

**演艺成分：** 歌唱、乐器

**法术抗力：** 可

你以缓慢沉重的节拍吟唱，让整片区域的时间与动作都变得迟滞。指定60尺内一点，其周围20尺半径内的敌人在区域内受到逐级增强的迟滞效果：第1级（开始演绎后）区域内敌人移动速度减半；第2级（完整维持1轮后）区域内敌人在其回合开始时额外少获得1AP；第3级（完整维持2轮后）区域内敌人无法主动离开该区域。此艺术上限3级。敌人离开区域后，其身上来自此艺术的效果立即解除。

**演艺时间：** 2 AP

**演艺距离：** 自身（30尺半径）

**演艺成分：** 歌唱、乐器

**法术抗力：** 无

你与至少2名盟友共同演绎这首恢弘的战地交响曲（最低参与人数3人，含本人），所有参与者维持专注。持续期间，你周围30尺半径内的所有盟友攻击检定+2、AC+2，且在每个自己回合开始时获得等同你魅力调整值的临时生命（不与同源临时生命叠加，取高者）。保持专注的参与人数低于3人时，此协作曲立即结束。

# 唤雨长调

*三环 基础艺术*

**演艺时间：** 10分钟

**演艺距离：** 自身（半里半径）

**演艺成分：** 歌唱

**持续时间：** 1小时

**法术抗力：** 无

你以绵长高远的调子向天空歌唱，云层应和。完成10分钟的吟唱后，你在方圆半里内唤来或驱散一场小雨或薄雾（由你选择），效果持续1小时。此艺术无法改变极端天气，只能在正常气候下产生影响。

# 回声地图

**演艺时间：** 2 AP

**演艺距离：** 自身（200尺半径）

**演艺成分：** 歌唱

**持续时间：** 10分钟

**法术抗力：** 无

你低声吟唱，让回声为你探路。方圆200尺内的地形、通道与大型物体（如门、立柱、石棺等）以心智地图的形式呈现于你脑中，此感知可穿透墙壁与障碍物。10分钟内你可以随时在脑海中查阅这张地图。此艺术无法探测生物、陷阱与隐形物体。

**演艺成分：** 歌唱、乐器
