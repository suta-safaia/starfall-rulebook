# 六环艺术

# 星殒高歌

*六环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 120尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

你仰头高歌，歌声化作一颗燃烧的流星划破长空，轰然砸向敌阵。选择120尺内一点，以该点为中心40尺半径范围内的所有生物受到 `1d6 / 每吟游诗人等级（最高16d6）` 点音波伤害，反射豁免成功伤害减半。豁免失败的生物应声倒地。具有飞行速度的生物豁免失败时额外被音浪击落：若其正在飞行，则坠向地面（正常承受坠落伤害），落地后倒地。

# 湮灭咏叹调

*六环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 60尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

你唱出一个不该存在于世上的音符。选择60尺内一名你可见的生物，其受到 `1d10 / 每吟游诗人等级（最高16d10）` 点音波伤害，强韧豁免成功伤害减半。若此伤害将目标的生命值降至0，其身躯被音波彻底湮灭，连灰烬也不曾留下：该生物无法被常规复活手段（如复活术、死者复活）唤回，只有完全复活术或同等强度的奇迹才能使其归来。

# 万物终章

*六环 谢幕曲*

**演艺时间：** 2 AP

**演艺距离：** 自身（60尺半径）

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

只有当你正在维持演艺时才能使用。你将整支乐曲在一瞬间推向终结的强音，音墙以你为中心轰然炸开。你周围60尺半径内的所有敌人受到 `1d6 / 每吟游诗人等级（最高16d6）` 点音波伤害，反射豁免成功伤害减半；豁免失败的敌人震慑1轮、倒地，并被击退30尺。你的盟友不受此艺术伤害。曲终之后，你声嘶力竭：你的下个回合可使用的AP减少2点。

# 世界挽歌

*六环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 60尺

**演艺成分：** 歌唱

**持续时间：** 专注、1分钟

**法术抗力：** 可

你为这个世界唱起送葬的挽歌，听闻者无不心生绝望。选择60尺内一点，以该点为中心40尺半径范围内的所有敌人须进行意志豁免。豁免失败的敌人在此艺术持续期间，攻击检定、AC与全部豁免检定承受-4减值，且在其每轮开始时受到2d6点音波伤害。

# 寂静神谕

*六环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 60尺

**演艺成分：** 歌唱

**持续时间：** 专注、直到你主动停止

**法术抗力：** 可

你的歌声攀至极高处戛然而止，将一名敌人连同它的魔力一起锁进绝对的静默。选择60尺内一名你可见的生物，其须进行意志豁免。豁免失败的目标陷入绝对静默：它无法施放任何法术（包括无需声音成分的法术——静默隔绝了魔力共鸣），也无法使用类法术能力、艺术或类法术道具。此效果持续到你主动停止或失去专注。目标在其每轮结束时可以劣势重新进行意志豁免，豁免成功则此艺术结束。

# 命运纺织曲

*六环 变奏曲*

**演艺时间：** 2 AP

**演艺距离：** 60尺

**演艺成分：** 歌唱

**持续时间：** 专注、直到你主动停止

**法术抗力：** 无

你在主旋律之上织入一段隐秘的复调，轻轻拨动命运的丝线。此艺术不中断你当前的演艺，其效果与你当前的演艺并存。维持此变奏曲期间，60尺内的所有盟友免疫重击（对其造成的重击按普通命中计算），且每名盟友在其每轮中可以重骰一次豁免检定，并采用较好的结果。

# 不朽交响诗

*六环 协作曲*

**演艺时间：** 2 AP

**演艺距离：** 60尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 无

最低参与人数：3（含你本人）。你与盟友们的歌声汇成不朽的交响，在最高潮的一个和弦中，奇迹降临。60尺内的所有盟友恢复全部生命值，移除其身上的全部负面状态与属性流失；其中已死亡不超过1分钟的盟友被歌声唤回，以生命值上限一半的生命值复活。演绎完成后此艺术立即结束。

# 传奇史诗

*六环 进行曲*

**演艺时间：** 2 AP

**演艺距离：** 60尺

**演艺成分：** 歌唱

**持续时间：** 专注、直到你主动停止

**法术抗力：** 无

你唱起英雄们的史诗，而随着诗篇一章章展开，你的盟友也一步步成为诗中人。你开始此演艺时，60尺内的所有盟友的攻击检定、AC、豁免检定与伤害掷骰获得+2加值；此后每完整维持1轮，该加值再+1，最高至+6。当此演艺完整维持满5轮时，盟友额外免疫恐惧与魅惑，直至演艺结束。中断后再次使用，加值从+2重新计算。

# 位面歌谣

*六环 基础艺术*

**演艺时间：** 10分钟

**演艺距离：** 自身

**演艺成分：** 歌唱、乐器

**持续时间：** 立即

**法术抗力：** 无

你吟唱一首古老的歌谣，歌声在每一个位面之间回响，为你找到回家的和声。持续吟唱10分钟后，你面前打开一道位面之门，将你与至多8名自愿的盟友送往你熟知的一个位面，或该位面中你熟知的指定地点。位面之门在你与同行者穿过后立即关闭。

# 神迹清唱

*六环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 见正文

**演艺成分：** 歌唱

**持续时间：** 见正文

**法术抗力：** 依所复制的效果而定

你不借助任何外物，只以一段空灵的清唱向世界的旋律祈愿。此艺术复制任意一个不超过5环的法术或艺术的效果，无需材料成分；其演艺距离、持续时间、豁免与法术抗力等参数与被复制的效果相同（若被复制效果的演艺时间长于2 AP，则采用较长者）。或者，你也可以祈求一个与上述效果强度相当的奇迹，由GM裁决其具体效果。
