# 元素秘术表

元素师通过元素修炼里程碑获得的特殊法术。所有秘术每天可免费施展一次，不消耗法术位、不需要准备，即使当前可用环阶不足也可施展。秘术豁免DC与攻击检定按元素师正常施法规则（感知主属性）。

伤害/治疗数值遵循《法术伤害基础模型》：单体 1d10/施法者等级、多目标 1d6/施法者等级、治疗单体 1d8/级、多目标 1d6/级，并按环阶封顶（2环=8级、3环=10级、4环=12级、6环=16级，7环及以上不封顶）。
