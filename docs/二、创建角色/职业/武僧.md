# 武僧

佣兵们的刀剑劈在那件灰色僧袍上，却像劈进了一团风里。他侧身、低头、让过一柄战斧，顺手在斧背上轻轻一按——持斧的壮汉便失去了平衡。第二人的长剑刺到一半，手腕已被两根手指扣住，随即一记肘击落在肋下，剑"当啷"落地。最后一人转身要逃，却发现不知何时那人已经站在了他身后的门框里，掸了掸僧袍上的灰。"出家人不动刀兵，"他说，"但路，你们今天走不过去。"

武僧是透过严苛修行锤炼身心的徒手格斗家。他们不依赖武器与甲胄——身体就是武器，气息就是护甲。经年累月的修行让武僧的徒手击打威力不输白刃，出手的速度甚至快过持剑的战士；他们能以体内的"气"施展不可思议的技巧：徒手震慑敌人、飞檐走壁、百病不侵。武僧的修行之路也是自我超越之路：随着功力渐深，他们的拳锋能破开魔法与精金的防御，身躯能抵御毒素与法术，直至超凡入圣，超越凡人的境界。

血肉为刃，气随意动。

**阵营限制：** 只有守序阵营的角色才能成为武僧。

生命值：每等级18点

武僧武器训练：你为以下武器选择 专攻武器专长或者专精武器专长
* 徒手攻击

**武僧戒律：** 武僧的许多能力要求身体能够自由活动。穿戴任何盔甲、持用盾牌、或处于中度/重度负重时，武僧失去AC加值与速度加值，也无法使用疾风连击。

**AC加值（Ex）：** 未着甲且未持盾时，武僧可以将感知调整值作为洞察加值加到AC上，5级起再获得表中的额外AC加值。即使面对接触攻击或措手不及时，该加值仍然有效；但动弹不得或陷入无助状态时失去。

**徒手击打（Ex）：** 武僧的徒手攻击视同武器攻击，可以使用敏捷调整值代替力量调整值进行攻击与伤害检定（如同灵巧武器）。武僧徒手作战时拳打、肘击、膝顶、脚踢互相组合，即使双手持物也可进行徒手攻击；徒手攻击没有主副手之分。武僧可以选择以徒手攻击造成非致死伤害，且攻击检定不受减值。武僧的徒手攻击同时视为人造武器与天生武器（用于法术强化等判定）。徒手伤害见表。

**疾风连击（Ex）：** 未着甲时，武僧在自己的回合进行武器攻击时，可以额外花费1AP发动疾风连击：本回合你获得一次额外的武器攻击（必须以徒手或武僧武器发动）。

**奖励专长：** 武僧在1、2、6级时各获得一个奖励专长，从对应的两项中选择其一，选择时无需满足专长的前置条件。

**反射闪避（Ex）：** 2级起，当你受到一个允许你进行敏捷豁免来只承受一半伤害的效应影响时，你在豁免成功时不受伤害。你无法在失能状态下使用此特性。

**心如止水（Ex）：** 3级起，武僧对惑控系法术与效果的豁免检定获得+2加值。

**斗气击（Su）：** 4级起，武僧的徒手攻击在击破伤害减免时视为魔法武器；10级起还视为精金武器。

**轻身坠（Ex）：** 4级起，武僧坠落伤害时高度减去表中的数值；20级时武僧可以从任何高度坠落而完全不受伤害。

**百病不侵（Ex）：** 5级起，武僧免疫所有非魔法疾病。

**混元体（Su）：** 7级起，武僧可以导引气息自我疗伤：每天可以恢复的生命值总额等于武僧等级×5，可以分多次使用。

**精通反射闪避（Ex）：** 9级起，反射闪避提升：此类效应中，武僧豁免成功时不受伤害，豁免失败时也只承受一半伤害。

**金刚体（Su）：** 11级起，武僧免疫所有毒素。

**高等疾风连击（Ex）：** 11级起，武僧发动疾风连击时可以额外花费2AP，变为2次额外攻击。

**遁术（Su）：** 12级起，武僧可以在两点之间瞬间移动，如同法术*任意门*，每天一次。施法者等级等同于武僧等级的一半。

**金刚魂（Ex）：** 13级起，武僧获得法术抗力，数值等于武僧等级+10。

**渗透劲（Su）：** 15级起，武僧可以在敌人体内种下致命的震动。每完成一次长休前只能使用一次，必须于攻击检定前宣告。渗透劲对构装生物、泥形生物、植物、不死生物、虚体生物和免疫重击的生物无效。若该次徒手攻击命中并造成伤害，渗透劲植入成功：此后等同于武僧等级的天数内，武僧可以一个即时动作令目标进行体质豁免（DC=10+武僧等级的一半+感知调整值），失败则立即死亡；若豁免成功，此次渗透劲失效。

**不老身躯（Ex）：** 17级起，武僧不会因年老承受属性减值，也不会被魔法老化（已有的减值保留，寿限不变）。

**天语通（Ex）：** 17级起，武僧可以与任何生物交谈。

**空灵体（Su）：** 19级起，武僧每天可以化为灵体状态，效果如同法术*同游灵界*，每天可维持的总轮数等于武僧等级，可分多次使用。

**超凡入圣（Su）：** 20级时，武僧的修行臻于完美，成为魔法生物：在法术与魔法效果的判定上视为异界生物而非凡俗种族（例如*魅惑人类*对其无效），并获得伤害减免10/魔法。武僧仍然可以被正常复活。
