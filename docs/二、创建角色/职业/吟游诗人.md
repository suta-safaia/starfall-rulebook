# 吟游诗人

战况最烈的时候，琴声忽然插了进来。没有一个人回头——所有人都知道那是谁。前排的佣兵们只觉一股热流顺着脊背涌上手臂，方才还沉重如铅的刀剑忽然轻了三分；而敌军的阵脚却乱了，那旋律像一只手，把他们的战意一根一根抽走。曲至中段，调子陡然一转，金铁之音炸开，冲锋的号角里混进了不属于人间的轰鸣。没人说得清吟游诗人是什么时候站到那块岩石上的，就像没人说得清，这场仗是从哪一个小节开始赢的。

吟游诗人是以艺术撬动超凡力量的类施法者。他们不钻研符文，不祈求神恩——他们的魔力沉淀在音乐、诗歌、舞蹈与戏剧之中，每一种艺术都是千锤百炼的绝技，一经施展，便能产生不逊于法术的真实效果。艺术是吟游诗人的全部家当：他们会的曲目有限，每一种在短休前也只能演绎一次，如何分配演出的顺序，就是吟游诗人最深的学问。而演出方式更是因人而异：有人怀抱鲁特琴立于阵后，让歌声越过战友的头顶笼罩战场；也有人一手按弦一手执剑，踏着节拍径直跳进敌群，把战歌唱在刀锋之上。

舞台上的每一秒都是设计好的，一曲终了，胜负已分。

**演艺（吟游诗人）：** 吟游诗人是类施法者，通过音乐、诗歌、舞蹈、戏剧等艺术形式释放类似法术的效果，这些技艺统称为**艺术**。艺术的主属性为魅力：

- 艺术豁免DC = 8 + 熟练加值 + 魅力调整值
- 艺术攻击检定 = d20 + 熟练加值 + 魅力调整值
- 艺术效果视为类法术能力，其环阶用于解除魔法、反制法术等判定。

**已知艺术：** 吟游诗人1级时知晓2个艺术，之后每提升一级多知晓1个（见表），可学习的艺术最高环阶见表。具体艺术内容见吟游诗人艺术表（待补充）。

**演出限制：** 每一种艺术在完成一次短休前只能使用一次。吟游诗人的力量来自反复打磨的绝技而非法术位，因此规划演出顺序是吟游诗人的核心课题。

**演艺：** 开始一项演艺需要2AP（除非艺术另有说明）。演艺的持续时间由艺术条目标注：

- **持续型演艺**需要专注维持，规则同维持法术专注，其效果持续到你主动停止、失去专注、或完成一次短休为止。你同一时间只能维持一项持续型演艺（变奏曲例外，见后）。
- **瞬时演艺**只产生即时效果，一经施展立即生效，无需维持，也不占用你的演艺位。

**切换艺术：** 在自己的回合，你可以花费2AP生硬地中断当前演艺（被中断的演艺立即结束），之后再正常开始一项新的演艺。

**艺术的类型：** 每一种艺术都属于以下类型之一，具体类型在艺术条目中标注。

- **基础艺术：** 艺术的主体，既包括持续提供增益的演艺，也包括瞬时生效的技艺。
- **谢幕曲：** 只有当你正在维持演艺时才能使用：中断当前的演艺，将其推向高潮，释放出比普通艺术更强的效果。谢幕曲一经使用，被中断的演艺立即结束。
- **变奏曲：** 使用变奏曲不需要中断当前的演艺：在变奏曲结束前，变奏曲的效果与你当前演艺的效果同时存在；且在此期间你切换其它演艺无需先中断当前演艺——不消耗切换的AP，也不会导致变奏曲结束。维持变奏曲期间，你只需为变奏曲进行专注，当前演艺的专注由变奏曲一并承载；变奏曲结束时，若你仍在演艺，则恢复为正常维持专注。
- **协作曲：** 需要你与至少1名盟友共同参与演绎（每项协作曲会标明最低参与人数，含你本人，至少为2）。你和所有参与盟友都需要维持专注。任何时刻，保持专注的参与人数低于该协作曲的最低人数要求时，协作曲立即结束。
- **进行曲：** 其效果会随着维持时间不断增强：演艺每完整维持1轮，效果便按艺术说明提升一级，直到该艺术标注的上限为止。进行曲中断后再次使用，效果从最初级重新计算。

**风格选择：** 1级时，吟游诗人从以下两种演出风格中选择一种，一经选择不可更改。

- **战歌风格：** 你喜好跳进敌群，在刀光剑影中弹唱。你的基础攻击加值提升为半BAB（见表中"战歌"列）。
- **咏叹风格：** 你喜好稳居后方，让歌声鼓舞全场。你获得**诗人激励**：当你开始一项演艺时，你可以选择60尺内一名你可见的生物，使其获得一枚1d4激励骰，持续1分钟。该生物可以在一次攻击检定、属性检定或豁免检定中投出这枚激励骰并将结果加在检定上。诗人激励不可叠加，一个生物同一时间只能持有一枚激励骰。

**增强风格：** 5级时，你的演出风格得到强化。

- **战歌风格：** 当你开始一项演艺时，直到你的下个回合开始，你的武器攻击附加等同于你魅力调整值的伤害。
- **咏叹风格：** 开始一项演艺只需1AP，而非2AP。

**精通风格：** 10级时，你的演出风格臻于化境。

- **战歌风格：** 维持演艺期间，你每回合第一次以武器攻击命中敌人时，恢复1点AP。
- **咏叹风格：** 切换艺术只需1AP，而非2AP。

**见多识广：** 吟游诗人在所有知识技能检定上获得等同于其吟游诗人等级一半的加值（最少+1）。

**余音绕梁：** 当你使用谢幕曲中断一项演艺时，被中断演艺的效果会额外持续1轮后才结束。

**安可：** 完成一次短休前，你可以重新演绎一个本次短休前已经使用过的艺术（该艺术额外获得一次使用机会）。你只能使用这个能力一次，直到你完成了一次短休。
