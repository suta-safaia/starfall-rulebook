# 混沌学者

实验记录第七十三页："受试者今日施展了一个照明术。照明很成功。同时，实验室天花板上出现了一窝发光的乌鸦，三只烧瓶变成了青蛙，受试者的头发至今仍是亮蓝色的。结论：受试者状态良好。"记录员的批注停在三天前——那天以后，没有人能打开实验室的门，因为门变成了一只友善的石蜥蜴。

混沌学者是主动拥抱失控魔力的施法者。寻常施法者穷尽一生驯服魔力，他们却反其道而行：松开缰绳，任由魔力的野马狂奔，再从混乱的轨迹中窃取力量。他们不是不懂秩序，只是发现了一个秘密——魔法的本质从来就不是秩序。当旁人视失控为事故时，他们视之为馈赠。

你无法驾驭风暴。但你可以成为风暴眼。

先决条件：能够施展3环法术。

每等级12点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+0（0）|施法精进，魔潮涌动|
|2|+1（1）|施法精进，混乱之潮|
|3|+0（1）|施法精进，驾驭混乱|
|4|+1（2）|施法精进，属性值提升，魔潮主宰|
|5|+0（2）|施法精进，混沌赐福|

**施法精进：** 每当你获得一个混沌学者等级，指定一个你拥有的施法者职业：你的法术位、已知法术（或法术书可准备的法术）与施法者等级如同在该职业上额外提升了1级，但你不会获得该职业的其他职业能力。

**魔潮涌动（Su）：** 你体内的魔力不再安分。每当你消耗环阶不低于2环的法术位来施展法术时，掷一次d20：若结果为1-2，你本次法术的施法者等级-2，并且引发一次魔法浪涌（见魔法浪涌表）；若结果为19-20，你本次法术的施法者等级+2，并且引发一次魔法浪涌。

**混乱之潮（Ex）：** 当你进行攻击检定、豁免检定或属性检定时，你可以消耗一点混乱之潮重新投掷该检定；你必须接受新的结果，除非再消耗一点混乱之潮继续重投。你的混乱之潮点数上限等同于你的混沌学者等级；每当你触发魔潮涌动时，你回复一点混乱之潮。混乱之潮没有其他恢复手段——想再赌一次，就得先纵身跃入洪流。

**驾驭混乱（Su）：** 每短休一次，当你消耗环阶不低于2环的法术位施展法术时，你可以主动引发一次魔法浪涌——不掷d20，本次法术的施法者等级也不因此改变。

**魔潮主宰（Su）：** 当你引发魔法浪涌时，你可以掷两次魔法浪涌表，自选其中一个结果生效。

**混沌赐福（Su）：** 你在为法术进行伤害掷骰时，如果其中的任何一粒骰子掷出最大值，则选择这些骰子之一再骰一次，这些新骰子不会再触发新的混沌赐福。
