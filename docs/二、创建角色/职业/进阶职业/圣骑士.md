# 圣骑士

城门被撞开的时候，守军已经退到了第二条街。圣骑士没有退。她把剑拄在地上，开始念诵誓词，声音不大，溃逃的士兵却一个个停下脚步，转过身，在她身后重新列队。那头撞碎城门的巨魔扑上来时，她拔剑相迎，一剑劈开它半边头颅——剑刃上的圣光烧进伤口，让它无法再长合。天亮时城门还是破的，但门前多了一圈不敢靠近的敌人。

圣骑士是以誓言为力量源泉的神卫。誓言约束他们的言行，也赐他们力量：掌心的圣疗能愈合伤患，破邪的斩击令邪恶之物胆寒，周身的灵光庇护每一个站在他们身边的人。他们还与天界立下契约——圣灵寄于剑刃，或化为忠诚的坐骑。这份力量来自信念而非神赐的施舍，因此也容不得玷污：背弃誓言者，圣光弃之。

誓言有多重，剑就有多重。



先决条件：善良阵营，基本攻击加值+3，拥有神术施法者等级

**誓言（Ex）：** 当你选择成为一名圣骑士时，你决心投入于对抗邪恶与维持公义的事业之中，为此你必须先规范自己的行为，你立下神圣的誓言将与你的圣骑士身份同在，在你成为一名圣武士之后，你的身上将散发出治愈灵光。

**背弃誓言：** 圣骑士的道路过于艰难，圣骑士一生都在追求自己理想化的誓言，但难免会因情绪化翻错亦或是陷入两难的境界不得不打破誓言，通常在圣骑士做出违反自己誓言的行为后，都会在教堂或者同僚的协助下忏悔。若圣骑士自愿放弃了誓言且不愿意忏悔，根据情况，可能是圣骑士修正了自己的看法选择立下了其他誓言，也可能是圣骑士变成灰心哥后不再相信自己信念，后者这种严重的情况会导致其圣武士的力量，或者成为一名破誓者。

**圣疗（Su）：** 圣骑士的治愈灵光给予了他治疗他人的能力，圣骑士花费1行动点进行一次成功的接触攻击后（不会引发借机攻击），圣骑士可以治疗其1d6/每圣骑士等级，圣骑士在长休前能使用该能力的次数等于其魅力调整值。

**破邪斩（Ex）：** 圣骑士可以呼唤善良的力量来帮助她与邪恶作战。圣骑士花费2行动点指定视野内的一个目标。如果该生物为邪恶，在圣骑士对其发动攻击时，圣骑士的攻击检定获得等同于其魅力调整值的士气加值，并且圣骑士在每回合的第一次对破邪斩的的目标造成伤害时，目标受到等同于圣骑士等级的真实伤害。当破邪斩的目标对圣骑士发起攻击检定时，其受到等同于圣骑士魅力调整值的士气减值。如果目标为非邪恶生物，能力次数会消耗掉且不产生任何效果。

该效果一直持续到圣骑士进行短休或者长休或者圣骑士再次释放该能力。

圣骑士在长休前能使用的破邪斩次数等同于**1+圣骑士等级的三分之一。**

**灵光（Su）：** 圣骑士身上的治愈灵光被进一步加强，给予圣骑士和身边10尺内的盟友加成，圣骑士的誓言将会决定灵光的具体效果（自选一个效果，选择后无法改变），灵光只有在圣骑士未处于失能状态时有效。

- 勇气灵光：圣骑士免疫恐惧和魅惑状态，圣骑士和灵光范围内的盟友在感知豁免，魅力豁免上获得等同于圣骑士魅力调整值的士气加值。
- 哨卫灵光：圣骑士不会因为被突袭陷入措手不及状态，圣骑士和灵光范围内的盟友在进行先攻检定时获得等同于圣骑士魅力调整值的士气加值。
- 守护灵光：圣骑士的AC获得+2士气加值，当敌人对你灵光范围的盟友进行一次攻击检定时，你能使用一个反应动作将这次攻击引导向你，且攻击检定数值不变。
- 迅捷灵光：圣骑士的移动速度增加20尺，圣骑士和在圣骑士灵光范围内开始回合的盟友获得额外1行动点。
- 征服灵光：圣骑士的武器攻击附加1d6点光耀伤害，每个在圣骑士灵光中开始回合的敌对生物受到等同于圣骑士魅力调整值的光耀伤害。
- 恐惧灵光：每个第一次进入圣骑士灵光范围内的敌对生物必须通过一次DC=10+圣武士魅力调整值的魅力豁免，否则陷入恐惧状态1分钟，目标在24h内不会重复受到该灵光的影响。

**神圣契约（Sp）：** 圣骑士践行誓言使得他获得了来自天界圣灵的青睐，圣武士可以选择以下一种契约，一旦选择就无法更改。

圣洁武器：圣骑士高举他的武器，花费4点行动点让圣灵附着在自己的武器之上，援助时间持续10分钟。当圣灵附着在自己的武器上时且为圣骑士使用时，武器将会发出30尺半径且无法被魔法黑暗压制的圣光，圣武士的武器临时获得以下一个可选附魔：公正、光能、护身、瓦解、炽焰、焰爆、神圣、锐锋、慈悲和追击，圣武士在长休前可以使用2次本能力。

天界坐骑：圣武士可以花费4行动点随时召唤与他签订契约的忠诚坐骑，并且决定是否直接变为骑乘状态。坐骑为天界模板，且获得额外加成（规则在另一台电脑上）。若坐骑死亡，圣灵将回归天界且在你完成一次长休前无法被再次召唤。

**神恩（Ex）：** 圣武士不再受到非魔法疾病的影响，也不会受到腐化的影响

**灵光范围扩大（Su）：** 灵光的范围从10尺变为30尺

**圣愈恩典：** 在你使用圣疗能力时，你每花费2行动点都可以额外使用一次以下一个效果

- 净化（Sp）：移除一个耳聋、目盲、困倦、目眩或石化效果

- 移除疾病（Sp）：如同释放一次移除疾病法术，将圣武士等级作为施法者等级
- 移除诅咒（Sp）：如同释放一次移除诅咒法术，将圣武士等级作为施法者等级
- 坚毅（Su）：受治疗者获得等同于圣武士等级的临时生命值

**群体破邪斩（Ex）：** 每个在你灵光范围内的盟友都获得破邪斩的增益效果
