# 回音战士

古战场的尽头，幸存的士兵抱着断剑跪坐在尸堆之间。他本该死在第七次冲锋里——他清楚记得长矛刺入胸口的冰冷。但某个瞬间，时间在他面前分了岔：死去的那个他倒下了，而另一个他站到了现在。自那天起，他不再是孤身一人。每当战端再起，那个灰蒙蒙的、来自另一条时间线的自己便会持剑而立，与他并肩作战——那个未曾幸存的他，剑术与他一模一样。

回音战士是触摸到时间裂痕的武者。他们的力量不来自神明、魔法或血脉，而来自一个朴素的疑问：如果当初走上另一条路的那个自己，如今身在何处？答案是：从未离开。回音战士召唤的回音不是幻象、不是傀儡，而是"另一种可能"的实体化——它拥有战士的全部武艺，承担战士未能承受的伤害，去往战士分身乏术的位置。与回音并肩作战，就是与自己全部未曾实现的人生并肩作战。

战场上最默契的搭档，是另一个你自己。

先决条件：基本攻击加值+4

每等级20点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+1（1）|回音显形|
|2|+1（2）|回响|
|3|+1（3）|回音换位|
|4|+1（4）|属性值提升，回音殉身|
|5|+1（5）|万千回音|

**回音显形（Su）：** 花费3AP，你在30尺内一处你能看见的未被占据的空间召唤出一个魔法回音：它是你半透明的灰色影像，与你共享姿态与动作，但并非真正的生物。回音占据空间；其AC为10+你的回音战士等级+你的敏捷调整值；其生命值为1，免疫一切状态，受到任何伤害即被摧毁。在你的回合中，回音可以随你的移动一并移动至多30尺，无需额外消耗行动。若回音在你的回合结束时距离你超过30尺，或你陷入失能，回音立即消散；你也可以花费1AP主动遣散回音。回音被摧毁或消散后，你可以再次召唤，本能力没有每日次数限制。

当你进行近战武器攻击时，你可以选择让该攻击以你或回音的位置为源点，触及范围自所选位置计算；回音在战斗中也算作一个有威胁的生物，例如当一名敌人离开回音的威胁范围时，你可以消耗你的反应动作，如常以回音为源点对其发动借机攻击，包括你的其它盟友也能与其进行夹击。

**回响（Su）：** 每回合一次，当你或回音的近战武器攻击命中一名敌人后，未发动该次攻击的另一方（你与其他回音）可以立即各自对其触及范围内的另一名敌人进行一次相同的武器攻击。你每完成一次短休便恢复全部使用次数，次数等同于你的回音战士等级。

**回音换位（Su）：** 花费1AP，你与一个30尺内的回音交换位置。

**回音殉身（Su）：** 每短休一次，当一个距离你30尺以内、你能看见的生物被一次攻击命中时，你可以以一个反应动作令回音瞬间扑至该生物身前（视为传送）：该次攻击的目标改为回音。回音几乎必然因此消散——这是它存在的意义之一。

**万千回音（Su）：** 你现在可以同时维持两个回音（召唤第二个回音同样花费3AP，两者可以分别随你移动、分别作为攻击源点）；回音换位时你可以任选其中一个回音交换位置。此外，当你的回音被摧毁时，散逸的可能性回流向你：你获得5点临时生命值。
