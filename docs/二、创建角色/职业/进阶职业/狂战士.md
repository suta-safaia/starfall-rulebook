# 狂战士

第一个撞上盾墙的是狂战士。长矛刺穿他的肩膀，他连眉头都没皱——抓住矛杆，把持矛的士兵整个人拖出队列，一斧劈进头盔。第二根长矛扎进大腿，第三根擦着肋骨划过，血顺着盔甲往下淌，而他的斧头没有停。盾墙从中间裂开一道口子，口子后面的士兵开始后退：他们看见那个浑身是血的男人在笑，笑得像是听见了什么极好笑的笑话。没有人敢问笑点是什么。

狂战士是把疼痛酿成烈酒的战场疯子。寻常的战士在受伤后退缩，狂战士在受伤后兴奋——每一道伤口都是一记战鼓，每一滴鲜血都是一声号角。他们战斗时毫无保留，把防御抛诸脑后，把全部的生命押在下一击上。而当死亡真正逼近时，狂战士反而踏入最强的境地：垂死的狂怒之下，刀剑难伤，魔法难困。

别惹流血的人。尤其别惹流着血还在笑的人。

先决条件：基本攻击加值+5，威吓+8，顺劈斩或强力顺劈斩

**鲁莽攻击（Ex）：** 你进行近战武器攻击时，可以选择鲁莽攻击：你的下个回合结束前，你的近战武器攻击获得+2加值，伤害检定获得等同于你狂战士等级一半（向下取整）的加值；但作为代价，你的AC同时获得-4士气减值。

**睚眦必报（Ex）：** 当一名敌人以攻击命中你后，你将被其激怒：直至你的下个回合结束前，你对该敌人的攻击检定获得+2士气加值；若该敌人在你的速度范围内，你为了攻击他而进行的移动不需要花费AP。同一敌人重复命中你时，效果不叠加，但持续时间刷新。

**血怒（Ex）：** 当你的生命值低于上限的1/4时，你进入血怒状态，在该状态下，你获得等同于你狂战士等级的物理抗力，且在对抗惑控系与心灵影响效果的豁免检定上获得+4士气加值。

**以牙还牙（Ex）：** 每轮一次，当触及范围内的一名敌人以攻击命中你时，你可以以一个反应动作立即对其进行一次借机攻击，在血怒状态下，这次攻击不消耗反应。

**威吓咆哮（Ex）：** 花费2AP，你发出令敌胆寒的咆哮：30尺内所有由你指定的敌人必须进行一次DC=10+狂战士等级+你力量调整值的感知豁免，失败则恐惧状态1分钟。若你在血怒状态，豁免失败的敌人在第一回合会额外陷入震慑。

**激励狂怒（Su）：** 你的狂怒会点燃身旁的战友。当你处于血怒状态时，60尺内能看见或听见你的盟友获得以下增益：攻击检定获得+1士气加值，对抗恐惧的豁免检定获得+2士气加值。这些增益在你脱离血怒状态时立即结束。

**血怒强化（Ex）：** 你在血怒状态时还会额外获得强酸、火焰、冷冻、闪电的抗力，等同于你的狂战士等级，你的武器攻击额外造成你狂战士等级一半的武器同类型的伤害。

**死战不休（Ex）：** 每长休一次，当你的生命值降至0或以下时，你拒绝倒下，你可以正常行动，但是在你的回合开始时，你获得2层力竭。
