# 决斗家

决斗场的黄沙上，重甲战士拖着巨剑步步逼近，决斗家却把左手的披风解下，随手抛在栏杆上。第一剑劈来，他侧身让过，细剑在对方腕甲的接缝处点了三下；第二剑横扫，他俯身低头，剑锋自下而上停在了对方的咽喉。战士怔在原地——他甚至没看清那柄细剑是何时出鞘的。

决斗家是把一对一的战斗升华为艺术的大师。他们不依赖蛮力与重甲，而是依靠步法、节奏与时机：在对手挥剑的间隙里读完他的意图，在自己的剑尖抵达之前就已经知道了结局。铠甲会拖累脚步，蛮力会蒙蔽双眼，决斗家的武器只有两件——一柄快剑，和比剑更快的头脑。

胜负在剑刃相交之前，就已经分出来了。

先决条件：基本攻击加值+4，敏捷16，拥有任意灵巧武器的专攻武器专长

每等级20点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+1（1）|精准剑术，灵动防御|
|2|+2（2）|灵巧步伐|
|3|+3（3）|孤剑|
|4|+4（4）|属性值提升|
|5|+5（5）|致命剑术|
|6|+6（6）|决斗挑战|
|7|+7（7）|完美格挡|
|8|+8（8）|属性值提升|

**精准剑术（Ex）：** 当你单手持用一把灵巧近战武器、且另一只手没有持用武器时，你以该武器进行的攻击，其伤害检定获得等同于你决斗家等级一半（向下取整，最少1）的精准加值。

**灵动防御（Ex）：** 未穿着中甲、重甲时，你的AC获得等同于你敏捷调整值一半的环境加值。即使你陷入措手不及，该加值依然有效。

**灵巧步伐（Ex）：** 你每回合第一次因为移动招致的借机攻击不会生效。

**孤剑（Ex）：** 你熟练与一对一的决斗，当和敌人作战时，若你的周围有一名敌人且你和敌人周围都没有对方以外的其他盟友或敌人，你进入专注决斗状态，并将其视为你的决斗对象：

- 你在决斗状态时，你的灵动防御效果翻倍。
- 你对决斗对象的灵巧武器攻击检定获得+2加值。
- 决斗对象离开你威胁的区域时，即使使用五尺快步，也会照常引发你的借机攻击。

**致命剑术（Ex）：** 你对你的决斗对象进行灵巧武器攻击时，重击阈值扩大2。

**决斗挑战（Ex）：** 每短休一次，你花费3AP向一名你能看见的敌人发起决斗挑战，敌人可以选择是否接受你的挑战。
若敌人接受：
- 无论是否符合孤剑条件，你都处于决斗状态且敌人视为你的决斗对象。
- 决斗对象攻击除你以外的目标时，攻击检定和DC承受-4环境减值。

若敌人不接受：
- 你不消耗你的决斗挑战次数
- 敌人必须进行一次DC = 10 + 你决斗家等级 + 感知调整值的感知豁免，否则对你恐惧1分钟。

决斗在以下任一情况发生时结束：决斗任意一方死亡或失去意识；你自愿以即时动作结束决斗；或你攻击了决斗对象以外的敌人。你同一时间只能有一名决斗对象。

**完美格挡（Ex）：** 当你被一次近战攻击命中时，你可以以一个反应动作进行一次武器攻击检定：若你的检定结果不低于对方的攻击检定结果，该次攻击的伤害减半；若你的检定结果超过对方5点或以上，该次攻击被完全格开，你不受任何伤害。使用格挡时，你必须持用一把你拥有专攻武器专长的武器。如果你格挡成功且格挡的对象是你的决斗对象，你恢复你反应动作。
