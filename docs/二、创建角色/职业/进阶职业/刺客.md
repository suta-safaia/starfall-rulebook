# 刺客

宴会上，目标举起酒杯向宾客致意。他看不见人群里那个端酒的侍者已经换了三次位置，看不见烛火的阴影里有一双眼睛数着他的呼吸，更看不见三天前就有人坐在他的书房里，记下他读信时习惯把椅子向右倾——露出左肋的缝隙。酒杯举到唇边时，刀锋从那个缝隙里走了进去。宾客们甚至没听见倒下的声音。

刺客是把杀戮锤炼为精密工艺的匠人。他们不追求堂堂正正的胜负——那是武士的事。刺客追求的是"必然"：在出手之前研究目标的呼吸、习惯、护甲的接缝与心防的破绽，然后在一击之中兑现全部的准备。对刺客而言，战斗在拔刀之前就已经结束了；刀刃只是来收取一个早已注定的结果。

你死的那一刻，只是我已完成的计划里，最后执行的一步。

先决条件：隐匿+8，偷袭

每等级15点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+0（0）|致命伏击|
|2|+1（1）|无声无息|
|3|+1（2）|淬毒|
|4|+1（3）|属性值提升，致命研究|
|5|+0（3）|死亡宣告|

**致命伏击（Ex）：** 对未察觉到你存在的目标，你的第一次武器攻击若命中，自动视为重击。刺杀的艺术在于：第一刀，就是最后一刀。

**无声无息（Ex）：** 你的隐匿检定获得+2环境加值；你在隐匿状态下进行攻击后，可以花费1AP尝试保持隐匿（再次进行一次具有-5环境减值的隐匿检定）。此外，你以正常速度移动时，隐匿检定不再承受减值。

**淬毒（Ex）：** 你精通毒药的运用：你为自己或武器涂抹毒药时不会有误伤自己的风险；你制作的毒药豁免DC+2。此外，你可以花费即时动作为武器临时淬毒：下一次以该武器命中的攻击附加2d6点毒素伤害，然后效果结束。你可以使用这个特性的次数等同于你的刺客等级，每完成一次长休后恢复全部次数。

**致命研究（Ex）：** 花费1分钟持续观察一名你能看见的目标，你找到了它的命门：你对该目标的攻击，重击范围扩大1点（例如从20扩大为19-20），且偷袭伤害额外增加2d6。研究效果持续至你更换研究目标或经过24小时。

**死亡宣告（Ex）：** 当你的偷袭命中一名已被你致命研究的目标，或你的偷袭攻击造成重击时，你可以对其发出死亡宣告：目标必须进行一次DC=10+刺客等级+你敏捷调整值的体质豁免，失败则直接死亡，豁免成功也额外受到50点伤害。若目标的等级比你的等级低不到5级，其豁免自动通过。一名目标在24小时内不会再次受到本特性的影响——真正的强敌从不死于一声宣告。
