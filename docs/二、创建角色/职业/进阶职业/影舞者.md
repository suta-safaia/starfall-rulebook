# 影舞者

市集的人群中，刺客的刀刃刚抵上目标的后腰——下一秒，他脚下的影子立了起来。没有人看清发生了什么：人群依旧喧闹，尸体却已消失在巷尾的阴影里，只剩地上一道细长的血线，和墙头一片微微晃动的、不属于任何物体的影子。有人说那是光玩的把戏。死者们知道不是。

影舞者是行走于光与暗夹缝中的大师。他们不制造阴影，他们成为阴影。在影舞者眼中，阴影是道路、是盔甲、也是武器：在影中穿行，借影藏身，以影缚敌。寻常游荡者需要黑暗才能隐藏自己，而影舞者本身即是黑暗——光越强，他们脚下的路就越多。

光明所至之处，阴影亦步亦趋。

先决条件：敏捷17，拥有偷袭能力且偷袭伤害不低于2d6

每等级15点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+0（0）|幽影视界，影匿|
|2|+1（1）|影跃|
|3|+1（2）|影缚|
|4|+1（3）|属性值提升，迅捷影跃|
|5|+0（3）|幽影化身|

**幽影视界（Ex）：** 你获得30尺黑暗视觉；若你已拥有黑暗视觉，其范围增加30尺。你可以看穿魔法黑暗，如同其为普通黑暗。

**影匿（Ex）：** 只要你处于微光或黑暗环境中，即使你正处于敌人的直接注视下，你依然可以尝试进行隐匿检定来隐藏自己。

**影跃（Su）：** 花费2AP，你融入脚下的阴影，瞬间出现在另一片阴影之中：你传送至至多每影舞者等级10尺（最高50尺）远的一处你能看见的、未被占据的空间，起点与终点都必须处于微光或黑暗之中，该移动不会引发借机攻击。且你在影跃后的同一回合内，下一次你以武器攻击命中一名敌人，该次攻击可以附加偷袭伤害，即使偷袭的通常条件并未满足。

**影缚（Su）：** 花费2AP，你缚住30尺内一名敌人的影子，将其钉在原地：目标必须进行一次DC=10+影舞者等级+你敏捷调整值的魅力豁免，否则其影子被钉在原地不会随着本体移动，持续至你的下个回合结束。影子和本体的数据保持一致，影子所受到的伤害将会有一半会传导给本体，你每完成一次长休便恢复全部使用次数，影缚的次数等同于你的影舞者等级。

**迅捷影跃（Su）：** 你回合中的第一次影跃无需花费AP；此外，只要你5尺内存在任何比你体型更大的物体投下的阴影，你的影匿在明亮环境中同样有效。

**幽影化身（Su）：** 每长休一次，花费3AP，你化身为半实体的幽影，持续1分钟：你获得等同于你影舞者等级两倍的物理抗力；你的移动不会引发借机攻击；你可以穿过其他生物占据的空间与任何不小于1寸宽的缝隙，但无法穿过固体障碍；在你的身边弥漫着10尺半径的魔法黑暗，其效力视为2环法术。效果结束时你恢复实体，若你正处于无法容纳你的空间中，你被挤入最近的空位并受到4d6点力场伤害。
