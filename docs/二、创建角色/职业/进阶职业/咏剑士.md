# 咏剑士

观战的士兵们本以为会看到一场决斗，结果看到的是一支舞。那名咏剑士在枪林剑雨中旋转、折身、剑锋贴着敌人的咽喉掠过却不落下，口中吟着一首没有歌词的古调。第十个音节落下时，七名敌人的武器同时脱手——没有人看清是哪一剑挑飞的。她收剑回鞘，歌声的余韵还绕在梁上。有人问她这是什么剑法。她说："这是歌。剑只是伴唱。"

咏剑士是把奥术唱进剑招里的武者艺人。这门技艺源自古老的传统：法术不一定要吟诵咒文，也可以融进旋律；剑术不一定要刚猛暴烈，也可以踏着节拍。咏剑士战斗时一心三用——剑在走，歌在唱，魔法在音节的缝隙间流淌。他们的剑舞既是舞步也是施法姿势，他们的歌声既是战曲也是咒语本身。

剑是词，歌是谱，战斗是一首唱不完的长诗。

先决条件：能够施展2环奥术，体操+5

每等级15点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+0（0）|施法精进，朦胧之歌|
|2|+1（1）|次级法术之歌|
|3|+1（2）|施法精进|
|4|+1（3）|属性值提升，轻灵之歌（2环）|
|5|+0（3）|施法精进|
|6|+1（4）|高级法术之歌|
|7|+1（5）|施法精进|
|8|+1（6）|属性值提升，轻灵之歌（4环）|
|9|+0（6）|施法精进|
|10|+1（7）|守御之歌|

**施法精进：** 在1、3、5、7、9级时，指定一个你拥有的奥术施法者职业：你的法术位、已知法术（或法术书可准备的法术）与施法者等级如同在该职业上额外提升了1级，但你不会获得该职业的其他职业能力。

**朦胧之歌（Su）：** 当你单手持用灵巧武器、另一只手完全空着（不持盾、不副手持武器、不持用任何物品），且只穿着轻甲或无甲时，你的AC获得等同于你咏剑士等级的闪避加值，最高不超过你的智力调整值。

**次级法术之歌（Ex）：** 你在施展法术时若使用防御性施法，专注检定获得等同于你智力调整值的加值。

**轻灵之歌（Sp）：** 每短休一次，你可以如同附带了法术瞬发一般，瞬发一个2环或以下的奥术：不消耗更高环的法术位，也不需要额外的施法时间。使用本特性必须满足朦胧之歌的持剑与着装条件。8级起，你可以瞬发的法术提升至4环或以下。

**高级法术之歌（Ex）：** 你的所有专注检定获得等同于你智力调整值的加值（防御性施法不会因此重复获得加值）。

**守御之歌（Su）：** 受到伤害时，你可以用自己的反应来消耗一个法术位，以使你受到的伤害减少等同于该法术位环阶七倍的数值。
