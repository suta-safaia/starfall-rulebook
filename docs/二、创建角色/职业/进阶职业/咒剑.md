# 咒剑

佣兵们第一次见他出手时，以为他只是个普通的剑士——直到他的剑亮了起来。第一剑劈开铠甲，刃上缠绕的奥光比钢铁更锋利；第二剑刺入大地，被封存在剑身里的火球顺着伤口轰进了巨魔的胸膛；第三剑挥出时，剑身上冰封的咒语碎裂开来，把扑来的狼群连同空气一起冻结。战后有人问他究竟是战士还是法师。他擦拭着剑刃上明灭的符文，说："咒语不一定要念出来。我把它写在剑上。"

咒剑是将奥术封存进武器的战斗施法者。他们不把法术位当作用完即弃的弹药，而是当作可以锻打进钢铁的材料：法术位被压入剑刃，化作流转的锋锐与杀机；完整的法术被封进剑脊，在命中的一瞬坍缩、引爆，顺着剑刃灌进敌人的躯体。咒剑自身的剑术足以立身，而他们的魔法学识——无论来自法师的典籍还是术士的血脉——都会成为剑刃上的一道道咒纹。

咒是刃，剑是鞘，出鞘之时，万法归一。

先决条件：至少拥有1级奥术施法者职业等级（法师、术士等）

每等级20点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+1（1）|咒刃注能|
|2|+2（2）|施法精进，奥术斩|
|3|+3（3）|战斗施法|
|4|+4（4）|施法精进，属性值提升|
|5|+5（5）|法术灌注|
|6|+6（6）|施法精进，瞬影斩|
|7|+7（7）|破法斩|
|8|+8（8）|施法精进，属性值提升|
|9|+9（9）|剑气延展|
|10|+10（10）|施法精进，万咒归刃|

**施法精进：** 在2、4、6、8、10级时，指定一个你拥有的奥术施法者职业：你的法术位、已知法术（或法术书可准备的法术）与施法者等级如同在该职业上额外提升了1级，但你不会获得该职业的其他职业能力。

**咒刃注能（Su）：** 花费2AP，消耗一个你的奥术法术位，将魔力注入你持用的一把武器，持续1分钟：该武器在注能持续时间内视为魔法武器，其攻击检定获得等同于所消耗法术位环位一半的增强加值（向下取整），命中时额外造成等同于该环位的力场伤害。对一把仍有注能效果的武器再次注入时，新注能替换旧注能。注能只在你持用该武器时生效。

**奥术斩（Su）：** 当你的武器攻击命中时，你可以以一个即时动作消耗一个奥术法术位，将纯粹的奥术能量顺着武器灌入目标：额外造成1d10力场伤害，消耗的法术位每高于1环则额外增加1d10。你每回合只能使用一次奥术斩。

**战斗施法（Ex）：** 你持用武器的手可以完成法术的姿势成分；你在敌人的威胁范围内施法引发借机攻击时，你的AC在对抗该次借机攻击时获得+4闪避加值。

**法术灌注（Su）：** 花费2AP，将一个你已知或已准备的奥术封存进你持用的一把武器，并消耗对应环位的法术位。下一次以该武器攻击命中时，该法术自动顺着剑刃释放，且只作用于被命中的生物：若法术以单体为目标，则直接对其生效（需要法术攻击检定的视为命中，如果需要豁免则正常进行豁免检定）；若法术为范围效果，则坍缩为单体，仅被命中者进行豁免并承受效果。法术的豁免DC与施法者等级按你原施法职业计算。灌注持续至你的下次长休；一把武器同一时间只能灌注一个法术，灌注新法术会替换旧法术；你可同时灌注法术的武器数量等同于你咒剑等级的一半（向下取整，最低为1）。

**瞬影斩（Su）：** 花费3AP，消耗一个奥术法术位，你化作一道奥光突进：传送至30尺内你可见的一处未被占据的空间，然后对触及范围内的一名敌人进行一次武器攻击；此次攻击若命中，视同以该法术位环位发动了奥术斩（计入奥术斩每回合一次的限制）。

**破法斩（Su）：** 每回合一次，当你使用消耗了至少3环法术位的奥术斩命中目标时，你可以尝试如同*解除魔法*般解除该目标身上的一个法术效果，施法者等级等同于你的奥术施法者等级。

**剑气延展（Su）：** 你的注入武器锋芒毕露，剑气延伸至刃外20尺：你可以持注入武器对20尺内的目标进行攻击，此次攻击视作远程攻击（如同远程武器攻击般会引发借机攻击），但命中时视同近战武器攻击命中，可以正常触发奥术斩、破法斩与灌注法术等效果。

**万咒归刃（Su）：** 你的注能技艺臻至化境：注能额外伤害提升为所消耗法术位环位的两倍；你的注入武器在击破伤害减免时额外视为精金与银质武器。此外，每长休一次，你可以不消耗法术位进行一次咒刃注能，其环位视同你能施展的最高环法术。
