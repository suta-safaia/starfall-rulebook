# 元素师

老祭司说世界是神造的，法师说世界是符文织的，而岩洞深处的那个人只是摊开手掌：掌心上方，水与火各自旋转，互不侵犯，又彼此成全。"都错了，"他说，"世界不是被'造'出来的，是被'调'出来的——水多少，火多少，光多少，暗多少。万物皆有其配比，我所做的，不过是听懂元素的声音，然后请求它们多给我一分。"洞外雷暴正烈，洞内干燥温暖，火光在他的指尖跳动着，像一头被驯服的兽。

元素师是与构成世界的六大元素——水、火、土、风、光、暗——直接沟通的施法者。他们不似法师那般钻研符文的结构，而是终其一生锤炼自己与元素的共鸣：每精进一分修为，便选择一种元素加深理解，让那种元素的魔力在体内沉淀得更为深厚。深厚的元素修为不仅拓宽他们的法术——每一种元素法术都对相应的元素修为有所要求——也会反过来淬炼元素师的本体：修火者不畏烈焰，修风者身轻如燕，修土者坚若磐石。而当你对某种元素的理解抵达一定的深度，或是两种元素在你体内达成奇妙的平衡时，元素会回赠你超越自身环位的秘术——那是任何法术书上都找不到的、独属于元素师的馈赠。

万物皆由六元素调和而成，元素师做的，只是让世界听见自己的声音。

*元素师的戏法准备位不限，戏法栏数字仅代表元素师升级能获得的戏法数量。*

**施法（元素师）：** 元素师为记忆施法者，施法主属性为魅力。元素师无需法术书，可以直接准备元素法术表中记载的所有法术，但每个元素法术都标注了元素等级需求（例如"火2"、"水1风1"），元素师只能准备和施展满足需求的法术。高环法术通常需要较高的单元素等级（例如9环法术一般需求对应元素13级），双元素法术则对两项元素各有等级需求，须同时满足。

- 仪式施法：如果你的法术位准备了一个带有仪式标签的法术，你可以使用该法术位进行仪式施法，规则同法师。

**元素修炼：** 元素师每提升一个职业等级，就选择水、火、土、风、光、暗中的一**项元素提升1级**。元素师的全部元素等级之和等于其元素师等级。元素等级产生两方面的影响：

- **本体增益：** 每项元素在达到特定等级时，会为元素师本体带来永久的增益（见下表）。
- **元素秘术：** 达到特定的元素里程碑时，元素会回赠元素师特殊的秘术（见后）。

**本体增益：** 元素师的每项元素在达到1级、5级、10级、15级、20级时，为其带来如下永久增益。
见[元素修炼表]

- **水：**
  - 1级：你的寒冷法术额外造成等同于你水元素等级的伤害。你获得水中呼吸能力，以及等同于你陆地速度的游泳速度。
  - 5级：你获得寒冷抗力5。
  - 10级：受到你寒冷法术伤害的生物，移动速度降低10尺，持续1轮。你可以在水面上行走，在水下行动不受任何惩罚。
  - 15级：你获得寒冷抗力10。
  - 20级：你获得快速医疗5。你濒死时自动稳定伤势。
- **火：**
  - 1级：你的火焰法术额外造成等同于你火元素等级的伤害。你不受炎热环境的影响。
  - 5级：你获得火焰抗力5。
  - 10级：你的火焰法术无视目标等同于你火元素等级的火焰抗力。
  - 15级：你获得火焰抗力10。
  - 20级：你的火焰伤害对免疫火焰的生物仍造成一半伤害。
- **土：**
  - 1级：你的毒素法术额外造成等同于你土元素等级的伤害。你的AC获得+1天生护甲加值。
  - 5级：你获得毒素抗力5。
  - 10级：你获得挥砍、穿刺、钝击抗力3。
  - 15级：你获得毒素抗力10。
  - 20级：重击对你只视为普通命中。
- **风：**
  - 1级：你的闪电法术额外造成等同于你风元素等级的伤害。你的移动速度增加10尺。
  - 5级：你获得闪电抗力5。
  - 10级：你获得飞行速度30尺（机动性良好）。
  - 15级：你获得闪电抗力10。
  - 20级：你的飞行速度提升为60尺，机动性完美。你的移动不会引发借机攻击。
- **光：**
  - 1级：你的光耀法术额外造成等同于你光元素等级的伤害。你可以随意施展*光亮术*（类法术能力）。
  - 5级：你获得光耀抗力5。
  - 10级：不死生物与邪恶异界生物对你的攻击检定承受-2减值。你施展的带有治疗字段的法术，额外恢复等同于该法术环阶两倍的生命值。
  - 15级：你获得光耀抗力10。
  - 20级：你周围20尺范围内弥漫神圣灵光，可以一个即时动作抑制或恢复。灵光内的盟友豁免检定获得+2加值；不死生物与邪恶异界生物在灵光内攻击检定承受-2减值，并在其回合开始时受到1d6光耀伤害。
- **暗：**
  - 1级：你的暗蚀法术额外造成等同于你暗元素等级的伤害。你获得60尺黑暗视觉；若你已拥有黑暗视觉，其范围增加30尺。
  - 5级：你获得暗蚀抗力5。
  - 10级：受到你暗蚀法术伤害的生物，攻击检定承受-2减值，持续1轮。你可以看穿魔法黑暗。
  - 15级：你获得暗蚀抗力10。
  - 20级：你在昏暗或黑暗环境中获得隐蔽（对你的攻击承受20%失手率）。你造成的暗蚀伤害的一半转化为对你的治疗。

**元素秘术：** 当元素师的元素修为达到特定的里程碑时，元素会回赠独属于元素师的特殊法术（见[元素秘术表](元素秘术表.md)）。元素秘术每天可以免费施展一次，不消耗法术位、不需要准备，即使元素师当前的可用环阶还不足以施展该法术。

- **单元素里程碑：** 每当一项元素达到**3级、7级、13级、20级**时，获得该元素对应深度的一份秘术，分别相当于**2环、4环、7环、9环**法术。
- **双元素里程碑：** 当某**两项元素的等级达到**达到**3+3、5+5、8+8**时，获得这两种元素对应的融合秘术，分别相当于**3环、6环、8环**法术。每一对达标的元素组合都会各自给予一份融合秘术。

**元素归一：** 20级时，你每天可以额外使用一次任意一种你已获得的元素秘术。
