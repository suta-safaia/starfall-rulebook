# 法师

学徒们早已睡下，只有老法师还坐在摊开的三本古籍之间，逐字比对同一个符文的三种写法。桌角的法术书摊开着，纸页间夹满批注——四十年前他在这页写下第一个法术时，字迹还歪歪扭扭。奥术从不白给任何人：天赋让人触到它的门槛，而门后的路，只能用理解一步一步走完。吹熄蜡烛前，他在笔记末尾写下今晚的结论。明天，他的法术书里又会多出一页。

法师是天赋与学识缺一不可的奥术施法者。没有奥术天赋，便触摸不到魔力的源流；而没有经年累月的钻研，天赋也不过是一粒无法发芽的种子。法师的求学之路注重根基：他们钻研符文的结构、咒文的音律、元素流转的原理，把每一个法术从里到外吃透，再工整地誊录进自己的法术书。这份对基础知识的执着换来了广博——法师掌握的法术数量庞大，法术书随着阅历不断增厚，从点亮烛火的小伎俩到撕裂空间的大奥术，尽在其中。战斗中的法师从容而周密：提前准备的法术如同排布好的棋局，无论局面如何变化，他们总能从书页间翻出应对之策。

奥术面前人人平等：你钻研多少，它就给你多少。

*法师的戏法准备位不限，戏法栏数字仅代表法师升级能获得的戏法数量*



**法术书（Spellbooks）：** 法师必须每天研习他的法术书来准备法术。他不能准备任何没有记录在他法术书内的法术，除了*阅读魔法（read magic）* ，任何法师都可以凭记忆准备这个法术。

在开始游戏的时候法师会带有一本法术书，该法术书内记录了所学习的法术（除了他的禁止学派法术，如果有的话;见之后学派专精），再加上3个玩家选择的一级法术。法师的每一点智力调整值可以让起始法术书内多获得一个一级法术。每获得一个新的法师等级，法师都可以获得两个法术添加在法术书中，这两个法术可以是任何他能施展的法术等级上的法术（基于他新的法师等级）。

**施法（法师）：** 法师为记忆施法者，施法主属性为智力，在法师完成长休时，你需要从法术书中选择一个法术填充进你的法术位中（填充的法术环阶必须不高于你的法术位环阶），若你没有填充法术位，你就不能使用该法术位施法，一些能力能让你即时或者以较短的时间临时填充预留的空法术位，但总体来说法师的法术绝大部分需要提前准备。

- 仪式施法：如果你的法术位记录了一个带有仪式法术，你可以使用该法术位进行仪式施法，这种施法方式不会消耗法术位以及里面存放的法术，你随时可以中断仪式施法转而以一个正常的方式释放法术
- 每日额外法术：法师在长休时获得额外等同于他智力调整值的法术位总额，法师可以将值分配在不同的法术位上，例如一个法师的智力调整值是+4，那么可以选择获得2个额外的1环法术位和1个额外的2环法术位，也可以获得1个额外的4环法术位。



**学派专精：** 绝大部分法术属于八大类法术的一种，每类法术都有一个共同的特色。如果愿意，法师可以专精某一个学派（见后）。学派专精可以让法师施展他所选定学派时获得增强并且能够释放额外法术，但在释放某些其他学派的法术时将会受到削弱。

在法师1级时，就要决定是否专精学派，且他就必须选择专精于哪一学派，并且选择两门学派作为自己的**生疏学派**，代表自己为了专精某一学派而忽视的学派。

**专精学派**

- 你在释放该学派法术时，施法者等级+1
- 在辨识该学派的法术时，你的辨识检定获得+2加值
- 你的每一个等级的环阶每天可以额外记忆一个该学派的法术

**生疏学派**

- 你在释放该学派法术时，施法者等级-2
- 你永远无法制造与该学派相关的卷轴、法杖等魔法物品



**奖励专长：** 法师的奖励专长从超魔法专长、物品制造专长或者法术熟稔专长中选择。
