# 大法师

魔法学院藏书塔的塔顶有一扇没有锁的门，门上只有一行字："你明白了什么？"求索者们穷尽一生作答：有人写下方程，有人献出血脉，有人堆起金山，门从未打开。直到一位老者在门上写下一个字——"够"。门开了。塔顶的灯火亮起，照亮了他身后的万里长夜。

大法师是站在奥术之巅的求索者。当普通法师还在逐字逐句地诵读咒文时，大法师已经在拆解魔法本身的经纬：他们看穿法术的结构，捏合互斥的元素，把咒语锻造成顺手的形状，甚至将法术位当作可以随意取用的薪柴。对大法师而言，魔法不再是需要侍奉的神明，而是俯首听命的仆从——他们唯一仍然敬畏的，是奥术本身的无穷。

法术书会写完，而奥术没有最后一页。

先决条件：能够施展5环奥术法术

每等级12点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+0（0）|施法精进，高深学识|
|2|+1（1）|施法精进，奥术回响|
|3|+0（1）|施法精进，高深学识|
|4|+1（2）|施法精进，属性值提升|
|5|+0（2）|施法精进，高深学识，传奇法师|

**施法精进：** 在1、2、3、4、5级时，指定一个你拥有的奥术施法者职业：你的法术位、已知法术（或法术书可准备的法术）与施法者等级如同在该职业上额外提升了1级，但你不会获得该职业的其他职业能力。

**高深学识：** 你习得了超越凡俗的奥术秘艺。在1、3、5级时，你从下列学识中各选择一项；除特别注明外，同一项学识不可重复选择。

- **奥术余烬（Su）：** 法术位燃尽后仍有余温。花费1AP，你点燃一个**已消耗**法术位中残存的魔力：化作一道60尺直线或30尺锥形的能量洪流，范围内生物受到每法术位环阶1d8点力场伤害（反射豁免成功伤害减半，DC=10+大法师等级+你的施法主属性调整值），视为释放了一次塑能法术。每个已消耗的法术位只能被点燃一次，该法术位正常随休息恢复。你可以使用这个特性的次数等同于你的大法师等级，每完成一次长休后恢复全部次数。
- **塑形掌控（Su）：** 当你施展影响一片区域的塑能系法术时，你可以任意指定至多等同于你施法主属性调整值名生物，他们完全不受该法术影响。
- **法术之力（Ex）：** 你的奥术的施法者等级+1。该学识可以选择两次，效果叠加。
- **反制掌控（Su）：** 当你成功反制一个法术时，你可以花费2AP将该法术反弹回其施法者：如同你是该法术的施法者，而原施法者成为目标。
- **高等超魔（Su）：** 每短休一次，你可以在不增加施法时间、不消耗更高环法术位的前提下，为你施展的一个法术附加一个你已掌握的超魔法专长效果。
- **万法通晓（Su）：** 每长休一次，你可以施展一个你当前并未准备（或不知晓）的奥术，如同你已准备（或知晓）它：记忆施法者只能选取记录于自己法术书中的法术，自发施法者只能选取其职业法术列表中的法术。施展时正常消耗法术位与施法时间。

**奥术回响（Su）：** 当你施展一个环阶不高于3环的法术后，你都有25%的概率不消耗法术位。当你达到大法师5级时，该能力可以对环阶不高于5环的法术使用。

**传奇法师（Ex）：** 大法师足以触及凡人不应触及的领域——第十环。你从10环法术中选择一道铭刻于心（10环法术表尚未收录，待后续补充）。10环法术已没有传统意义上的法术位：施展它无需消耗法术位，但仍需满足其施法时间、法术成分等全部正常规则。触及第十环的代价同样超越凡俗：法术结束后，你立刻获得1d4层力竭，且在之后的3d8天内无法再次使用本特性。
