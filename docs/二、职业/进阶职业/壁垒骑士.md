# 壁垒骑士

城破的那一夜，所有人都退进了内堡，只有他反身走向了城门。他没有锁门，也没有祈祷，只是把塔盾往门洞中央一立，双手拄着剑柄站定。潮水的第一波浪头拍在盾面上时，他退了半步；第七波浪头拍上来时，他已经一步都不退了。天亮后援军赶到，看见城门洞里堆着小山般的尸体，和尸体后面那个拄剑而立、浑身是伤却依然站着的身影。有人问他怎么做到的。他说："我没想赢。我只是不能倒。"

壁垒骑士是把"守护"二字铸进骨髓的战士。他们的武艺不为杀敌，而为遮挡：为身后的同伴挡下刀刃、箭矢与法术，为脚下的阵地挡住人潮与恐惧。一名壁垒骑士站在哪里，哪里就是城墙；他走向哪里，城墙就推进到哪里。敌人很快会明白一件事：想要伤害他身后的人，唯一的办法是先让他倒下——而这恰恰是世界上最难的事。

城在人在。城，就是人。

**格挡护卫（Ex）：** 当你持用盾牌或具有格挡词条的武器时，你能为身旁的同伴挡下攻势：与你相邻的盟友AC获得+2盾牌加值。此外，每回合一次，当与你相邻的一名盟友被一次攻击命中时，你可以以一个反应动作代为格挡：该盟友对抗该次攻击的AC再获得+2盾牌加值，若因此使该次攻击未能命中，则其正常落空。

**壁垒甲胄（Ex）：** 甲胄如肤。当你穿着重甲时，你额外获得等同于1+你壁垒骑士等级一半的物理抗力，且你能够穿着重甲进行正常的休息。

**守卫领域（Ex）：** 你的存在本身即是阵地：你的威胁范围扩大5尺。敌人在你的威胁区域内移动不会引发你的借机攻击，但会将你的威胁区域视为困难地形——踏入你防线的人，每一步都要付出代价。

**保护（Su）：** 你魔法性和一个自愿生物创建一条神圣连接以保护他的生命，当你被保护的人受到伤害时，其受到的伤害减半，但你也受到同样数值的真实伤害。

**守卫结界（Su）：** 当你或你30尺内的盟友面临范围法术或范围效应的威胁时，你可以以一个反应动作展开守卫结界：你30尺内的所有盟友在此次效应中受到的伤害减半——你自己不在其列。结界护得住所有人，唯独护不住张开它的人，这就是守护。使用次数等同于1+你的魅力调整值（最少1次），你每完成一次短休或长休便恢复全部使用次数。

**心如砥柱（Ex）：** 守护的意志不可动摇：你免疫一切会强迫你攻击盟友的魅惑与胁迫效果（该效果的其他部分仍正常生效）。法术可以迷惑你的眼睛，却指挥不了你的剑该指向谁。

**守护之誓（Su）：** 花费1AP，你将自己的生命渡给身后之人：你失去任意点数的生命值（至多为你壁垒骑士等级的两倍，且不会因此降至0点以下），60尺内一名盟友获得等量的临时生命值。

**圣所壁垒（Su）：** 每长休一次，花费2AP，你将全部心神倾注于守护，立起一座以身躯为基石的圣所，持续1分钟：期间你的AC承受-2减值；每当一名敌人以你威胁范围内的盟友为目标发动攻击时，其必须先通过一次魅力豁免（DC=10+你壁垒骑士等级的一半+你的魅力调整值），失败则该次攻击的目标改为你。此能力无法转移范围效果——火球落下时，你能做的只有扑在同伴身上。
