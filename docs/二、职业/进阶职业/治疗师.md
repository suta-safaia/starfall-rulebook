# 治疗师

战后的营地没有歌声。治疗师提着药箱走过一排排担架，验伤、清洗、缝合、喂药，动作不快，但没有一下是多余的。有人拽住她的袖子，问这条腿保得住吗。她看了一眼伤口："保得住。三天别下地。"说完走向下一张担架。

治疗师是把医术做到极致的人。他们的手段未必来自法术：一副药剂、一套推拿、一卷绷带，同样能把人从鬼门关前拉回来。同样的药，在他们手里效力更强；同样的伤，在他们手里好得更快。刀斧贴到眼前时他们的手不会抖；战友麻痹倒地、力竭透支，经他们调理还能站起来再战。冒险队伍可以不养闲人，但没有人会把治疗师叫作闲人。

他们也许在杀敌上不算出众，但每一场能活着打完的仗，都有他们一份。

先决条件：医疗+5

每等级15点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+0（0）|快速治疗|
|2|+1（1）|治疗提升|
|3|+0（1）|复原|
|4|+1（2）|属性值提升，振奋|
|5|+0（2）|生命回流|

**快速治疗（Ex）：** 你使用恢复生命值的法术、类法术能力或治疗物品时，不会引发借机攻击。

**治疗提升（Su）：** 当你释放法术环位或引发类法术能力（含映射了法术环位的治疗物品）恢复一名生物的生命值时，该次治疗额外恢复等同于2×（法术环阶+你的治疗师等级）的生命值。赋予临时生命值的效果不视为治疗，不触发本特性。

**复原（Su）：** 你花费2AP触碰一名生物，你直接解除其耳聋、目盲、中毒、石化、麻痹或震慑状态。你可以使用这个特性的次数等同于你的治疗师一半等级，完成一次短休或长休后恢复全部次数。

**振奋（Su）：** 每长休一次，花费10分钟你以纯熟的理疗手法舒缓其透支的身体：目标的力竭等级降低一半。当你使一个濒死生物脱离濒死时，移除其一层力竭。

**生命回流（Su）：** 当你以法术、类法术能力或治疗物品恢复其他生物的生命值时，流淌的生命之力也润泽你自己：你获得等同于该次回复量一半的临时生命值（若一次效果同时治疗多名生物，以其中最高的单体回复量计算）。
