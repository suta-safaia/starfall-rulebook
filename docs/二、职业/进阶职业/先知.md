# 先知

谈判桌上，贵族的使者刚刚展开卷轴，老先知就抬手打断了他："不必念了。第三段关于关税的部分，你们国王今晨已经改了主意——使团鞋底的红泥来自北港，你们提前收到了飞鸽。"使者脸色煞白。先知啜了口茶。他没有读心，也不通神谕，他只是早已看见了今晚国王书房里的那场会议，以及会议记录里引用的今日之言。

先知是窥见命运丝线的觉醒者。他们不借助任何法术——未来不是被预言的，而是被看见的，如同看见桌上的一杯茶。先知的感知敏锐到刺穿了时间的帷幕：刺客的刀尚未出鞘，他们已侧身让开；灾祸的征兆尚未浮现，他们已备好退路。与先知为敌是一种令人绝望的体验：你的每一步棋，都落在他的棋谱里。

世上没有意外。只有看得不够远的人。

先决条件：知识（奥秘）+6

每等级12点生命值

|等级/特性|基础攻击加值|特性|
| :---------: | :------------: | :------------: |
|1|+0（0）|预景|
|2|+1（1）|危机预感|
|3|+0（1）|命运重写|
|4|+1（2）|属性值提升，趋吉避凶|
|5|+0（2）|既定未来|

**预景（Su）：** 每次长休结束时，未来的碎片涌入你的梦境：掷2个d20并记录结果。当30尺内一名你能看见的生物（包括你自己）将要进行攻击检定、豁免检定或属性检定时，你可以以一个反应动作，用一条预景记录替换该次掷骰（必须在该次掷骰之前宣告）。未被使用的预景在你的下次长休时消散。你同一时间最多持有2条预景。

**危机预感（Su）：** 灾祸在发生之前就已向你示警。你的先攻检定获得等同于你智力调整值的加值。

**命运重写（Su）：** 当你被攻击命中、或豁免检定失败而将要承受伤害或其他有害影响时，你看见的其实只是短暂的未来——而它尚有改写的余地：你投掷1d3+1，将结果加在本次攻击所针对的你的AC、或本次豁免检定的结果上，若这足以改变结局，则按新的结果结算。你可以使用这个特性的次数等同于你的先知等级，完成一次长休后恢复全部次数。

**趋吉避凶（Su）：** 每完成一次长休，你获得2次施展占卜术的机会：以此方式施展时无需任何法术成分，且成功率恒为100%。

**既定未来（Su）：** 你对未来的掌控臻于完善：你使用预景时，不再需要在掷骰之前宣告，可以在该次掷骰的结果出现之后，再决定是否以预景记录替换它。
