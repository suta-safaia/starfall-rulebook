# 野蛮人

箭是从他背后的树林里射出来的。没有人看见弓手——除了他。他在箭矢离弦前就已经侧过了身，说不清是听见了弦响，还是后颈的汗毛先竖了起来。他没有冲向箭来的方向，而是斜插向侧翼——箭雨只是钩子，真正的杀招在左边那片蕨丛后面。巨斧劈开蕨丛时，他胸腔里那团火也被点燃了。吼声压过了整条山谷的风。离他最近的伏击者拼尽全力把长矛刺出——枪尖递到胸前，那人只是侧目瞥了一眼，单手折断矛杆，另一只手里的巨斧已经抡圆了砸了下去。那一刻伏击者们才明白：陷阱没有失败，是他们被引进了这头发怒的野兽的领地。有人转身就逃，有人双腿一软跪在原地。

野蛮人是战场上的狂战士。怒火点燃时，他们进入忘我的狂暴：力量暴涨，战意如沸，寻常兵刃落在身上阻不住他们的脚步，只会让他们更加暴怒。而真正令敌人胆寒的，是那股扑面而来的战意——野蛮人冲锋时，身经百战的老兵也会后退半步，因为所有人都认得那种眼神：没有恐惧，没有迟疑，只有要把你撕碎的笃定。但若因此把野蛮人当作单纯的莽夫，就大错特错了：他们拥有野兽般敏锐的感知，危险临近时先觉先避；拥有千锤百炼的战场直觉，能在刀光箭雨中找到唯一安全的路径，哪怕被团团围住，也不曾真正失去防备。怒气是他们的力量，直觉是他们的眼睛。

怒火会熄灭，而幸存者余生都会在梦里听见那声战吼。

生命值：每等级25点

野蛮人武器训练：你为以下武器选择 专攻武器专长或者专精武器专长
* 三种简易武器
* 三种军用武器 或(b)一种军用武器和一种异种武器

野蛮人护甲训练：你视为拥有 擅长盔甲(轻型)、擅长盔甲(中型)、擅长盾牌 专长。

**快速移动（野蛮人）：** 野蛮人在未着装重甲且没有重载时获得该增益，他的移动速度增加10尺。

**狂暴：** 野蛮人可以使用2 AP进入狂暴，在狂暴中野蛮人获得以下效果：

- 野蛮人的力量和体质获得+4加值，并获得3 / 每野蛮人等级的临时最大生命值，并恢复同等的生命值。
- 野蛮人在对抗感知豁免和魅力豁免时获得+2士气加值
- 野蛮人无法在狂暴中使用法术和维持法术的专注（仍然可以通过命令语启动魔法物品）
- 野蛮人的AC获得-2减值

狂暴最多持续1分钟，在以下场景狂暴将会提前结束：

- 野蛮人陷入昏迷状态
- 主动以一个即时动作停止狂暴
- 在上个回合和这个回合均未对任何生物造成伤害，在回合结束时，除非你使用2 AP主动维持狂暴，否则狂暴结束

在狂暴结束后，你获得1级力竭

**坚韧狂暴：** 当你在狂暴状态时，你获得挥砍、穿刺、钝击的伤害抗力，数值等于你野蛮人等级的一半。

**大狂暴：** 在狂暴中，野蛮人的力量和体质加值变为+6，对抗豁免和魅力豁免的士气加值变为+3。临时最大生命值变为5 / 每野蛮人等级。

**不倦狂暴：** 野蛮人在结束狂暴时不再获得力竭状态，且野蛮人在狂暴状态时不会受已有的力竭状态影响。

**不屈意志：** 当野蛮人在进行豁免检定失败时，野蛮人可以消耗一次特性使用次数重骰本次豁免，你必须接受重骰之后的结果

**强力狂暴：** 在狂暴中，野蛮人的力量和体质加值变为+8，对抗豁免和魅力豁免的士气加值变为+4。临时最大生命值变为8 / 每野蛮人等级。
