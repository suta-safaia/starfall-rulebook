# 二环艺术

# 震音波

*二环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 30尺

**演艺成分：** 歌唱、乐器

**持续时间：** 立即

**法术抗力：** 可

你骤然拔高嗓音，一道肉眼可见的声波如重锤般轰向目标。30尺内一名生物受到1d10/每吟游诗人等级（最高8d10）点音波伤害，强韧豁免成功伤害减半。豁免失败的生物被声波击退10尺。

# 裂甲之音

*二环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 30尺

**演艺成分：** 歌唱、乐器

**持续时间：** 立即（AC减值持续1分钟）

**法术抗力：** 可

你唱出一串精准的颤音，声波顺着甲片的接缝与盾牌的铆钉钻入，震得金属嗡嗡作响。30尺内一名生物受到1d10/每吟游诗人等级（最高8d10）点音波伤害，强韧豁免成功伤害减半。若该生物穿着盔甲、持用盾牌或为构装生物，且豁免失败，其护甲因共振而松动，AC额外承受-2减值，持续1分钟。

# 共鸣击

*二环 变奏曲*

**演艺时间：** 2 AP

**演艺距离：** 自身

**演艺成分：** 歌唱、乐器

**持续时间：** 专注

**法术抗力：** 无

你在演艺的旋律之下叠唱出一段短促的副歌，让你的武器随节拍嗡鸣。维持此变奏曲期间，你的武器攻击命中时额外造成1d6点音波伤害。

# 风暴吟唱

*二环 进行曲*

**演艺时间：** 2 AP

**演艺距离：** 自身（20尺半径）

**演艺成分：** 歌唱

**持续时间：** 专注

**法术抗力：** 可

你的歌声引动气流，呼啸的音浪以你为中心盘旋成一场声音的风暴，且愈演愈烈。第1轮，身处20尺半径内的敌人受到1d6点音波伤害；此后每完整维持1轮，伤害提升1d6，最高8d6。每一轮在你的回合结束时结算伤害，受影响生物可以进行反射豁免，成功则伤害减半。

# 终曲强音

*二环 谢幕曲*

**演艺时间：** 2 AP

**演艺距离：** 自身（40尺锥形）

**演艺成分：** 歌唱、乐器

**持续时间：** 立即

**法术抗力：** 可

只有当你正在维持演艺时才能使用。你将当前演艺推向最后一个爆裂的强音，旋律轰然收束，余波横扫全场。中断当前演艺：40尺锥形范围内的生物受到1d6/每吟游诗人等级（最高8d6）点音波伤害，强韧豁免成功伤害减半。豁免失败的生物震慑1轮，并被击退10尺。被中断的演艺立即结束。

**演艺成分：** 歌唱、乐器

你压低嗓音唱出黏稠的低音，声波渗入地面，使土地变得如泥沼般滞涩难行。选择60尺内一点，以其为中心的20尺半径区域对你的敌人视为困难地形，持续到你主动停止或失去专注为止。此效果不影响你与盟友。

**演艺成分：** 歌唱

**法术抗力：** 无

你与盟友的歌声交织成严丝合缝的和声，如穹顶般笼罩整支队伍。需要至少1名盟友与你共同演绎（最低参与人数为2，含你本人），所有参与者均须维持专注。持续期间，30尺半径内的所有盟友全部豁免检定获得+2加值。保持专注的参与人数低于2人时，此协作曲立即结束。

# 寻物歌谣

*二环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 1里

**演艺成分：** 歌唱

**持续时间：** 专注、10分钟

**法术抗力：** 无

你轻声唱起一支悠扬的谣曲，让歌声替你向四面八方探问。想着一件你熟知的物品：只要它位于你1里之内，你便能感知到它所在的方向与大致距离。此效果最多维持10分钟，物品移动时你能实时感知其方位变化。若物品处于阻碍预言效果的防护之下，歌谣无法寻得它。

# 安睡摇篮曲

*二环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 30尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

你唱起一支轻柔绵长的摇篮曲，音符如温暖的毯子般裹住听者，眼皮止不住地往下坠。30尺内至多4名由你选择的生物须进行意志豁免（自愿的盟友可以放弃豁免）：失败者昏昏欲睡——若当前并非战斗状态，它直接安然入睡；若处于战斗中，它恍惚1轮。入睡的生物会因受到伤害或他人以动作摇晃而醒来。对自愿聆听的盟友，这支曲子能助其在休息时快速入眠。
