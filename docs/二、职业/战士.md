# 战士

老卫兵雷欧把断成两截的长矛随手丢掉，从尸体旁捡起一把战斧。他不记得自己什么时候学过这把斧头的用法——不，他学过，在二十年的行伍生涯里，他学过每一种兵器的用法。斧刃劈开第一个冲进来的敌人的胸甲，他侧身让过长枪，反手用斧背砸碎另一人的膝盖，顺势拔出腰间短剑掷出，钉进远处弓手的咽喉。没有法术的光辉，没有血脉的轰鸣，只有肌肉、钢铁和千锤百炼的本能。

战士是最基础的战斗职业，也是冒险者中人数最多的职业。他们既非天生超凡，也无须祈求神恩——战士的力量来自千百次挥砍中磨砺出的技艺。战士是当之无愧的武器大师：任何武器在他们手中都能发挥全部威力，从匕首到巨剑，从短弓到重弩，来者不拒。战士的战斗技巧精妙入微，他们掌握的战技远多于其他职业，能自由组合出属于自己的战法——你可以成为坚不可摧的盾卫、百步穿杨的神射手，或是双剑如风的杀手。而在最关键的时刻，战士能爆发出惊人的力量，在一瞬之间倾泻出远超常理的行动，于胜负未分之际一锤定音。

战士的起点或许平凡，但每一条传奇的冒险之路上，几乎都站着一位战士。



生命值：每等级20点

战士武器训练：你为以下武器选择 专攻武器专长或者专精武器专长
* 四种简易武器
* (a)四种军用武器 或(b)两种军用武器和一种异种武器

战士护甲训练：你视为拥有 擅长盔甲(轻型)、擅长盔甲(中型)、擅长盔甲(重型)、擅长盾牌、擅长塔盾 专长。

**战士奖励专长:** 你可以从战士奖励专长种挑选一个专长习得。

**动作如潮:** 你消耗2AP，使你的AP点恢复到上限，你只能使用你的这个能力一次， 直到你完成了一次短休.

**狂潮不息:** 你可以在短休之间使用更多的动作如潮，但在短休期间你第二次使用动作如潮开始，你回合结束时立即获得一层力竭。你一回合仍然只能使用一次动作如潮。
