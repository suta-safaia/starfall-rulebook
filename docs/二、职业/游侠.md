# 游侠

他蹲下身，指尖拂过被踩断的蕨叶。三天，最多三天——这些人和他追踪的目标接触过。身后的巨狼低吼一声，他抬手示意安静。这片森林的每一条路都刻在他脑子里：哪片沼泽能陷住重甲，哪条山脊在正午有最好的视野，猎物会往哪里逃，伏击该设在哪里。至于目标本身——兽人劫掠者，他研究了半辈子的对手——他知道他们如何扎营、如何放哨、如何在恐惧时犯错。他抽出双刀，刀身在林间的光斑里只闪了一下。今夜，森林会自己讨回公道。

游侠是为自然效力的战士。他们有着不输战士的武艺与坚韧，却把刀剑献给了荒野：抵御摧残森林的劫掠者，猎杀威胁生灵的凶兽，指引迷途的旅人穿越绝地。长年的猎守生涯，让游侠对一切都有自己独到的见解：面对宿敌，他们熟知其习性与弱点，追踪、交涉与猎杀都事半功倍；踏上熟悉的土地，山川草木皆为其耳目，他们能察觉最细微的异样。而在战斗风格上，游侠分道扬镳：有人执双刀近身搏杀，攻势如疾风骤雨；有人执长弓远程狙杀，箭箭夺命；也有人与野兽结伴，同忠实的动物伙伴并肩狩猎。森林不言语，但游侠听得懂。

他们是荒野的猎手，也是荒野的盾。

**宿敌：** 1级时，游侠可以从表：游侠宿敌中选择一类生物作为自己的宿敌。在对此类生物使用欺瞒、恐吓，察觉、洞察、及生存检定时游侠具有+2加值。同时在对此类生物的武器伤害检定上也有额外伤害。随着等级提升，游侠可以额外选择多个不同的宿敌。

**野性认同：** 游侠在对主人是友方阵营或者无主的野兽进行驯兽检定时获得+4加值。

**动物伙伴：** 游侠获得奖励专长：动物伙伴（无视前置条件）。

**偏好地形：** 游侠可以从表：游侠偏好地形中选择两类地形作为自己的偏好地形。在此地形中，游侠的察觉、生存、察觉、自然、隐匿检定级武器攻击检定获得额外加值。

**战斗流派：** 游侠可以从双武器战斗、箭术、驯兽师中选择一个流派。游侠在无着甲或者着装轻甲时才能从战斗流派中收益。

- 箭术：获得奖励专长：快速射击（无视前置条件）。
- 双武器战斗：获得奖励专长：双武器攻击（无视前置条件）。
- 驯兽师：你获得奖励专长：进阶动物伙伴（无视前置条件），并视为已额外选择了一次专长「动物伙伴」（战斗中可同时让两只伙伴出场）。

**穿林：** 游侠在穿越非魔法的灌木丛类似的地形时，不会受到伤害以及困难地形的影响。

**增强战斗流派：** 

- 箭术：获得奖励专长：多重射击（无视前置条件）。
- 双武器战斗：获得奖励专长：进阶双武器攻击（无视前置条件）。
- 驯兽师：你的动物伙伴也能从你的宿敌和偏好地形中受益。

**增强偏好地形：** 当你在一个不是你偏好地形的地形上进行了一次长休时，你可以选择在长休期间的行动选择熟悉地形，该地形将临时变为你的偏好地形，直到你下次长休结束。

**精通战斗流派：**

- 箭术：获得奖励专长：精准射击（无视前置条件）。
- 双武器战斗：获得奖励专长：高等双武器攻击（无视前置条件）。
- 驯兽师：你视为再额外选择了一次专长「动物伙伴」（战斗中可同时让三只伙伴出场），并且你的动物伙伴获得额外进阶技能。

**自然伪装：** 游侠可以在任何自然地形下使用躲藏技能，即便该地形没有提供遮蔽物

**宿敌标记：** 你可以指定任一你所见过的独特生物为你的宿敌，持续到长休结束。你能使用这个能力一次直到你完成了一次长休。

**增强自然伪装：** 即便游侠被注意到，也能在满足自然伪装的前提下进行躲藏。
