# 术士

他小时候烧掉过半个马厩——不是故意的，只是那天的怒火恰好有了自己的形状。血脉里的东西在他出生时就在了：或许是巨龙在族谱某页留下的吻，或许是先祖与某位高等存在订下的契约，无人说得清。它不需要他读书，不需要他祈祷，它只在他心跳加速时苏醒，顺着脊椎爬上来，在指尖噼啪作响。导师只教过他一件事，也是唯一重要的事："别想着堵住它，孩子，学会给它让路。"多年后他终于明白：他的魔力不是武器，是潮水——他修不了堤坝，只能学游泳。

术士是天赋与修习共同造就的奥术施法者。奥术天赋是每个施法者的前提，而术士的天赋往往格外惊人：血脉中的传承或高等生物的赐福，让他们体内沉睡着汹涌的先天魔力，施法储备深厚，战斗中可以接连不断地施展法术。但天赋只是起点——术士同样需要钻研奥术学识，只是他们求学的目的有着鲜明的倾向：不是为了积累更多法术，而是为了掌控自己的魔力。沸腾的力量若不加驾驭，先伤到的往往是自己；因此术士精研原理、锤炼意志，学会在魔力奔涌时握住缰绳，让每一分力量都如臂使指。术士掌握的法术未必广博，但每一个都被反复淬炼，早已成为身体的一部分。

力量早已在血脉之中，他们要做的，是学会驾驭它。

术士*的戏法法术位不限，戏法栏数字仅代表术士升级能获得的戏法数量*



**施法（术士）：** 术士为自发施法者，施法主属性为魅力，与法师、神官等记忆施法者不同，术士无需准备就可以使用任意未使用的法术位施展他任何已知的术士法术。

术士的已知法术比较稀少，术士在1级时获得6个戏法和2个已知法术，在每次升级时，术士只能选择1个法术加入自己的已知法术，且每次升级时，术士可以将一个已知法术替换为另一个已知法术。
