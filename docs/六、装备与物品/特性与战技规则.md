# 特性与战技规则

> 本文件是武器特性与战技的通用规则。各武器文件中收录的战技文本为该武器的**定制版本**，与本文件冲突时以武器文件为准。

---

## 一、特性词条

武器只有「特性」一层：通用机制词条，见下表。**没列在这里的特性都不存在。**

| 词条 | 规则效果 |
|---|---|
| **轻型** | 轻便的单手武器。进行双武器战斗时，主手和副手中每有一把轻型武器，主手和副手的攻击检定都 +2（详见《额外攻击和特殊攻击》）。 |
| **双手** | 必须双手持用。造成伤害时，属性调整值按 1.5 倍计入。 |
| **重型** | 沉重的大型武器，必定为双手武器。造成伤害时，额外将力量调整值的一半加入伤害（即在双手的 1.5 倍基础上，合计按 2 倍计入）。 |
| **两用** | 可以单手拿也可以双手拿的武器。近战武器双手持用时，按双手武器规则结算伤害；火器单手持用时攻击检定 −2，双手持用则不受此减值。 |
| **投掷** | 可以当作远程武器投出，攻击检定按远程武器处理。 |
| **回力** | 投掷出手后会在回合结束时自动飞回持有者手中，此时攻击者需要有空着的一只手去接住，否则武器掉落在脚下。 |
| **长型** | 近战攻击范围扩大，默认扩大 5 尺；有标注的按标注距离。仍可攻击相邻目标。 |
| **触及** | 特殊的长型：攻击范围扩大，但无法攻击自己 5 尺内的敌人。 |
| **灵巧** | 攻击检定与伤害可使用敏捷调整值代替力量调整值。 |
| **装填** | 需要花费 2AP 才能为该武器换弹。 |
| **装填(整轮)** | 装填为整轮动作。 |
| **装填(弹匣)** | 装填的是弹匣。弹匣是独立物品，其中事先存放了多发弹药，按压弹顺序依次射出。 |
| **双头** | 可以用这一把武器进行双武器战斗，而不受其他限制；哪一端是主手端、哪一端是副手端，以及各端的属性，由武器条目事先规定。 |
| **摔绊** | 擅长摔绊的武器。用它摔绊被反摔绊时，可以丢下武器来防止自己被摔绊。 |
| **卸除** | 用它卸除武器被反卸除时，可以丢下武器来防止自己被反卸除。 |
| **武僧** | 武僧也可熟练使用的武器，可用于武僧需要"武僧武器"的能力。 |
| **劲弓** | 造成伤害时可将力量调整值加入伤害，力量为负时同样承受减值。 |
| **回摆** | 攻击未命中时，这次攻击不计入多重攻击减值。 |
| **水下战斗** | 在水下使用此武器攻击不受水下战斗减值。 |
| **隐蔽** | 藏匿此武器的巧手检定获得 +5 加值，可以进行当面突袭。 |
| **缠手** | 可以绑在手臂上，不占用手。 |
| **变形** | 可以在两种形态之间切换，具体变形规则参照武器规则。 |
| **双管** | 拥有两根须分别装填的独立枪管。进行一次攻击时可同时击发双管：伤害骰翻倍，且本次攻击的故障值 +2。 |
| **散射** | 弹丸呈散布射出，伤害随距离衰减：首个射程增量内全额，此后每多一个射程增量伤害 −1d6（最低 1d6）。 |
| **贯甲** | 弩机的强劲击发可以贯穿护甲：在首个射程增量内，攻击按**接触攻击**结算（目标 AC 失去盔甲加值）。 |
| **故障(X)** | 火器特性。攻击检定的天然骰 ≤ X 时，枪械**故障**（X=1 即仅大失败故障）：本次攻击自动失败（弹药照常消耗，故障是枪的状态），武器进入故障状态。清除故障 = 整轮动作（引发借机）。故障的武器仍可强行击发：未再掷出故障则正常结算；若再次故障则**炸膛**：该武器在本次战斗中无法使用（需战斗外修理），且持有者受到该武器伤害骰 ×4 的伤害。没有此特性的火器不会故障（天然骰 1 仅为普通失手）。 |
| **粗制** | 黑作坊仿造的土制火器。没有改造槽，无法接受任何枪械改造；只能使用土制弹药，无法使用标准弹药与任何特殊弹种。 |

## 二、战技通用规则

战技是武器使用的高阶技巧，与职业无关。

- **习得前提**：你必须拥有某武器的「专攻武器」专长，才能使用该武器的战技。
- **使用次数**：战技条目下以斜体标注次数。
  - *1（3）次 / 短休*：拥有「专攻武器」专长时每次短休可使用 1 次；拥有「高级武器专攻」专长时每次短休可使用 3 次。
  - *无使用次数限制*：不限次数，满足条件即可发动；仍算发动，受每回合一次的限制。
  - *被动*：持续生效的修正，不算发动，不受每回合一次的限制。
- **每回合限一次**：**同一件武器每回合只能发动一次战技**（双持两件武器时分别计算）。标注 *无使用次数限制* 的战技同样受限；*被动* 不是发动，不在此列。
- **发动方式**：多数战技是**替换战技**——当你拥有额外攻击时，用其中一次攻击替换发动（替换规则见《动作资源》「替换战技」），条目不再标注 AP 消耗；标注了 AP/RP 消耗的战技是有独立消耗的动作。
- **触发语**：以「武器命中时」开头的战技是攻击的附带效果：照常进行攻击检定与伤害结算，命中时追加战技效果。
- **借机攻击**：攻击附带类战技不额外引发借机攻击（远程武器的攻击本身仍照常引发借机）。
- **文本优先**：武器文件中的战技文本为该武器的定制版本；与本名录不一致时，以武器文件为准。

## 三、战技名录（通用基准）

### 通用近战战技

**破甲**：武器命中时，目标的盔甲加值 −2，直到你的下个回合结束。（部分重型武器为 −3，以武器条目为准）

**弱化打击**：武器命中时，目标直到你的下个回合开始前，所有攻击检定 −2。

**连击**（无使用次数限制）：当你进行由 BAB 带来的额外攻击时，若你本回合上次的武器攻击使用的是该武器并且命中，本次攻击的攻击检定 +5。

**精准攻击**：你使用这把武器精准攻击敌人的弱点，本次攻击视作接触攻击。

**强化冲锋**（保留）：提升冲锋系专长的伤害，见专长。

**华舞**：你对你武器威胁范围的**内圈**——即武器能威胁到的最近一圈（普通武器为身边 5 尺；触及武器为其触及距离，如中型生物持巨镰为 10 尺，大型生物持巨镰威胁 10~15 尺时内圈为 10 尺）——内的所有生物分别进行一次攻击检定。（部分武器的所有攻击应用相同的攻击检定，以武器条目为准）

**顺劈**：你对目标以及目标周围 5 尺内的至多 2 个目标分别进行一次攻击检定；本次攻击不能将属性调整值加入武器伤害。

**迅击**：本次攻击改为以这把武器连续进行两次攻击检定。

**冲撞打击**：武器命中时，你同时对目标发起一次冲撞：照常进行冲撞的对抗检定，但这次冲撞不会引发借机攻击。

**摔绊打击**：武器命中时，你同时对目标发起一次摔绊：照常进行摔绊的对抗检定，但这次摔绊不会引发借机攻击。

**流血打击**：武器命中时，敌人被附加同等武器伤害骰一半的出血（部分武器为全额，以武器条目为准；出血状态的规则另见状态章节）。

**钩拉**：武器命中时，将目标向你拉近至多 10 尺。多数武器的攻击距离为 10 尺，实际通常只能拉近 5 尺。强制移动会触发借机攻击。

**退步斩**（无使用次数限制）：在攻击后可以免费附带一次径直远离目标的五尺快步。

**反冲锋**（1 RP）：当敌人从你的威胁区外进入威胁区时，你可以发动一次借机攻击；这次借机攻击造成双倍伤害。该触发是反冲锋提供的特例。

**眩晕打击**：武器命中时，对敌人造成 1d4 回合目眩。

**格挡**（1 RP）：在面临一次武器攻击时，以反应格挡攻击，对于这次攻击你获得盔甲加值（单手武器 +2，双手武器与盾牌 +3）。反应类防御在攻击检定结果公布后、伤害结算前决定是否使用。

**棒击大地**（大槌）：本次攻击附加一次溅射：目标和目标周围 5 尺的目标都必须进行力量豁免（DC = 10 + 你的最高 BAB）。失败受到 2d6 钝击伤害并倒地，成功则伤害减半且不倒地。

**侵扰**（无使用次数限制，弯刃大刀）：当你用这把武器命中一个生物并对其造成伤害时，直到你的下一回合结束前，你对该生物的下一次武器攻击检定 +2。

**追击**（弯刃大刀）：当你用这把武器命中一个生物并对其造成伤害时，若你仍有额外攻击的次数，你的额外攻击只需花费 1AP；你可以重复该动作直到用尽攻击次数或追击未命中。

### 远程战技

**瞄准**：若你本回合没有移动过，你的下一次远程攻击造成的伤害翻倍，并且本回合无法再移动。

**狙击**：在突袭轮、躲藏状态下使用：本次攻击若有因超出射程的射程减值，可以最多抵消 −4，且命中时固定视为暴击。

**腿筋射击**：武器命中时，目标的所有速度 −10 尺，直到目标的下个回合结束。

**灵巧步伐**：你声明一个可以看见的敌人，本回合你拿着这把武器时移动不会招致其借机攻击。

**扇形扫射**（装填(弹匣)的远程武器）：你向正前方倾泻弹药：前方 30 尺锥形内的所有生物须进行敏捷豁免（DC = 10 + 你的最高 BAB），失败受到等同于命中的伤害，成功则减半。消耗弹匣内全部弹药。

**滑步装填**（火器）：为火器执行装填动作时，你可以在装填之前或之后免费移动至多 10 尺；这次移动照常引发借机攻击。

**火力压制**（双管或装填(弹匣)的远程武器，2 AP，引发借机）：消耗 3 发弹药，指定射程内一名你能看见的目标；直到你的下一轮开始，该目标的攻击检定 −2。本次压制不造成伤害、无需攻击检定；目标处于全掩蔽时不受影响。

**击退/击倒**（霰弹枪）：武器命中时，你同时与目标进行一次力量对抗：若你胜出，目标被击退 5 尺或倒地（由你选择）。
