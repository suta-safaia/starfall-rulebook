# 弹药

> 弓弩与火器的消耗品。特殊弹药（霰弹、穿甲弹、龙息弹）见《特殊弹药》文件夹。

## 通用规则

- 装填弹药 = 2AP（引发借机）；重弩装填 = 整轮动作；弹匣武器 2AP 更换整个弹匣。
- 战斗结束后可回收一半射失/射出的普通箭矢（向下取整），魔法弹药与命中的箭矢不可回收。
- 吹箭筒的吹箭、手里剑视作弹药，命中或落空均消耗。
- 火器无法在水下击发。

- **标准弹药**：弹丸、发射药与底火装在同一枚弹壳里的定装弹，是所有制式火器的通用弹药。装填快捷，但每一发都是矮人管制技术的价格。
- **土制弹药**：散装火药与自制弹丸，仅土制火器可用（粗制火器也无法使用标准弹药与任何特殊弹种，见粗制特性）。
- **转轮弹巢 / 步枪弹匣**：预先装满的备用弹巢/弹匣，战场上直接整体更换，比逐发装填快得多。
