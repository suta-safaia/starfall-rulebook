# 长弓

长弓是弓身与人等高的强弓，需要相当的膂力才能拉开。射程远、威力大，是军用弓的标准装备，但在坐骑上使用受到限制。

| 重击 | 伤害 | 射程 | 重量 | 价格 | 特性 |

## 战技

### 瞄准

*1（3）次 / 短休*

若你本回合没有移动过，你的下一次远程攻击造成的伤害翻倍，并且本回合无法再移动。

---

### 狙击

*1（3）次 / 短休*

在突袭轮、躲藏状态下使用：本次攻击的若有因超出射程的射程减值，可以最多抵消-4的效果，且命中时固定视为暴击。
