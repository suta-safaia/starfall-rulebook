# 复合长弓

复合长弓是以复合工艺制成的大弓，弓梢反曲、蓄力极强。开弓需要力量与技巧，射程与威力均为弓类之最。

## 战技

### 瞄准

*1（3）次 / 短休*

若你本回合没有移动过，你的下一次远程攻击造成的伤害翻倍，并且本回合无法再移动。

---

### 狙击

*1（3）次 / 短休*

在突袭轮、躲藏状态下使用：本次攻击的若有因超出射程的射程减值，可以最多抵消-4的效果，且命中时固定视为暴击。
