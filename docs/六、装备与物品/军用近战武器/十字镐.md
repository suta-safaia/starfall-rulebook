# 十字镐

十字镐是装有尖锐镐头的战镐。以高举下凿的方式使用，力量集中于镐尖一点，适于穿透盔甲。

## 战技

### 流血打击

*1（3）次 / 短休*

武器命中时，敌人被附加同等武器伤害骰的出血。

---

### 精准攻击

*1（3）次 / 短休*

你使用这把武器精准攻击敌人的弱点，本次攻击视作接触攻击。
