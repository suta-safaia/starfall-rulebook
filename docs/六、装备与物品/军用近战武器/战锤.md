# 战锤

战锤一端为平头，一端为尖喙，可单手或双手持用。平头用以碎骨，尖喙用以破甲。

## 战技

### 连击

*无使用次数限制*

当你进行由BAB带来的额外攻击时，若你本回合上次的武器攻击使用的是该武器并且攻击命中时，本次攻击的攻击检定 +5。

---

### 冲撞打击

*1（3）次 / 短休*

武器命中时，你同时对目标发起一次冲撞：照常进行冲撞的对抗检定，但这次冲撞不会引发借机攻击。
