# 巨斧

巨斧是斧面宽阔的双刃巨斧，必须双手持用。以全身力量挥动，劈砍威力为斧类之最。

## 战技

### 顺劈

*1（3）次 / 短休*

你对目标以及目标周围 5 尺内的至多 2 个目标分别进行一次攻击检定；本次攻击不能将属性调整值加入武器伤害。

---

### 破甲

*1（3）次 / 短休*

武器命中时，目标的盔甲加值 −3，直到你的下个回合结束。
