# 大砍刀

大砍刀是刃身宽长的双手砍刀，攻击范围较一般近战武器更远。以大幅度的挥砍扫击为主要使用方式。

## 战技

### 顺劈

*1（3）次 / 短休*

你对目标以及目标周围 5 尺内的至多 2 个目标分别进行一次攻击检定；本次攻击不能将属性调整值加入武器伤害。

---

### 华舞

*1（3）次 / 短休*

你对你武器威胁范围的内圈的所有生物分别进行一次攻击，这些攻击应用相同的攻击检定。
