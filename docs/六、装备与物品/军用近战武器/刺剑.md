# 刺剑

刺剑是剑身细长的决斗用剑，配有精巧的护手。几乎专用于突刺，以速度与技巧弥补力量的不足。

|---|---|---|---:|---:|---|

## 战技

### 格挡

*1（3）次 / 短休*

- **AP 消耗**：1 RP

在面临一次武器攻击时，以反应格挡攻击，对于这次攻击你获得+2盔甲加值。

---

### 精准攻击

*1（3）次 / 短休*

你使用这把武器精准攻击敌人的弱点，本次攻击视作接触攻击。
