# 鞭子

鞭子是一条数尺长的编革软鞭。它造不成像样的杀伤，但抽打、缠绕、勾拉样样都行，距离还比任何近战武器都远。

## 战技

### 摔绊打击

*1（3）次 / 短休*

武器命中时，你同时对目标发起一次摔绊：照常进行摔绊的对抗检定，但这次摔绊不会引发借机攻击。

---

### 缠鞭

*1（3）次 / 短休*

武器命中时可以不造成伤害，改为缠住目标：目标无法主动离开你的鞭子范围，直到其以整轮动作通过力量对抗挣脱，或你主动放开。缠绕期间你对该目标的摔绊与卸除对抗 +4。
