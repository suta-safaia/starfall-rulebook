# 野太刀

野太刀是全长五尺以上的大太刀，刀身修长微弯，可单手也可双手持用。以大幅度的斩击与借力打力的弹反见长。

## 战技

### 顺劈

*1（3）次 / 短休*

你对目标以及目标周围 5 尺内的至多 2 个目标分别进行一次攻击检定；本次攻击不能将属性调整值加入武器伤害。

---

### 弹反

*2（4）次 / 短休*

- **AP 消耗**：1 RP

当你被近战武器攻击命中时，挥刀弹开：你进行一次攻击检定，若结果不低于该次攻击的攻击检定结果，该次攻击无效；且若攻击者处于你的触及内，你立即对其进行一次武器攻击。
