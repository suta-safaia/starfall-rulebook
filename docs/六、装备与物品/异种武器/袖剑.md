# 袖剑

袖剑是藏于腕下护具中的细刃，平时完全隐蔽，出刃只在翻腕之间。它绑在手臂上，不占用手——持刀之手依然可以施法、攀爬或持握他物。它是刺客的武器：不用于对峙，用于了结。

## 战技

### 迅击

*1（3）次 / 短休*

### 背刺

*被动*
