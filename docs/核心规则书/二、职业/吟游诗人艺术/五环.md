# 五环艺术

# 女妖终嚎

*五环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 自身（60尺锥形）

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

你发出凄厉至极的终末哀嚎，无形的声波撕裂锥形区域内的血肉。你身前60尺锥形范围内的所有生物受到 `1d6 / 每吟游诗人等级（最高14d6）` 点音波伤害，强韧豁免成功伤害减半。豁免失败的生物震慑1轮。当前生命值低于其生命值上限一半的生物在此豁免上受到 -2 环境减值。

**演艺时间：** 2 AP

**持续时间：** 立即

**法术抗力：** 可

# 终末进行曲

*五环 进行曲*

**演艺时间：** 2 AP

**演艺距离：** 自身（至多30尺半径）

**演艺成分：** 歌唱、乐器

**持续时间：** 专注、至多14轮

**法术抗力：** 可

你奏响末世的乐章，声浪如涟漪般以你为中心逐轮扩张、愈加强烈。此艺术每完整维持1轮便提升一级，中断后再用须从第1级重算：

- 第1级：你周围10尺半径内的敌人受到1d6点音波伤害，反射豁免成功伤害减半。
- 每提升一级，半径扩大10尺、伤害增加1d6，至第3级达到30尺半径、3d6伤害。
- 自第4级起半径不再扩大，每提升一级伤害再增加1d6，最高至第14级的30尺半径、14d6伤害。

每轮你的回合开始时，当前覆盖范围内的敌人进行此豁免。你移动后，声浪仍以你为中心结算范围。

# 世界终曲

*五环 谢幕曲*

**演艺时间：** 2 AP

**演艺距离：** 自身（60尺半径）

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

只有当你正在维持演艺时才能使用。你中断当前演艺，将所有积攒的旋律推向世界终结般的轰鸣。你周围60尺半径内的所有敌人受到 `1d6 / 每吟游诗人等级（最高14d6）` 点音波伤害，反射豁免成功伤害减半。豁免失败的敌人倒地，并被朝远离你的方向击退20尺。你的盟友不受此艺术影响。被中断的演艺立即结束。

你唱起源自安眠之渊的摇篮曲，柔和的音波如雾般漫过指定区域。指定60尺内一点，其周围30尺半径内的所有敌人进行意志豁免，失败者陷入魔法沉睡，直至此艺术持续时间结束。沉睡的生物受到伤害时，或其盟友用一个动作摇晃唤醒它时，沉睡提前结束。对睡眠免疫的生物不受此效果影响。

# 万籁俱寂

*五环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 60尺（30尺半径）

**演艺成分：** 歌唱

**持续时间：** 专注、10分钟

**法术抗力：** 可

你唱出的最后一个音符被深渊吞没，指定区域陷入绝对静默。指定60尺内一点，其周围30尺半径内的一切生物与物体都无法发出声音，无法聆听任何声响，音波伤害无法在此区域内产生或传播。在此区域内施放需要声音成分的法术，或使用以歌唱为成分的艺术的生物，须先通过一次以你的艺术豁免DC为准的专注检定（d20+施法属性调整值），失败则该法术或艺术被打断且不生效。

# 英灵安魂曲

*五环 协作曲*

**演艺时间：** 10分钟

**演艺距离：** 30尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 无

你与至少1名盟友共同演绎这首迎魂归体的安魂曲（最低参与人数2人，含本人），所有参与者在演绎全程维持专注。完成后，唤回30尺内一名在上一轮内死亡的盟友：目标复活，生命值变为 `1d8 / 每吟游诗人等级（最高14d8）` 点。此曲能治愈目标死亡时承受的伤口与损耗，但无法治愈由不超过三环的法术、艺术或类似效应造成的肉体缺失（如断肢）；若尸体缺失关键部位，复活失败。复活的盟友因死而复生的冲击，在所有属性检定、攻击检定与豁免检定上承受-4罚值，直至完成一次长休。保持专注的参与人数低于2人时，此协作曲立即中断且不生效。

# 英灵战歌

*五环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 30尺

**演艺成分：** 歌唱、乐器

**持续时间：** 专注、1小时

**法术抗力：** 无

你的战歌回荡在往昔英雄的墓茔之上，一支半透明的英灵合唱队应召显现：视为一个中型虚体盟友，出现于30尺内你可见的一处未被占据空间。英灵合唱队的生命值等于你的吟游诗人等级×5，其攻击检定使用你的艺术攻击加值，命中造成2d8+你的魅力调整值点音波伤害。它在你的回合中依你的口头指令行动（无需动作），每回合可移动至多30尺并进行一次攻击。合唱队为虚体，对非魔法武器伤害具有抗性，可穿过生物与其它物体占据的空间，但不能在其中结束移动。合唱队生命值降至0时消散，此艺术随之结束。

# 传世留声

*五环 基础艺术*

**演艺时间：** 10分钟

**演艺距离：** 触及

**演艺成分：** 歌唱

**持续时间：** 直至被触发

**法术抗力：** 依封入效果

你将歌声封入一件你触及的小型物件，使其成为传世的留声之器。你选择其一：录制一段至多10分钟的声波信息（话语、乐曲或环境声），或将一个你已知的、不超过三环且持续时间为立即的艺术封入其中。封存时你设定触发条件（如特定词句、持握者的身份、特定时间等）；条件满足时，物件播放该段录音，或以你当前的吟游诗人等级与魅力调整值计算效果释放该艺术。封入的艺术释放后物件回归空寂，可再次以此艺术封存新内容；录音播放后仍保留，直至你以一个动作将其抹除。你同一时间维持的留声物件数量不超过你的熟练加值。

# 万物之声

*五环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 自身

**演艺成分：** 歌唱

**持续时间：** 1小时

**法术抗力：** 无

你轻声唱起创生之初的第一支歌，万物的声音在你耳中渐次分明。1小时内，你通晓一切语言（可听懂、言说与读写任何语言），并能与动物、植物、元素生物及无生命的物件交谈。动植物与元素生物能感知你的善意，通常愿意与你交流；物件只能讲述它们曾「听闻」或「见证」的事物，其认知以自身所处环境为限。此效果不强迫任何存在回答你。
