# 一环艺术

# 尖啸歌谣

*一环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 30尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

你骤然拔高嗓音，一声尖锐到几乎看不见的嘶鸣直刺目标的颅腔。对距离内一名生物造成 1d10 / 每吟游诗人等级（最高5d10）点音波伤害，目标可以进行一次强韧豁免，成功则伤害减半。

# 碎瓷高音

*一环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 30尺

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

你唱出一个不断攀升的颤音，停在物质共振的那个频率上。对距离内一名生物或一个物件造成 1d10 / 每吟游诗人等级（最高5d10）点音波伤害；若目标由晶体、玻璃或陶瓷构成（包括此类质地的生物），此伤害翻倍。目标生物可以进行一次强韧豁免，成功则伤害减半。此外，歌声可以震碎距离内无人看管的普通易碎物件（酒杯、瓷盘、窗玻璃等），由裁判裁定范围。

# 破阵鼓点

*一环 进行曲*

**演艺时间：** 2 AP

**演艺距离：** 自身（10尺半径）

**演艺成分：** 歌唱、乐器

**持续时间：** 专注、1分钟

**法术抗力：** 可

你击打出越来越急促的鼓点，声波一圈圈向四周碾去，敌人的阵型随之松动。每个你的回合开始时（自你开始演艺的当轮起算），半径内的敌对生物受到音波伤害并进行反射豁免，成功则伤害减半。第1轮造成1d6点伤害；此后演艺每完整维持1轮，伤害提高1d6，最高至5d6。中断后再次使用从1d6重新计算。

**演艺距离：** 自身（40尺锥形）

**演艺成分：** 歌唱

**持续时间：** 立即

**法术抗力：** 可

只有当你正在维持演艺时才能使用。你中断当前的演艺，将全部余韵推上最后一个撕裂长空的高音。锥形范围内的生物受到 1d6 / 每吟游诗人等级（最高5d6）点音波伤害，并需进行一次强韧豁免：豁免失败则伤害全额且陷入震慑，持续1轮；豁免成功则伤害减半。被中断的演艺立即结束。

# 唤鸟晨歌

*一环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 自身

**演艺成分：** 歌唱

**持续时间：** 10分钟

**法术抗力：** 无

你模仿清晨林间的鸟鸣，唱出一段只有鸟儿听得懂的邀请。歌声召来一只无害的小鸟，停留在你的肩头，为你服务10分钟。你可以让它飞往你指定的方向侦察，归来后以鸣叫与姿态向你描述沿途所见（规模、动静、大致危险）；也可以让它将一句不超过25字的口信带往1里内你指定的地点，复述给该处的指定对象。小鸟不为你作战，受到伤害或受到惊吓时立即飞离。

# 辨音回响

*一环 基础艺术*

**演艺时间：** 2 AP

**演艺距离：** 自身（30尺半径）

**演艺成分：** 歌唱

**持续时间：** 专注、1分钟

**法术抗力：** 无

你发出一串细密的颤音，再闭上眼，听世界把声音还给你。持续时间内，你通过回声定位感知半径内的地形、物件与生物的位置，无需依赖视觉：你能分辨墙壁、坑洞、障碍物的轮廓，以及生物的大致方位与体型，包括隐形或隐蔽的生物（你不会看见其细节，但能察觉"那里有东西"）。震耳欲聋的噪音区域会干扰回声，该处视为无法感知。
