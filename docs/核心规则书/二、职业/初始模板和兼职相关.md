# 初始模板和兼职相关

## 通用升级奖励

所有角色按**角色总等级**获得以下奖励，不按单个职业等级分别计算：

- **专长：** 每提升3级获得一个普通专长，即总等级3、6、9、12、15、18、21……级时各获得一个；选择时须满足该专长的先决条件。
- **属性值提升：** 每提升4级获得一次属性值提升，即总等级4、8、12、16、20、24……级时各获得一次。
- 同一等级同时满足两项时，两项均获得。兼职或进阶不会重置累计等级，也不重复计算奖励。
- 这些是角色的通用升级奖励，不再列入各职业的等级表。职业给予的**奖励专长**以及其他特定专长能力仍照常保留，与普通专长分别获得。
- 本次只统一获取节奏，不调整一次属性值提升的具体效果。
