# 钉头锤

钉头锤是锤头铸有尖钉的单手战锤。钉刺先于锤面接触目标，兼具钝击与穿刺的破坏力。

## 战技

### 破甲

*1（3）次 / 短休*

武器命中时，目标的盔甲加值 −2，直到你的下个回合结束。

---

### 流血打击

*1（3）次 / 短休*

武器命中时，敌人被附加同等武器伤害骰一半的出血。
