# 巨棒

巨棒是一根粗大的木棒，常在端部包铁或嵌钉，必须双手持用。它没有刃，杀伤全靠自重。

## 战技

### 顺劈

*1（3）次 / 短休*

你对目标以及目标周围 5 尺内的至多 2 个目标分别进行一次攻击检定；本次攻击不能将属性调整值加入武器伤害。

---

### 冲撞打击

*1（3）次 / 短休*

武器命中时，你同时对目标发起一次冲撞：照常进行冲撞的对抗检定，但这次冲撞不会引发借机攻击。
