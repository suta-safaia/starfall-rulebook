# 巨镰

巨镰是在长柄上横向安装巨大弯刃的长兵器。以长杆挥动镰刃扫割，攻击范围远，但无法攻击贴近的敌人。

## 战技

### 华舞

*1（3）次 / 短休*

你对你武器威胁范围的内圈的所有生物分别进行一次攻击，这些攻击应用相同的攻击检定。

---

### 流血打击

*1（3）次 / 短休*

武器命中时，敌人被附加同等武器伤害骰的出血。
