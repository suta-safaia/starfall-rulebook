# 半人马

半人马是奔行于草原与商路之上的种族：人的躯干自骏马的肩颈处昂然而起，四蹄踏地时，蹄声如鼓点滚过大地。他们天性高傲而豪爽，信守承诺到了近乎固执的地步——"半人马说到就到，字面意思"。商队、驿道与牧场上处处能见到他们的身影：驮着整队货物的运输手、比坐骑跑得还快的驿卒、绝不背弃誓言的流浪骑士。他们的寿命与人类相近，约八十年上下。半人马最不能忍受的事有两件：被关在没有窗的小房间里，以及有人当着他们的面谈论马肉料理——"我们和马完全不是一回事，谢谢。"

如果你想要塑造一个逐风而行的草原弓骑兵，一个把"上来吧，我驮你"视作此生最重誓言的高傲骑士——无论那个人已坐在你的鞍上，还是仍在旅途尽头等你——一个爽朗到有些吵闹、却永远赶在最前面的角色，你应该选择半人马。

**你也许……**

- 一站定就忍不住用蹄子刨地——这是半人马版的"抖腿"。
- 赛跑邀约从不拒绝，哪怕对方骑着马——尤其是对方骑着马。
- 一辈子只对寥寥几个人说过"上来吧"，每一个都记得清清楚楚。
- 背上常备着一副空置的鞍具——不是忘了卸，是还没等到那个值得的人。
- 进店之前先探头问一句："你们这儿有坡道吗？"

**其他人可能……**

- 觉得你开朗好相处，就是饭量有点大（草料也算饭）。
- 把你当成会自己走路的城墙——尤其是箭雨落下来的时候。
- 好奇被半人马驮着全速飞奔是什么感觉，但不太敢问出口。

**体貌描述**

半人马是四足的大型生物：下半身是完整的马躯，人的躯干自马颈根处向上生长，生有四腿双臂。自头顶算起全高230至270厘米，马身肩高150至180厘米，首尾长约300厘米。平原血脉者马身修长、鬃发飘逸，如逐风的骏马；山地血脉者体格紧凑、蹄宽而稳，毛色多为岩褐或青灰；圣誓血脉者毛色多为雪白或栗金，鬃发间编入缎带——每一根缎带都记着一桩立下的约定。他们的肌肉线条流畅而充满爆发力，长尾在奔跑时帮助保持平衡。半人马十八岁左右成年，寿命约八十岁。

**社会**

半人马大多以游牧、商队与驿传为生，他们的商队是大陆贸易的动脉。他们没有固定的国度，但每条主要商路上都有半人马的歇脚驿站——宽门、缓坡、最深的厩房，站内永远备着最好的草料和最烈的麦酒。半人马文化的核心是**誓约**：一诺既出，万山无阻，"误期"在他们的语言里几乎等同于耻辱。而诸誓约之中最神圣的一桩，是**骑主之誓**——半人马的背只属于他们认可的极少数人。允许一个人骑上自己的背，意味着把性命与荣誉一并托付给对方；反过来，陌生人哪怕伸手碰一下他们的鞍具，都足以让一场晚宴变成决斗。圣誓血脉的骑士把骑主之誓奉为骑士道的顶点：有人早已立誓，终生追随誓主左右——那往往就是并肩冒险的伙伴；也有人仍在旅途中寻找那个值得托付背脊的人，在找到之前，以守护每一段同路之缘为暂誓。但无论鞍上是否已坐着那个人，圣誓骑士的忠诚首先属于誓言本身。

### 半人马特性

- 体型：大型。
- 速度：步行25尺
- 天生语言：通用语与额外一门自选语言
- 天生武器：你的四蹄是天生武器，造成1d6钝击伤害。
- 四足之躯：你是四足生物。你在攀爬梯子与绳索时需要进行攀爬检定。

### 半人马血统

- 稳健步伐（1点数）：四足踏地的你在对抗倒地与强制移动的豁免上获得+2加值。碎石、荆棘与浅雪等粗糙地面不视为你的困难地形。
- 驮载（1点数）：你的负重翻倍；驮运一名体型不大于你的生物时，不需要其控制，毕竟你是智慧生物。
- 特殊加护（2点数）：星之加护 / 裂地奔腾：每日一次，本回合你的步行速度额外提升5尺，且移动不会招致借机攻击；每当一个敌人从你双蹄的威胁范围外进入威胁范围时，你都可以免费对其进行一次蹄击攻击。

**平原血脉**

逐风于辽阔草原的支系，鬃发如旗，耐力冠绝大陆。平原血脉的半人马是商队的脊梁：驮着两百斤的货翻越山口，当天傍晚还能笑着邀人摔跤。他们相信伙伴与道路——"马不欺路，人不欺心"，一支有平原血脉同行的商队，从未有过误期的记录。

- 平原血统（1点数）：你的力量+2，敏捷-2。
- 驰骋（1点数）：你的步行速度提升5尺。
- 草原射手（1点数）：你获得短弓、长弓、复合短弓、复合长弓中其中一个武器专攻专长，你使用长弓不会受到骑乘影响。

> 注：按骑乘规则，骑乘时使用长弓会承受减益；半人马自身不算骑乘，此处只是明确这一点。

**山地血脉**

栖居于丘陵与山地的支系，蹄稳如钉，身法如电。山地血脉的半人马能在近乎垂直的崖壁上三跳两跃便没了踪影，牧民说追他们不如去追风。陡峭崖径上的蹄印是他们的勋章——每一道，都值得在篝火边讲上三遍。

- 山地血统（1点数）：你的敏捷+2，体质-2。
- 山崖跳跃（1点数）：你的跳跃距离翻倍，且你在跳跃与攀爬的检定上获得+2加值。
- 奔踏（2点数）：当你的冲锋攻击命中并造成伤害时，该目标额外受到1d6钝击伤害，并需进行一次体质豁免（DC=8+你的力量调整值），失败则被推离10尺或倒地（由你选择）。

**圣誓血脉**

追奉古老骑士道的支系，毛色如晨雪初阳，鬃发间编入誓约缎带。圣誓血脉的半人马将骑主之誓奉为毕生的顶点：他们中有人早已立誓，终生追随誓主鞍前马后；也有人仍在旅途上寻找那个值得托付背脊的人，在找到之前，以守护同路人为暂誓。鞍上是否已坐着那个人并不重要——重要的是誓言本身从不蒙尘。

- 圣誓血统（1点数）：你的魅力+2，敏捷-2。
- 圣疗之手（1点数）：你每日可各一次施展疗伤术与强制决斗（如同同名法术），施法者等级等于你的职业等级总和，施法主属性为魅力。
- 誓卫（1点数）：你与你相邻的盟友在AC上获得+1神圣加值。
- 特殊加护（2点数）：星之加护 / 圣辉之躯：每日一次，你激发血脉中的圣辉，持续1分钟：你与30尺内的盟友在豁免检定上获得+2神圣加值，你的蹄击与持用武器视为魔法武器与善良武器。
