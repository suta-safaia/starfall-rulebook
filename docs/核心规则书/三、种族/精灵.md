# 精灵

### 精灵

精灵是自然与时光的宠儿。他们大约二十岁成年，此后漫长的岁月里，绝大多数精灵会长期保持着宛如少年或青年初期般的容貌——五官精致，体态轻盈，仿佛时间在他们身上流淌得格外缓慢。直到五百岁左右，岁月的痕迹才终于开始浮现，而他们最终会在六百至七百岁的某个时刻，如同睡着一般安静地离去。精灵对美有着近乎偏执的追求：从发丝的梳理、衣袍的褶皱，到言辞的韵律、举止的弧度，每一处细节都被精心打磨。在短命种族看来，这种交流方式简直低效得令人窒息——一句问候要绕七个弯子，一场告别可能要花上一整天。但精灵从不为此道歉，因为他们坚信：**粗糙是对生命最大的亵渎**。

如果你想要塑造一个优雅从容、品味高雅的冒险者，一个用漫长岁月打磨技艺与仪态的完美主义者，一个对粗鲁野蛮本能排斥、却愿意为真正美好的事物驻足千年的角色，你应该选择精灵。

**你也许……**

- 因为对方使用了一个不恰当的敬语而微微皱眉，虽然你并不会当面指出。
- 愿意花上数周时间只为挑选一块与你的长袍颜色相配的宝石，并且认为这完全合理。
- 面对兽人或食人魔时，你会本能地后退半步——不是恐惧，而是无法忍受那股粗野的气息。

**其他人可能……**

- 觉得你太过矫情，甚至怀疑你是否有能力在荒野中生存——毕竟你连坐下都要先铺一块丝绸。
- 惊讶地发现，你那看似“浪费时间”的细致，在鉴定古物、解读密文或处理外交时竟如此精准可靠。
- 抱怨你说话太绕，但也不得不承认你从未真正失礼于人。

**体貌描述**

精灵的身材修长而纤瘦，普遍比人类高出数寸，却轻上不少。他们的耳朵尖长，微微后掠，如同一片细长的叶片。精灵的容貌极少丑陋——这不是魔法，而是漫长进化与严苛审美共同筛选的结果。他们的发色常见银白、金黄、深棕或铜红，瞳色则包括蓝、绿、灰、紫甚至琥珀金。无论男女，精灵都注重修饰：头发从不杂乱，指甲修剪整齐，衣物即使简陋也力求整洁。精灵的“少年姿态”可以维持数百年，直到五百岁后，发间才会悄然出现银丝，眼角会浮现细纹，动作也不再如青年般迅捷。但即便衰老，精灵依然保持着那份优雅——他们视衰老为另一种美。

**社会**

精灵的社会形态多样，但大多建立在**温和、秩序与文化**之上。无论分支如何，精灵们都极度排斥暴力与粗野——他们更倾向于用几代人的时间去谈判，而不是打一场速战速决的战争。精灵的城市没有城墙，因为“需要城墙来防御的敌人根本不配进入我们的视野”。他们与矮人、人类等种族的关系时好时坏，取决于对方是否尊重精灵的文化细节。而对于兽人、哥布林等被他们视为“野蛮”的种族，精灵往往采取彻底的隔绝态度——不是打不过，而是“不值得浪费口舌”。值得注意的是，精灵并不仇视所有短命种，他们甚至会对那些展现出细腻情感与艺术天赋的人类或可可洛抱以真诚的欣赏。



### 精灵特性

- 体型：中型。
- 速度：步行20尺
- 天生语言：通用语、精灵语与额外一门自选语言



### 精灵血统

- 精灵血统（1点数）：你的魅力+2，体质-2。
- 昏暗视觉（1点数）：你获得昏暗视觉能力。
- 特殊加护（2点数）：星之加护 / 月之祝福：无论你是否会施法，你习得法术光亮术。在昏暗光照下，每天你能免费释放一次隐身术和召唤一次月光打击（如同同名法术）。

**高等精灵**

居于水晶与白石尖塔的精灵，醉心于魔法与哲学，是精灵中最执着于“完美”的一支。他们以几代人打磨一门法术为荣，认为仓促施展的魔法与粗鲁无异。高等精灵的图书馆比宫殿更加宏伟，学徒入门的第一课往往是学会闭嘴聆听十年。外族常觉得他们傲慢——而事实上，他们确实如此，并且对此毫无自觉。

- 高等精灵血统（1点数）：你的智力+2，体质-2。
- 奥术研习（1点数）：无论你是否会施法，你习得任意两个奥数戏法，他们的施法主属性是智力。
- 研习者（2点数）：你在知识检定上获得+2加值。并且你可以在任意技能检定上获得1d6加值，当你使用这项能力后，你必须进行一次短休后才能再次使用。

**森林精灵**

居于树冠之城的精灵，崇尚自然与艺术的交融，能在落叶落地前听出风的走向。他们的箭术与歌声同样出名，庆典时的箭舞能持续整整一个月圆之夜。森林精灵是精灵中最好客的一支，旅人只要言行得体，便能分到树果与蜜酒；但若有人敢在林中滥伐滥猎，迎接他的将是悄无声息悬于咽喉的箭尖。

- 森林精灵血统（1点数）：你的敏捷+2，体质-2。
- 敏锐感官（1点数）：你选择洞悉、求生、或察觉技能，使其熟练等级从普通提升至受训。
- 精灵武器训练（2点数）：你从长剑、刺剑、短弓、长弓中选择2个武器，其获得奖励专长：武器专攻

**苍白精灵**

在月光下长大的支系，白皙而温柔，习惯于夜间活动。他们被认为是精灵中最接近“月”的一支，言谈举止都带着月色般的安静。苍白精灵昼伏夜出，他们的城市在日落后才真正苏醒：银灯次第亮起，咏唱声彻夜不息。他们信奉月相的轮回，认为衰老与逝去皆是圆满的一部分，因此比任何精灵都更平静地面对死亡。

- 苍白精灵血统（1点数）：你的感知+2，体质-2。
- 月之侍僧（1点数）：无论你是否会施法，你从神术列表中习得1个戏法。
- 月瞳（2点数）：你获得60尺黑暗视觉能力。此外，月光对你格外眷顾：在月光照耀下，你将黑暗光照视为昏暗光照；在明耀的满月光照下，你将昏暗光照视为明亮光照。

**海精灵**

居于南方雾海半岛的岸边，以航路、潮汐与珍珠为生。她们是精灵中最娇柔恬静的一支，歌声能抚平最狂暴的风浪。海精灵的城市一半建在滩涂上、一半悬于浅海，涨潮时街道便成了水道。她们熟记每一道洋流的脾气，商人愿付重金聘请海精灵领航；而风暴夜里那穿透浓雾的歌声，是无数水手活下去的理由。

- 海精灵血统（1点数）：你的魅力+2，体质-2。
- 海中游子（1点数）：你获得20尺游泳速度，并获得奖励专长（水下战斗）。
- 塞壬之歌（2点数）：你可以使用整轮动作唱起深海之歌，30尺内所有盟友各解除一项恐慌、魅惑、麻痹或中毒状态（如同次等复原术）。使用此特性后，你在完成一次长休前不能再次使用。
