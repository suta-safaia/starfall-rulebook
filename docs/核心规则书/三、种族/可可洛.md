# 可可洛

可可洛是大陆上娇小且稀少的种族，平均身高仅80至120厘米，无论男女都长着一张圆润可爱的娃娃脸，外人几乎无法分辨性别。他们十岁便算成年，寿命却只有短短五十年左右。这个种族不希望因为身高被其他种族看轻，被叫“小不点”时会鼓起脸颊抗议，但那副模样只会让人觉得更可爱。然而，与小小的身体相反，可可洛拥有惊人的**坚定**：一旦找到自己热爱的事物——无论是锻造、剑术、音乐还是舞蹈——便会将短暂的生命全部燃烧进去，追求极致。

如果你想要塑造一个外表软糯、内心炽热的小小冒险者，一个害羞时会躲到同伴身后、但握起剑来眼神完全改变的角色，你应该选择可可洛。

**你也许……**

- 被人摸头或者叫“小可爱”时，会认真地纠正“我已经成年了”，但对方只会笑得更开心。
- 为了练好一招剑术，连续三个月每天挥剑一千次，小小的手掌磨出厚厚的茧也不肯停。
- 晚年坐在火炉边给年轻的可可洛讲故事时，讲着讲着眼睛就亮了起来，仿佛又回到了冒险的年纪。

**其他人可能……**

- 第一眼看到你时觉得你像个需要保护的小孩子，但很快就会发现你的意志比许多大个子都要坚定。
- 一开始觉得你又害羞又粘人，但在冒险中逐渐意识到——你是队伍里最可靠的那个，因为你从不半途而废。

**体貌描述**

可可洛身高80至120厘米，身体圆润而匀称，四肢短小却异常灵巧。他们的脸庞几乎是完美的圆形，眼睛又大又圆，无论年龄多大都保持着孩童般的可爱。男女之间几乎没有明显的外貌差异——唯有服饰或发型能提供些许线索，而许多可可洛根本不在意这些区分。他们的发色以暖色调为主：栗色、橙色、亚麻色、浅棕色。可可洛十岁成年，四十岁后动作渐缓，但眼中的光芒往往直到最后一天才会熄灭。

**社会**

可可洛没有庞大的王国，他们以家族为单位，聚居在人类城镇边缘或宁静的乡野。他们的社会围绕着“出去”与“归来”运转：深爱家庭，却又抑制不住对冒险的向往。成年后，他们纷纷踏上旅途闯荡世界；晚年则回到故乡，成为火炉边的“讲故事的人”。可可洛在人生的大部分时间都十分有活力，对待他人也抱有热情友好的态度，有学者认为这与他们寿命短灵魂能更快的回到天国有关。可可洛对"极致"的追求近乎偏执——他们知道自己没有足够的时间学所有东西，所以会选一件事，然后把短短五十年全部烧进去。

### 可可洛特性

- 体型：小型。
- 速度：步行20尺
- 天生语言：通用语、可可洛语与额外一门自选语言

- 坚韧意志（1点数）：可可洛在对抗恐惧，魅惑的豁免检定中获得+2加值。
- 特殊加护（2点数）：星之加护 / 全力全开：把日积月累的努力在这一刻一口气爆发出来。你至多储存2次使用次数；当你进行一次属性检定、攻击检定或豁免检定时，你可以消耗1次使用次数，不投掷d20、直接将掷骰结果视为10后计算检定结果。每当你完成一次长休，恢复1次已消耗的使用次数。

**远行血脉**

世代向往着远方、成年便背起比自己还大的行囊踏上旅途的可可洛。他们是地图的绘制者、异乡故事的收集者，风餐露宿反而乐在其中。远行血脉的可可洛发誓要看遍整个世界再回家，而每当他们回到故乡的火炉边，带回的故事总能让全族人的眼睛亮起来——然后，又送走下一批按捺不住的年轻人。

- 远行血统（1点数）：你的敏捷+2，力量-2。
- 可可洛武器训练（1点数）：只要武器满足其力量需求，你就能将其视为灵巧武器。
- 灵巧步伐（2点数）：获得额外专长：灵活移动

**炉火血脉**

世代留在故乡、围着炉火把一生烧进一门技艺的可可洛。他们是故事、手艺与传统的守护者：修补祖传的铠甲、誊抄泛黄的歌谣、记住每一个远游者的名字。炉火血脉的可可洛看似安于平淡，实则把“极致”二字熔进了日常——他们打造的器物或许不起眼，却能用上百年，也是远行者归乡时永远亮着的那盏灯。

- 炉火血统（1点数）：你的感知+2，力量-2。
- 一艺入魂（1点数）：任选一项技能或工具，其熟练等级从普通提升至受训。
- 炉边热食（2点数）：一同休息的同伴都能吃上一口热乎的。当你与盟友一同完成长休时，所有共同休息的盟友（包括你自己）的休息系数+10%。
