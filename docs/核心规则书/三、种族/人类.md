# 人类

### 人类

人类素有“万族之桥”的美誉，他们寿命短暂却步履不停，十五岁便算成年，匆匆八十载的一生中充满了变数与野心。人类没有统一的民族信条，每个人都怀揣着截然不同的信仰、欲望与梦想。正因如此，他们拥有着其他种族难以企及的天赋：**左右逢源**。无论是高傲的精灵，还是神秘的巨人，甚至是狡猾的哥布林，只要能够沟通，人类总能找到融入其中的缝隙——或成为朋友，或做起买卖，甚至学会对方的技艺与习俗。这种适应性让人类在纷乱的世界上既显得圆滑，又充满生机。

如果你想要塑造一个灵活多变、善于周旋的冒险者，一个懂得何时低头、何时握拳的务实之人，一个在陌生土地上总能找到立足之处的生存大师，你应该选择人类。

**你也许……**

- 在陌生的城市不出三天就认识了酒馆老板、铁匠铺学徒和守卫队长，并且已经谈妥了一笔生意。
- 学会用对方的语言讲笑话、谈信仰、甚至争论哲学，尽管你的口音总带着一丝故乡的痕迹。
- 将自己的短寿化作动力，拒绝浪费任何一天——你比任何长命种都更渴望在有限的生命里留下痕迹。
- 随身携带几件不同文化的小饰物，必要时能迅速伪装成当地人，因为“适应”本就是你的本能。

**其他人可能……**

- 尊重你的应变力，适应力以及……在大多数情况下，你活跃的思维。
- 惊讶于你如此轻易地理解他们的习俗与禁忌，却也因此对你放松警惕，甚至向你吐露心声。

**体貌描述**

人类的外貌差异之大，堪称所有种族之最。他们的身高从五尺到六尺有余不等，发色、瞳色、肤色因地域与血统千变万化。人类没有统一的服饰风格或发式，每个个体都在追求自己所认同的“美”。由于寿命短暂，人类在十五岁左右便进入成年，但许多社会仍会举行成年仪式以示区分。一个健康的人类通常能活到八十岁上下，其中最后二十年往往伴随着明显的衰老痕迹——白发、皱纹与行动的迟缓。但也正是这份短暂，让人类的青春显得格外热烈。

**社会**

人类没有单一的社会形态。从部落到王国，从共和城邦到神权帝国，人类的政体与文化之丰富令其他种族瞠目。唯一共通的是他们惊人的**流动性**：人类会为了更好的土地、更丰厚的贸易利润或更自由的信仰而迁徙。在任何一个非人类的城市里，你都能找到人类商贩、人类工匠，甚至人类难民。他们像水一样渗透进所有缝隙。这种特性让人类成为了大陆上最广泛的中介者。人类自己也说不清这究竟是优点还是诅咒，但至少有一点可以肯定：**只要还有交流的渴望，人类就永远不会被排除在任何圈子之外。**

### 人类血统

你获得4点种族血统点数（所有种族都一样，后不赘述），你可以任意组合以下血统特性

- 进化血统（1点数）：任选一项属性+1。
- 多用（2点数）：你可以自选1项额外专长。
- 特殊加护（2点数）：星之加护 / 逆转命运：当你投掷检定时，只要不是n1或者n20，你都可以反转其骰子大小，该加护在你进行一次长休后可再次使用。

**城邦人类**

世代生活在城墙与市集之间的人类，耳濡目染的是契约、谈判与人情往来。他们从小看着商队进出城门，学会了辨认四十种口音和一百种笑容。城邦人类相信任何问题都能在谈判桌上解决——只要价码合适；即便解决不了，至少也能拖到援军赶到。他们是天生的中间人、掌柜与掮客，人脉就是他们最坚实的铠甲。

- 城邦人类血统（1点数）：你的魅力+2，感知-2。
- 多才多艺（1点数）：你可以选择（a）任意2项技能　或（b）任意1项工具 熟练等级从普通提升至受训。

**旷野人类**

世代生活在边疆、荒原与迁徙路上的人类，习惯了自己动手、自己活命。他们认得每一种野兽的脚印，听得懂风暴来临前空气的颤动。旷野人类不迷信奇迹，只相信磨好的刀和存够的粮；对他们而言，承诺不如篝火实在，客套不如一碗热汤。艰苦的环境磨掉了他们的圆滑，却磨出了惊人的韧性与近乎固执的直率。

- 旷野人类血统（1点数）：你的体质+2，智力-2。
- 适应力（1点数）：当你在野外进行长休时，你的休息效率减值只受到环境一半影响。
