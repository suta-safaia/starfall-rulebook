# 鬼族

鬼族是行走的祭典。他们头生犄角、獠牙外露、力大无穷——但这副吓人的皮囊里，装着全大陆最痛快的天性：高兴就大笑，感动就大哭，交朋友用拥抱，讲道理用拳头，庆祝任何事情都用酒。鬼族从不说谎——不是不屑，是真的不会，谎话到了舌尖会自动变成打结的嘟囔；相应的，他们也最恨被骗，骗鬼一次，记恨三代。鬼族寿命约一百五十年，一生的信条只有一条：**拳头要硬，心肠要热，酒要满上**。

如果你想要塑造一个把每一场架都打成节日的豪快战士，一个力能拔山、却最爱搂着人脖子灌酒的大个子，一个不会说谎、把朋友的债当成自己债的角色，你应该选择鬼族。

**你也许……**

- 打招呼的方式是拥抱——至今没有人能在你的拥抱里保持肋骨完好，好在也没人真的介意。
- 把每一场架都当节日来过，把每一个节日都过成打架。
- 年轻时试过一次说谎，话音未落自己先笑场了，从此放弃了这条路。
- 随身酒葫芦里永远有"最后一口"，喝完还有，喝完还有。

**其他人可能……**

- 初见时被你的獠牙吓得绕道走，三杯之后被你搂着脖子称兄道弟。
- 发现你从不说谎，谈生意时都抢着拉你当见证人。
- 好奇你这么能吃能喝钱从哪来——答案是打一架挣一场，喝一场花光。

**体貌描述**

鬼族的体格差异极大：有的身高逾两米、肩背如城墙，有的娇小如孩童——但千万别以貌取人，鬼族的力量与体型毫无关系，徒手掰断铁条、单手扛起酒缸，对他们而言都只是助兴节目。他们头生一角或双角，肤色有赤红、青灰、古铜等多种，口生獠牙，笑起来比发怒还吓人。鬼族二十岁成年，寿命约一百五十岁。

**社会**

鬼族没有统一的国度，多聚居于山野之间的村寨——说是村寨，不如说是永不落幕的祭场：摔跤是早安，比武是午茶，入夜之后篝火与酒坛一起见底。鬼族的社会围绕"祭"字运转，打架、喝酒、唱歌、结拜，样样皆祭。他们不记仇，只记骗：欺骗是鬼族唯一的重罪，说谎者在寨子里的不受欢迎程度远胜强盗。鬼族常被人类村镇重金雇为护卫与佣兵，也常被请去主持庆典——毕竟有鬼族在的地方，就没有"冷场"两个字。

### 鬼族特性

- 体型：中型。
- 速度：步行20尺
- 天生语言：通用语与额外一门自选语言

### 鬼族血统

- 怪力（1点数）：你的力量检定和力量豁免额外获得+2加值。
- 粗犷（1点数）：你忠于本能的思考，让你在对抗魅惑与恐慌效应时额外获得+2加值。

**赤鬼血脉**

赤色皮肤的鬼族，战意比火还旺，笑声比战吼先到。赤鬼血脉把战斗当作最盛大的游戏：他们打架从不留手——留手是对对手的不尊重；打完必请喝酒——能接他们三棒还不倒的，就配做他们的兄弟。"拳头到不了的地方，道理也到不了"，但他们的拳头，很少落在没有恶意的人身上。

- 赤鬼血统（1点数）：你的力量+2，智力-2。
- 酣战（2点数）：当你的生命值低于生命值上限的1/3时，你的近战攻击检定与近战伤害掷骰各获得+2加值。
- 特殊加护（2点数）：星之加护 / 鬼之咆哮：每日一次，你发出一声震慑人心的咆哮：周围30尺内所有能听到你的敌对生物需进行一次感知豁免，失败者陷入恐慌，持续1分钟。

**酒呑血脉**

以酒为名的血脉，千杯不醉，越醉越勇。酒呑血脉的鬼族走到哪里，酒宴就开到哪里——他们的葫芦里永远有酒，他们的拳头永远有力；有人说他们酿的是酒，也有人说他们酿的是热闹。酒呑血脉极少动真怒，但千万别打翻他们的酒坛：那是全大陆少数几个能让笑声瞬间消失的时刻。

- 酒呑血统（1点数）：你的体质+2，智力-2。
- 千杯不醉（1点数）：你永远不会因饮酒而陷入任何负面状态（除非你自己想醉），且在体质豁免上获得+2加值。
- 特殊加护（2点数）：星之加护 / 无尽酒瓢：你可以将一件容器化为自己的专属酒器（同一时期至多拥有一件，化为酒器的仪式需耗时一夜）。此后每日清晨，酒器中会自行酿出一份美酒——这酒只对你一人生效，他人饮之不过是清水寡液。当你饮下这份酒时，如同受到一次假寐术的效果。
