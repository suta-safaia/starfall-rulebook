**生命值（HIT POINTS）**

生命值代表了你的生命力。角色的生命值上限来自职业：每个职业等级都会提供固定数值的生命值（见各职业条目），生命值上限即为所有职业等级提供的生命值总和。

当生命值大于等于0时，此时代表你仍有正常活动的能力，即使生命值只剩1点，也只是代表角色已经身负重伤，并不会影响行动能力。如果你的生命值降低为0，代表你的生命力已如风中残烛进入濒死状态陷入昏迷，这种致命的打击会让你获得一层力竭，并且在你的回合结束时你必须进行一次纯骰的生死豁免，每一次成功的生死豁免都会为你放置一个成功标记，反之则放置一个失败标记，当你生死豁免失败次数达到三次时，你就会死去，反之你先一步成功三次，你将会进入伤势稳定状态，除非你选择下文的硬撑（详细见下文）。当你的生命值恢复到0点及以上时，你从濒死状态脱离，并抹去所有生死豁免相关的标记。

通常敌方NPC处理方式则不同，当敌人的血量达到0时，玩家可以自行决定是杀死敌人还是使其昏迷。

*1. 生死豁免DC = 10，检定 = 1D20+其他调整值（与体质无关）*

*2. 伤势稳定：你无需再投掷生死豁免，并且1小时后会回复1点生命值脱离濒死状态。*

**休息与恢复**

长休结束时，角色恢复一部分生命值，并且已消耗的法术位有机会恢复，具体恢复量由休息系数决定：

**休息系数 = 30% + 体质调整值 × 2% + 环境加值 + 其它加值（最低 0%）**

环境加值由住宿、饮食、温度三项构成，各项取值如下（单位为百分点）：

| 住宿条件 | 加值 |
|---|---|
| 露宿荒野，无任何遮蔽 | -15 |
| 简陋遮蔽（破棚、山洞、就地而眠） | -10 |
| 拥挤嘈杂的通铺、廉价旅店 | -5 |
| 普通客栈房间、干净的床铺 | 0 |
| 舒适的上房、温暖的家中 | +5 |
| 豪华套房、温泉疗养地 | +10 |

| 饮食条件 | 加值 |
|---|---|
| 完全没有进食| -15 |
| 忍饥挨饿，只摄入了一半的需求食物 | -10 |
| 仅靠干粮、劣质食物充饥 | -5 |
| 正常的家常饭食 | 0 |
| 丰盛的大餐、滋补的膳食 | +5 |

| 温度条件 | 加值 |
|---|---|
| 温度适宜，或防护完全充分 | 0 |
| 寒冷或暑热，有一定防护 | -5 |
| 寒冷或暑热且无防护；或严寒或酷暑，有一定防护 | -10 |
| 严寒或酷暑，且没有任何防护 | -15 |

- 生命值：恢复相当于 生命值上限 × 休息系数 的生命值。
- 法术位：每个已消耗的法术位分别判定一次，有 50% + 休息系数 的概率恢复可用（最高 95%）。
- 力竭回复与惩罚：长休结束时，若住宿、饮食、温度三项的环境加值均不为负，你恢复1层力竭；若住宿与饮食均为+5且温度为0，则改为恢复2层力竭。若其中任意一项的减值达到-10或更低，你必须进行一次体质检定，DC = 10 + 5 ×（减值达到-10的项数）；若检定失败，你的力竭提升1级。此外，若任意一项的减值达到-15，你的力竭直接提升1级（无需检定，与检定失败的惩罚叠加）。

**短休**

短休是至少1小时的停歇：扎营、进食、包扎、整理装备。短休结束时：

- 所有标注「短休后恢复」的特性恢复其使用次数。
- 默认不恢复生命值与法术位。
- 每名角色选择执行一项**休整行动**。同一项休整行动在一次短休中至多由两名角色执行，除非其描述另有说明。

**休整行动**

以下休整行动对所有角色开放。标注检定的行动需要进行一次对应的属性检定，DC 通常为15，DM 可根据环境优劣上下浮动。

| 休整行动 | 效果 |
|---|---|
| **处理伤势**（医疗，感知） | 为自己或一名队友包扎伤口，目标恢复相当于生命值上限 × 10% 的生命值。|
| **采集补给**（生存，感知） | 在周遭搜寻食物与净水，获得1份简易口粮；检定结果每超出DC 5点，额外获得1份简易口粮。 |
| **生火烹饪** | 消耗至少1份口粮，为全队烹制热食。本次短休后紧接着的长休中，全队的饮食环境加值提升一级（最高不超过+5）。同一时间内全队只能享受一份热食的增益。 |
| **警戒放哨** | 你放弃休整，保持全副警觉。。 |
| **侦查探路**（察觉或生存，感知） | 探查周边地形与动向。你了解营地附近存在的危险、路径与资源，并且队伍在下一场遭遇战中不会被突袭。 |
| **磨砺武器** | 保养并打磨你的武器。在下一场战斗中，你首次命中的武器攻击额外造成1D6伤害。 |
| **保养护甲** | 修补并调整你的护甲。下一次你会被重击命中时，该次重击改为普通命中，随后此增益消失。 |
| **鼓舞谈心**（交涉或表演，魅力） | 开解一名队友的心结。该队友获得相当于 你的等级 + 你的魅力调整值 的临时生命值，持续至其下次短休或长休结束。 |
| **冥想调息** | 澄澈心神。直到下次长休结束，你的下一次豁免检定或专注检定获得+2加值。 |
| **祷告祭祀**（宗教，感知或智力） | 向神明或先祖祈求庇佑。你和至多两名队友在下一次生死豁免中获得+2加值。 |
| **制作修补**（对应工具） | 利用随身工具进行简单制作：制作至多20支箭矢、修复一件损坏的装备，或调制一份简易药膏（以一个动作使用，恢复1D6+你的等级的生命值，药膏在下次长休后失效）。 |
| **布置营地** | 在营地周围设置绊线、警铃与简易陷坑。若有生物在队伍休息期间潜入营地，会触发警报，队伍不会因此陷入措手不及。 |
