# 战斗详解

### 战斗常用数据

这一部分给出了哪些数据决定战斗是否成功，同时给出了它们的详细说明。



**基础攻击加值（BAB）**

职业给予你的攻击加值，可以加入到攻击检定之中，并且它还是许多兼职、专长的前置要求条件。

另外一个重要的点是BAB可以为你带来多次攻击的机会，当你的BAB超过5点后，每5点BAB都会为你带来一次额外攻击的次数（即BAB达到6、11、16、21、26……时），但是每一次额外攻击都需要承担-5的多重攻击减值，并且这个惩罚是累加的。（例如你的基础BAB是12，那么你可以一共进行3次攻击，这三次攻击的攻击加值分别是+12，+7，+2）。

*值得注意的是，也有一些专长也有额外攻击，例如多重射击，它们并不属于BAB给予的额外攻击，因此不会受到多重攻击减值的惩罚，并且也不会消耗BAB额外攻击的额外攻击次数。*



**攻击检定**

一次攻击检定代表你在该轮中自己行动时试图攻击你的对手一次。当作攻击检定时，你要投一个d20并且加上你的攻击加值（通常其他修正也要应用在这次检定上）。如果结果大于等于对手的防御等级，那么你命中了对手，并造成伤害。

*自动失手：攻击检定时自然骰结果为1（d20投出1）总是失手*

*自动命中和重击：当你的自然骰大于等于你武器的重击阈值时（无描述的武器和法术等重击阈值默认为20），此次攻击会变为重击。重击总是命中，重击时伤害骰按重击倍率翻倍（×2 即伤害骰翻倍，×3 翻三倍，以此类推）；调整值不受重击倍率影响*

攻击检定 = 1D20 + 基础攻击加值 + 属性调整值 + 体型修正 + 距离修正 + 其他加值

*1. 近战武器为力量属性，远程武器为敏捷属性，法术为施法主属性，一些特性能让你打破之前的属性限制，例如灵巧近战武器就可以选择使用敏捷属性而不是力量*

*2. 当你进行远程攻击一个超过标准射程的生物时，每超出一倍射程，距离修正为-2，例如你投掷手斧向75尺的敌人时，你手斧的的射程为20尺，那么你受到-6距离修正*



**防御等级**

防御等级代表对手能伤害到你的困难度。即对手要攻击到你需要的最低命中检定值。

防御等级 = 10 + 盔甲加值 + 敏捷调整值 + 敏捷修正 + 体型修正 + 熟练加值 + 其他加值。

*1. 接触攻击：一些攻击只需要触碰到你就能产生效果，常见于法术攻击，此种情况你的 AC 失去你的盔甲加值*

*2. 盔甲限制：盔甲牺牲了你的灵巧性，你的敏捷调整值不能全部加入 AC 中，详见每个盔甲的最大敏捷调整值*

*3. 失去敏捷：一些情况会让你无法即时做出反应或者无法行动，此时你的 AC 就会失去你的敏捷调整值和敏捷修正，常见于措手不及状态，沉睡，禁锢等。*

常见的其他加值

- 增强加值：增加你盔甲的防御能力，当你失去盔甲加值时，增加加值也一并失去
- 天生防御：一些生物天生会因为鳞片等特性获得额外的防御等级，当你失去盔甲加值时，天生防御也一并失去
- 闪避加值：不受盔甲影响的可叠加的闪避性能，常见于全防御，愚守于攻，剑歌，在你失去敏捷时，闪避加值也一并失去
- 偏斜加值：一些魔法有一种能弹开攻击的力场，常见于护盾术

**速度（SPEED）**

速度的单位通常是尺，代表了一轮中一次移动速度你能移动的距离，其数值主要和种族，负重以及法术挂钩。

为了简化，通常你只能在自己的回合中执行移动动作，但是你可以多次执行移动动作获得额外的速度，例如你的步行速度是20尺，你花费3 AP进行三次移动动作，你本回合就可以移动60尺。

> [!TIP] 💡 复合移动速度
> 当你拥有多种移动速度时，你进行移动时可以选择用多种移动方式，但是每一种移动方式不能超过其本身的速度上限，所有移动方式的移动距离总和不能超过你最大移动速度的上限。
>
> 例如，一位龙裔术士对自己使用了脚底抹油并展开了翅膀，于是他有30尺的步行速度和15尺的飞行速度，并且他使用了两次移动动作，本回合他的速度变为60尺步行和30尺飞行，龙裔术士为了冲向悬崖对面的敌人，先在地面上奔跑了35尺，再飞行了10尺跨过悬崖，最后落地后再跑15尺来到了敌人面前。这代表了移动时可以拆分使用多种移动方式。
>
> 如果悬崖的长度是40尺，则龙裔术士无法飞过悬崖，因为其悬崖宽度超过了龙裔的飞行速度。
>
> 如果最后龙裔还需要跑20尺才能抵近敌人，则他无法做到，即便他没用完他的步行速度，因为步行35+飞行10+步行20 = 65的总移动距离以及超过了其最大移动速度60尺步行。

**困难地形**

一些地形，例如碎石和灌木丛还有一个生物占据的单元格对于大部分人来说是困难地形，在进入一个困难地形时，你每移动5尺就要花费额外的5尺移动力，并且困难地形可以叠加。

- 移动速度不足以移动：当你的移动速度不为0时，且你花费所有AP都无法获得在困难地形上移动5尺的速度，你可以强制自己花费整轮动作移动5尺，但是这不等同于五尺快步；若因此移出敌人的威胁格，仍会引发借机攻击。

**法术DC（Spell-Difficulty Class）**

很多法术会说明目标可以进行一次豁免来回避法术部分或全部的效应。相关法术的描述中会详细说明使用的什么属性来进行豁免，以及豁免成功和失败的后果。你的法术豁免DC取决你的施法主属性和施法者等级。

法术DC =10 + 施法主属性调整值 + 法术环阶



**豁免检定（SAVING  THROWS）**

通常在受到特殊攻击或魔法攻击时，通常可以通过做一个某个属性的豁免检定来决定是否避开或者减低攻击效果，以无效或者减轻受到的效果影响。

豁免检定 = 1D20 +  属性调整值 + 熟练加值 + 其他加值



**先攻检定（Initiative** **ROLL）**

在每一轮中，每个战斗人员依照先攻值，由高到低依序动作，而决定先攻值的就是先攻检定。

先攻检定 = 1D20 + 敏捷调整值  + 其他加值 + 0.01*敏捷属性值

*1. 即同先攻值敏捷高者先攻值越高*



**专注检定（Concentration Roll）**

当在恶劣的条件下或者受到借机攻击时释放法术或维持专注法术，你需要进行专注检定来正常释放或维持法术的效果，专注检定的DC见后文的法术专栏。

专注检定 = 1D20 + 体质调整值 + 其他加值

**施法者等级检定**

某些时候，你需要进行施法者等级检定，例如在面对法术抗力时需要投掷施法者等级检定来击穿法术抗力。

施法者等级检定 = 1D20 + 施法者等级

**躲藏以及看不见的敌人**

参战者常常会用躲藏、隐形术等方式避开敌人的耳目。在攻击看不见的敌人或者被看不见的敌人攻击时，你视为目盲状态，而且很多法术要求你只能对看得见的生物释放。

与视线相关的状态一般有两种，一是隐形，二是躲藏。前者是敌人在通常视觉下无法看到你，但是能够通过你留下的痕迹知道你所在的位置。而后者是敌人连你的位置都无法察觉，当然也会获得隐形的好处；但是当你在躲藏状态下进行任何攻击或者释放一个带有姿势成分或者声音成分的法术时，你的躲藏状态将会结束。

- 何时能进行躲藏：当你对所有敌人处于全遮蔽时，你就可以进行隐匿，当然你无法说自己盖住一个白布进行隐匿然后在躲藏状态下离开，你能隐匿的前提还有一点就是你隐匿后敌人无法判断你是否已经离开原地，除非你确实有隐匿后进行传送等打破这一限制的能力。一些特殊能力能够让你在额外条件下（例如微光，灌木丛中就能进行隐匿）进行躲藏。

- 判定躲藏是否成功：当你第一次出现在敌人视野内（包括因特殊能力你能在敌人眼前隐匿时），你投掷隐匿检定，与敌人的被动察觉做对抗，只要你的隐匿检定大于敌人的被动察觉，那么你对于敌人来说就是躲藏状态。（躲藏状态是对于敌人来说的，多个敌人的被动察觉不同会导致不同的结果）。

- 保持躲藏：当你已经处于躲藏状态时，每轮你都需要重新投掷隐匿检定来保持躲藏，你在躲藏状态下，你的移动速度减半，否则你本轮的隐匿检定具有-5减值。

### 视觉与遮蔽

* 普通视觉：又称明亮光照下的视觉范围，往往能看到几里外的地方，若在高山处甚至能看几十里远，此时视觉距离往往是和障碍物有关。在下雨甚至起雾时，能见度又会急速下降。一般来说，这里的视觉范围只是说的能看见，而不是看清，若你想分辨一个人的特征，需要进行察觉检定，不过游戏中很少有这种机会。

* 昏暗视觉: 通常在那些在夜行种族上出现，在昏暗视觉的范围内，昏暗光照视为明亮光照，但仍然无法在黑暗中视物。

* 黑暗视觉：通常在地底、海底这种几乎完全生活在无光环境下的种族出现，在黑暗视觉的帮助下，除了拥有昏暗视觉的将昏暗光照视为明亮光照外，在范围内即便是黑暗对于这些生物也是昏暗光照。但是这个能力无法看穿由魔法造成的黑暗。

* 魔鬼视觉：进阶版的黑暗视觉，它除了拥有黑暗视觉外的所有能力还能看穿魔法黑暗。因这项能力经常在魔鬼种族上出现而得名。

* 盲视：通过回声定位、震动感知等非视觉方式，在范围内能像正常视力者一样精确地战斗和移动。能有效应对隐形和黑暗。只要目标对于你不是全身掩护，你就可以感知到它的位置。

* 盲感：通过训练捕捉微弱踪迹的能力，可以看作盲视的下位版本，拥有在范围内在能够像盲视一样察觉到生物位置的能力，但是不够精确，生物对于你来说仍然是全遮蔽。但是盲感在生物处于全身掩护的情况下也能被你捕捉到。

* 震颤感知：通过地面的震动捕捉的来精确定位目标的位置，往往是范围更大的盲视，但是缺点是无法探测到在空中移动的生物，也无法探测到完全静止的生物。

* 生命视觉：一种盲视，但是它只能探普通的生命体，不死生物、构装体、物品等非普通生命体它完全无法感知到。

* 真实视觉：几乎是最强大的感知能力，无论是否魔法黑暗，无论是否隐形，都无法阻碍它的视线，连在以太中藏匿的生物和幻术都能看清，通过感知魔素的流动能够发觉到魔法的发动，即便其没有姿势或声音的施法成分。唯一的缺点是作为视觉，它仍然会被全身掩护和雾气这样的全身遮蔽区域阻碍视线。

* 轻度遮蔽：常见于昏暗光照下，例如有光夜晚，黎明或黄昏，地下的发光地衣洞穴。薄雾、大雨、黄沙等天气也能造成轻度遮蔽。在轻度遮蔽下，你进行的视觉察觉检定获得-2减值。并且你攻击时有20%的失手率。

* 重度遮蔽：常见于昏暗视觉在黑暗光照下视物，或者在无光的夜晚。浓雾、沙尘暴、暴风雪等天气也能造成重度遮蔽。在重度遮蔽下，你进行的视觉察觉检定获得-5减值。并且你攻击时有35%的失手率。

* 完全遮蔽：常见于黑暗光照下，完全无光的洞穴、海底。云雾术和黑暗术创造的魔法区域也能阻断视觉形成完全遮蔽（值得注意的是，这两个法术的原理并不相同）。没有黑暗视觉的生物在此区域内视同目盲，基于视觉的技能检定直接失败，并且你攻击时有50%的失手率。
