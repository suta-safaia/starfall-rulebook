# 借机攻击

有些时候近战的人会放松自己的防卫。在此时，他周围的敌人可以利用他的松懈来自由的攻击他。这种攻击叫做借机攻击。

-什么是威胁区域：你的威胁区域，就是你近战攻击所能触及的所有方格，通常是你周围邻接的格子。这个区域即使在不是你的回合时也依然存在，代表着你对周围空间的持续控制力。
-如何获得威胁区域：你必须持用一把武器（或拥有除徒手武器以外的天生武器）才能建立威胁区域。如果你徒手或者持有远程武器，你无法威胁任何方格，也就不能进行借机攻击。
-扩大威胁区域：长型武器或者触及武器、以及更大的体型可以扩大你的威胁范围，例如一个超大型生物拿着长矛就有15吃的威胁区域。
-攻击性质：它是一次普通的近战攻击，使用你最高的那次bab攻击，不会受到你额外攻击次数的减值影响。并且借机攻击会立即暂停引发其借机攻击的行为，在借机攻击结束后才能继续执行引发借机的行为。且该引发借机攻击的行为不能改变，除非该动作已经因为借机攻击带来的影响无法执行。
-次数限制：一般来说，你在一轮中只有一次借机攻击机会。
