# 战斗修正速查

速查表，许多状态具体表现需见《附录B：术语汇编 状态》

以下修正直接计入攻击者的攻击加值。

| 攻击者状态 | 近战攻击加值 | 远程攻击加值 |
| --- | :---: | :---: |
| 目眩 | -1 | -1 |
| 纠缠<sup>1</sup> | -2 | -2 |
| 夹击目标 | +2 | +0 |
| 躲藏 | +2 | +2 |
| 倒地<sup>2</sup> | -4 | — |
| 恐惧 | -2 | -2 |
| 挤入狭窄空间 | -4 | -4 |

1. 纠缠还会使攻击者的敏捷属性受到 -4 减值，这可能进一步影响其攻击检定。
2. 大多数远程武器无法在攻击者倒地时使用，但攻击者可以在倒地时使用弩或投掷武器，且不受倒地减值。

## 防御等级（AC）修正

以下修正直接计入防御者的 AC。

| 防御者状态 | 近战 AC | 远程 AC |
| --- | :---: | :---: |
| 半身掩护 | +0 | +2 |
| 3/4掩护 | +2 | +5 |
| 目盲<sup>1</sup> | -2 | -2 |
| 隐蔽或隐形 | 见隐蔽规则 | 见隐蔽规则 |
| 纠缠<sup>2</sup> | +0 | +0 |
| 措手不及（如受突袭、体操维持平衡或运动进行攀爬等）<sup>1</sup> | +0 | +0 |
| 擒抱中（攻击者未参与擒抱）<sup>1</sup> | +0 | +0<sup>3</sup> |
| 无助 | -4 | +0 |
| 跪姿或坐姿 | -2 | +2 |
| 被压制<sup>4</sup> | -4 | +0 |
| 倒地 | -4 | +4 |
| 挤入狭窄空间 | -4 | -4 |
| 震慑<sup>1</sup> | -2 | -2 |

1. 防御者失去 AC 上的所有敏捷加值。
2. 纠缠会使防御者的敏捷属性受到 -4 减值，可能会影响AC。
3. 随机决定命中哪一名擒抱中的战斗者；被击中的防御者失去 AC 上的所有敏捷加值。
4. 计算 AC 时，将防御者的敏捷视为 0（敏捷调整值为 -5）。游荡者可以偷袭无助或被压制的防御者。

## 失手率

| 来源 | 失手率 | 说明 |
| --- | :---: | --- |
| 轻度遮蔽 | 20% | 昏暗照明、烟雾、稀疏灌木、以及回避凝视而移开视线等 |
| 重度遮蔽 | 35% | 繁茂灌木丛、倾盆暴雨等 |
| 全身遮蔽 | 50% | 无光黑暗、浓雾、目盲或无法看见对手等 |
| 虚体生物 | 50% | 无镀银武器、无幽魂武器和无力场伤害时时 |

- 多个隐蔽效果不叠加，取最高的失手率。
- 昏暗视觉、黑暗视觉、盲视、真视等能力能否消除失手率，取决于其是否能穿透对应的隐蔽来源。
- 掩护不造成失手率；全掩护表示无法直接攻击。
- 虚体生物的失手率来源于它在物理世界和以太位面膳所的结果，不属于隐蔽失手率，需要能穿越境界的武器才能忽视这个失手率。
