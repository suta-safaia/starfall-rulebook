# 2环

# 匕首之云

*二环 咒法*

**职业：** 法师/术士

**施法时间：** 3 AP

**法术区域：** 60尺 | 5尺球体 / 每2施法者等级（最高10尺） | 爆发

**法术成分：**  声音、姿势、材料（一小片玻璃）

**持续时间：**  专注、至多1分钟

**法术抗力：**  不可

你在法术区域内咒唤出旋转的匕首。区域内的每名生物受到 1d4 / 每施法者等级（最高8d4）点挥砍伤害。一名生物进入该区域，或是在该区域结束其回合时，该生物同样会受到此伤害。一名生物每回合只会受到一次该伤害。

# 地缚

*二环 变化*

**职业：** 法师/术士

**施法时间：** 2 AP

**施法距离：**  100尺 / 每施法者等级（最高600尺）

**法术成分：**  声音

**持续时间：**  专注、至多1分钟

**法术抗力：**  不可

选择施法距离内你能够看到的一个生物。黄色的魔法能量线缠绕着该生物。该目标必须通过一次力量豁免检定，否则其飞行速度（若有的话）在法术的持续时间内降为0尺。受到此法术影响的飞行中的生物以每回合60尺的速度安全降落，直到其撞到地面或法术终结。

# 守护之风

*二环 塑能*

**职业：** 法师/术士

**施法时间：** 3 AP

**法术区域：** 自身 | 10尺半径 | 爆发

**法术成分：**  声音

**持续时间：**  1分钟 / 每施法者等级

**法术抗力：**  无

一阵强风（风速每小时 20 里）充满法术区域，并能随着你移动，始终以你为中心。这股风将在法术的持续时间内持续存在。

这股风具有如下效果：

- 它会令你和其他区域内的生物<u>耳聋</u>。
- 它会令区域内未受保护的火焰熄灭，不过至多只能熄灭像火把那样大小的火焰。
- 它可以隔离那些能够被强风吹散的毒气、瓦斯和雾气。
- 区域对于除你之外的生物是困难地形。
- 若远程武器攻击进入或离开风区，其攻击检定得到 -4 减值。

# 心灵探针

*二环 预言*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  120尺

**法术成分：**  姿势

**持续时间：**  1分钟 / 每施法者等级

**法术抗力：**  可

你驱动一道心灵能量的锥刺侵入施法距离内一个可见生物的心智。目标必须进行一次魅力豁免检定，失败则会受到 1d8 / 每施法者等级（最高8d8）点心灵伤害，豁免成功则受到半数伤害。在目标豁免失败时，你在法术结束之前能时刻得知目标所在的方位，只要你们还处于同一个存在位面上。如果目标在你的 300 尺范围内，你将确切地知道其位置，目标不能对你躲藏，并且如果它处于隐形状态，在对抗你时它不能从这个状态中受益。

# 敲击术

*二环 变化*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  60尺

**法术成分：**  声音

**持续时间：**  立即

**法术抗力：**  无

指定施法距离内一个你能看见的物件。该物件可以是一扇门、一个盒子、一个箱子、一副镣铐、一把挂锁，或是一个其他通过魔法或普通手段防止被打开的物件。

被普通锁锁住的目标，其锁会被解开；被卡死的目标会被松开；被闩住的目标会被打开。如果目标被多把锁锁住，则只有一把锁会被打开。

若你指定的目标被秘法锁锁住，则该秘法锁被压制 10 分钟，这段时间内目标可被正常开启和关闭。

施展该法术时，目标会发出一声响亮的敲击声，其声响在 300 尺内都能听见。

# 浮空术

*二环 变化*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  60尺

**法术成分：**  声音、姿势、材料（一个金属弹簧）

**持续时间：**  专注、1轮 / 每施法者等级

**法术抗力：**  可

指定施法距离内你能看见的一个生物或未固定的物件，使其垂直上升至多20尺，并在该处维持悬浮直至持续时间结束。该法术可悬浮一个重量至多500磅的目标。一个非自愿的生物可以对法术进行一次体质豁免，若成功将避免受其影响。

目标只能通过推或拉一个固定的物件或平面（例如一面墙或者天花板）来进行移动，这种移动方式视为等同于攀爬。你可以在自己回合里将目标的悬浮高度向上或向下改变至多20尺：如果你自身就是该法术的目标，则你可以进行上升和下降并将其作为你移动的一部分；如果你不是该法术的目标，则你可以使用3AP来移动目标，但目标必须始终处于你的施法距离内。

法术终止时，仍处于空中的目标会以每回合60尺的速度缓缓飘落到地面。

# 物件定位术

*二环 预言*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  自身

**法术成分：**  声音、姿势、材料（一根分叉的树枝）

**持续时间：**  1分钟 / 每施法者等级

**法术抗力：**  无

你点名或描述一个你熟悉的物件。只要该物件与你相距不超过1000尺，你就会感测到该物件的方位。如果该物件正在移动，则你也将知晓其移动的方向。

该法术可定位一个你认识的特定物件，不过你需要曾经在30尺内近距离看到过该物件至少一次；或者它也可定位特定的一类物件（如某种服装、珠宝、家具、工具或武器）中距你最近的个体。

如果有任意厚度的铅，即使只是薄薄一片铅片阻挡了你与被定位物件间的通路，则该物件也无法被该法术所定位。

**施法时间：** 3 AP

**施法距离：**  触及

**法术成分：**  声音、姿势、材料（施法会消耗价值25GP的金粉）

你触碰一个关着的门、窗、容器或出入口，并使目标在法术持续时间内被魔法上锁。秘法锁无法被任何非魔法方式解锁。施展法术时，你可以指定若干其他生物；你和这些受你允许的生物能够无视秘法锁开启或关闭该物件。你还可以设置一条密语，在该物件 5 尺内念出密语时，秘法锁将被解锁（持续 1 分钟）。

# 空气泡泡

*二环 咒法*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  60尺

**法术成分：**  姿势

**持续时间：**  1轮 / 每施法者等级

**法术抗力：**  无

你指定施法距离内一个你能看见的自愿生物，并在其头部创造一个散发幽光的球体。这个球体隔绝了周围的空气，其内始终充满可供呼吸的新鲜空气，直到法术结束。因此目标可以自由呼吸，且不会受到外界气体（例如毒气、酸雾、以及其他有害气体）的影响。如果这个生物有多个头，那么球体只会出现在它的一个头周围（若该生物的所有头颅共用同一套呼吸系统，那么这个法术也可以让它避免窒息）。

# 超次声波

*二环 塑能*

**职业：** 法师/术士

**施法时间：** 5 AP

**法术区域：** 自身 | 20尺锥形 | 爆发

**法术成分：**  声音、姿势、材料（一片云母）

**持续时间：**  立即
你的手上发出闪电。在本回合结束前，你可以花费 2 AP 对一个触及范围内的生物进行一次近战法术接触攻击，随后法术结束。
**法术抗力：**  可

一阵常人无法听见的超次声波从你的嘴中发出。法术区域内除你以外的每个生物必须进行一次体质豁免，豁免失败者受到 1d10 / 每施法者等级（最高8d10）点雷鸣伤害，并被尽可能推离至距你 20 尺外的位置；豁免成功则伤害减半且不会被推离。

如果法术的范围内有一个未被任何生物着装或携带的非魔法物件，则它也要受到该伤害并且被推离。

# 镜影术

*二环 幻术*

**职业：** 法师/术士

**施法时间：** 整轮动作

**施法距离：**  自身

**法术成分：**  声音、姿势

**持续时间：**  1分钟

**法术抗力：**  无

你的身旁出现数个幻象分身，使敌人很难确定到底该攻击哪个目标。这些分身会一直待在你周围，被击中时即消失。

分身数量为 1 + 1 / 每4施法者等级，它们会围绕在你身边。你可以进入或穿过这些镜像。当你和你的分身分离时，观察者无法以视觉或听觉来判断到底哪个是你的真身。分身与分身之间也可以彼此互相穿越。所有的分身都会模拟你的行为，比如你施法时分身也会做出施法动作，你喝药水时分身也会喝药水，你飘在空中分身也会飘起来等等。

敌人若要攻击你或对你施法，必须在本体和数个分身中选择一个作为目标。每一个存活的分身都可以投掷一次 1d6；若结果为 3 或更高，则由该分身代替你承受攻击。任何成功的攻击都会摧毁分身。分身的AC为10+你的体型调整值+你的敏捷调整值。被区域型法术攻击时，分身也会做出应有的反应（如被*火球术（fireball）* 击中时，看起来也会被烧伤或烧死），但这不会摧毁分身。

敌人必须要看到镜影才会被迷惑。如果你隐形或攻击者闭上眼睛，或者目标有盲视或真视，法术就没有效果。

# 魔绳术

*二环 变化*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  触及

**法术成分：**  声音、姿势、材料（一段绳子）

**持续时间：**  1小时

**法术抗力：**  无

你触碰一段绳子。绳的一端会向上升起，直到整条绳索都垂直于地面挂在空中，或绳子的上端触及天花板。绳子向上的末端存在一个隐形的 3尺×5尺 大小的传送门，其通往一个在法术持续时间内一直存在的以太空间。沿着绳子向上攀爬即可进入此空间，绳子也可被拽入空间中或从空间中丢出。

空间可容纳至多每施法者等级 1 个不超过大型体型的生物。常规的攻击、法术和其他效应无法跨越位面进出，但能够跨越位面的攻击与敌人仍能来到这个空间。空间内的生物可以通过入口看到外面的景象。法术终止时，该空间的一切东西都会掉回物质位面。

# 涅斯图魔法灵光

*二环 幻术*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：** 触及

**法术成分：** 声音、姿势、材料（一小片方形丝绸）

**持续时间：** 24 小时

**法术抗力：** 可

你触碰一名自愿生物或者一个未被着装或携带的物件以在其上设置一道幻术。生物获得下述伪装效应，物件则获得下述虚假灵光效应。效应持续至法术结束。如果你持续 30 日每日均对同一个目标施展此法术，则幻术的持续时间变为直至被解除。

**伪装（生物）。**

选择一种与该生物实际类型不同的生物类型。法术和其他魔法效应会将目标生物视为属于该生物类型来处理效果。

**虚假灵光（物件）。**

你改变目标在能够侦测魔法灵光的法术和魔法效应（例如侦测魔法）中呈现的样子。你可以使一个非魔法物件如同具有魔法性、让一个魔法物件如同只是非魔法的，或者改变物件的魔法灵光学派，使其呈现出由你选择的特定魔法学派的灵光。
