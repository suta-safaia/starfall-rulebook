# 假寐术

*三环 惑控*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  30尺

**法术成分：**  姿势、材料（一撮沙子）

**持续时间：**  10分钟

**法术抗力：**  无

你做一个使人平静的手势，在施法距离内选择 1 + 1 / 每4施法者等级 名自愿生物，使其在法术持续时间内陷入昏迷状态。如果目标受到伤害，或者某人使用动作将其摇醒，该目标身上的法术提前结束。如果目标在整个持续期间都保持昏迷状态，目标会得到一次短休的好处，但在完成一次长休之前不能再受到这个法术的影响。



# 催眠图纹

*三环 幻术*

**职业：** 法师/术士

**施法时间：** 3 AP

**法术区域：** 120尺 | 60尺球体 | 爆发

**法术成分：**  姿势、材料（一撮五彩纸屑）

**持续时间：**  专注、1轮 / 每施法者等级

**法术抗力：**  可

你创造出一团在空中舞动旋转的彩色图纹，充满法术区域。每个处于该区域内的生物在其回合开始时必须进行一次魅力豁免，豁免失败者将被图纹吸引。

被吸引的生物必须使用一次移动动作，以最短且安全的路径向图纹移动（若图纹位于空中而该生物无法飞行，则移动到图纹正下方）。若该生物没有移动速度或无法、无需移动，它同样使用一次移动动作，并驻足观看图纹。此后该生物在本回合内可以正常行动。

# 死者交谈

*三环 死灵*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  10尺

**法术成分：**  声音、姿势、材料（燃烧的香）

**持续时间：**  10分钟

**法术抗力：**  无

你对施法距离内一具你所选择的尸体施以复生的表象，让其可回答你的问题。这具尸体必须还有一张嘴，且如果该生物死亡时是亡灵生物，则施法失败。若目标尸体在最近十日内曾被作为该法术的目标，则本次施法失败。

在法术终止前，你可以向尸体提出最多五个问题。尸体的知识和它讲述的语言仅限于其生前所知。回答通常是简短、含糊或重复的语句，而且如果你对尸体抱有敌意或者尸体认为你是其敌人，它也不是一定要给你正确的答复。该法术并不能让该生物的灵魂返回其身体中，只是活化了其精神。因此，该尸体不能认知新的信息，不能理解它死后发生的任何事情，也不能对未来的事件作出猜测。



# 气化形体

*三环 变化*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  触及

**法术成分：**  声音、姿势、材料（一块纱布）

**持续时间：**  1轮 / 每施法者等级

**法术抗力：**  无

在法术持续时间内，你将触碰到的一名自愿生物连同其穿着携带物一起转化为一团云雾。如果目标的生命值降至0或其用一个魔法动作终止其身上的法术效应，则该目标身上的法术终止。

在该形态下，目标唯一的移动方式即是10尺的飞行速度，且可以悬浮。该目标可以进入并占据一个已有生物占据的空间。其对钝击、穿刺和挥砍伤害拥有 10 点伤害减免，并对倒地状态免疫。该目标可以穿过狭隙，但会将液态物质视为固体表面。

云雾形态的目标不能讲话或操作物件，其随身携带或持握的物件不会掉落，也不能被使用或与之互动。另外，目标也不能攻击或施法。

目标若要在云雾形态下维持专注，需要在回合结束时进行专注检定。

一名受影响的目标必须额外花费 2 AP 才能穿过液体表面进入其内部，反之亦然。然而若目标将因坠落而进入液体中，则其会直接穿过液体表面，如常进入其内部。

**施法时间：** 3 AP

**施法距离：**  10尺 / 每施法者等级

**法术成分：**  声音、姿势、材料（一滴水）

**持续时间：**  专注、10分钟

**法术抗力：**  无

任何穿过墙体所在空间的远程武器攻击在攻击检定中具有-4减值，而穿过墙体到达其目标的火焰效果所造成的火焰伤害将减半。造成寒冷伤害的法术会冻结其穿过或影响的墙段。每段被冻结的水墙具有 AC 5 和 15 点生命值；其生命值降至 0 时，该墙段被摧毁，剩余水墙不会填补缺口。

# 火球术

**职业：** 法师/术士

**法术区域：** 120尺 | 10尺球体 / 每施法者等级（最高100尺） | 爆发

该区域内所有未被着装或携带的可燃物件会开始燃烧。



# 短讯术

*三环 预言*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  无限

**法术成分：**  声音、姿势、材料（一段铜线）

**持续时间：**  立即

**法术抗力：**  无

你向你所遇到过的或某人遇到过且向你描述的一个生物发送一小段二十五个词以内的信息。该生物将在心中听到你的信息，它可以认出你是发讯人（如果他认识你），还可以用同样的方式立即回复一条讯息。法术会让目标能够理解你短讯的信息。

你的传讯可以跨越任意长的距离，甚至能跨越位面。但如果目标和你不在同一个存在位面，则短讯术有5%的概率无法到达。如果讯息没能传达，你将得知这一结果。

在收到你的信息后，一个生物能够屏蔽你以这个法术再次向其发信的能力，持续8小时。如果你在这段时间内试图送出另一条信息，你会得知你的短讯被屏蔽，并且法术失败。

# 缓慢术

*三环 变化*

**职业：** 法师/术士

**施法时间：** 3 AP

**法术区域：** 120尺 | 20尺球体 | 爆发

**法术成分：**  声音、姿势、材料（一滴糖浆）

**持续时间：**  专注、1轮 / 每施法者等级

**法术抗力：**  可

你在法术区域内指定至多 1个 / 每5施法者等级 生物，并扭曲其周围的时间流。每个目标都要进行一次感知豁免，豁免失败则受到该法术影响直至法术终止。

受术生物在其每个回合结束时可以再进行一次该感知豁免，豁免成功则终止其身上的该法术效应。



# 臭云术

**施法时间：** 3 AP

**法术区域：** 90尺 | 20尺球体 | 爆发

**持续时间：**  1轮 / 每施法者等级

**法术抗力：**  不可

只要生物还在这团云雾中，那么反胃状态会一直持续，离开云雾后还会持续1d3轮，但可以使用魔法伎俩、操水、次级复原术等方式提前结束该效果。

任何通过体质豁免、但在回合结束时仍留在云雾中的生物，仍需要进行一次体质豁免。

# 闪现术

*三环 变化*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  自身

**法术成分：**  声音、姿势

**持续时间：**  1轮 / 每施法者等级 （可消解）

**法术抗力：**  无

你在主物质位面和以太位面之间来回“闪烁”。看起来你就像在非常快而乱的闪入闪出真实世界。

在闪现术的持续时间内，你获得以下效果。

- 当你受到攻击或法术影响时，你有 50% 的概率不受该次攻击或法术的影响，除非该攻击或法术能影响以太位面。
- 你的移动速度减半，但你能穿过固体物件；每移动 5 尺都有 50% 的概率化作实体被挤出，被挤出时每移动 5 尺受到 1d6 力场伤害。
- 当你坠落受到伤害时，你有50%的概率不受到坠落伤害的影响。
- 你的攻击检定获得 +2 加值，除非目标拥有以太视觉或真实视觉。但你的攻击和法术也有 20% 的失手率。
