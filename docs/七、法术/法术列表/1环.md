# 奥能冲击

**职业：** 法师/术士

**施法时间：** 4 AP

**施法距离：** 30尺

**法术成分：** 声音、姿势、材料（一小截银线）

**持续时间：** 立即

**法术抗力：** 可

你汇集出一股纯粹的奥术能量轰击施法距离内的一名你看得见的敌人，并对其进行一次远程接触攻击。命中则目标受到 1d10 / 每施法者等级（最高5d10）点力场伤害。

# 警报术

*一环 防护（仪式）*

**职业：** 法师/术士

**施法时间：** 1分钟

**法术区域：** 30尺 | 10尺球体 | 爆发

**法术成分：** 姿势、声音、材料（一根细银线）

**持续时间：** 8小时

**法术抗力：** 无

你设置一个警报以对付不速之客。你可以指定 30 尺内的一扇门或一扇窗，或以法术区域守护一片空间。直到法术结束之前，每当体型为微型或更大的生物触碰或进入被守护的区域或物件，警报都会警告你。当你施放此法术时，你可以决定哪些生物不会触发警报。你也决定该警报是精神警报还是声音警报。

若你距离守护区域1里内，精神警报会通过在你的意识中发出的尖锐声响来警告你。若你正在沉睡，这个声响将会把你叫醒。

声音警报会在60尺范围内制造出摇铃的声响，持续10秒钟。

# 扩大重力

*一环 变化*

**职业：** 法师/术士

**施法时间：** 整轮动作·持续施法

**法术区域：** 自身 | 10尺球体 / 每施法者等级 | 爆发

**法术成分：** 声音、姿势、材料（一根小铁棍）

**持续时间：** 1分钟

**法术抗力：** 不可

区域内的重力暂时性地增加。在区域内开始其回合的生物必须进行一次力量豁免，豁免失败则区域对其而言是困难地形。一旦你移动，法术提前终止。

此外，区域内还有以下影响：

- 坠落伤害额外增加 1d10 / 每施法者等级
- 对飞行生物而言如同强风天气
- 任何想要移动或捡起区域内未被着装或携带的物品的生物，都必须进行一次对抗你法术豁免 DC 的力量检定

# 易容术

*一环 幻术*

**职业：** 法师/术士

**施法时间：** 3 AP

**施法距离：**  自身

**法术成分：**  声音、姿势

**持续时间：** 1 小时 / 每施法者等级

**法术抗力：**  无

你改变自身的外貌，以及穿戴在身上的衣物、护甲、武器等所有物。肉眼看来，你的身高可以有 1 尺的增减，体态可胖可瘦。你必须选择一个与你肢体基础排列方式一致的形态。幻术的影响范围由你决定。

# 典礼术

*一环 防护*

**职业：** 神官

**施法时间：** 10分钟

**施法距离：**  触及

**法术成分：**  声音、姿势、材料（一瓶圣水作为耗材）

**持续时间：**  立即

**法术抗力：**  无

你进行几种宗教典礼之一。当你施展此法术时，选择下述典礼之一，其目标必须在施法过程中处于你周围10尺内。

- **赎罪：**  你触碰一个阵营发生了改变的自愿生物，并进行一次 DC 20 的感知（洞悉）检定。成功则你令目标恢复其原始阵营。
- **成人礼：**  你触碰一个年龄足够成年的类人生物。在接下来的 24 小时内，当目标进行一次属性检定时，它可以投 1d4 并将结果加到该检定上。一个生物只能从此仪式中获得此好处一次。
