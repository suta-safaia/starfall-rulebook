# 矮人

矮人身高约122至152厘米（4至5尺），身形壮实，肩宽背厚，如同矮墩墩的岩石。他们天生对火焰与毒素有着出众的抵抗力——这源于他们世代在熔炉旁与矿洞深处锻造出的坚韧体质。矮人几乎个个都流淌着工匠的血液，绝大多数人终其一生既是矿工也是工匠，从采掘矿石到锻造精钢，一气呵成。他们性格直爽，从不藏着掖着——高兴就大笑，不满就大骂，在精灵看来这简直是鲁莽粗野，但矮人从不在背后耍小心眼。正因如此，矮人是那种**会跟你吵得面红耳赤、但事后照样为你两肋插刀的朋友**。尽管与他们交朋友往往麻烦不断，可一旦你赢得了他们的信任，这份友谊就会像山岳一样可靠。

如果你想要塑造一个火爆直率、手艺精湛的冒险者，一个嘴上不饶人但关键时刻绝不会抛弃伙伴的角色，你应该选择矮人。

**你也许……**

- 见到一件锻造粗糙的武器，会忍不住当场批评：“这也能叫剑？我家打铁用的钳子都比这锋利！”
- 被精灵嫌弃“太莽撞”时，哈哈大笑：“总比你们说句话都要绕三个弯强！”
- 为了保护同伴，可以毫不犹豫地冲进火海或毒雾——反正这些东西对你要打不少折扣。
- 嘴上和朋友吵得不可开交，但转身就把自己新打造的护甲塞给对方，嘟囔一句：“拿着，看你那身破烂我都替你丢人。”

**其他人可能……**

- 觉得你嗓门太大、脾气太急，时常惹出麻烦——但又不得不佩服你从不在背后算计人，所有不满都当面说清。
- 惊讶于你对矿石和锻造的热情：你能一眼看出铁矿石的产地，也能连续打铁三天三夜不喊累。
- 意识到你是那种“麻烦但可靠”的伙伴：和你吵架很累，但把后背交给你时，从不用担心被捅刀子。

**体貌描述**

矮人身高122至152厘米，比人类矮上一大截，却几乎宽出一半。他们的骨架粗壮，肌肉结实，无论男女都显得敦实有力。矮人的脸宽阔，颧骨高耸，鼻子大而醒目，毛发浓密——男性尤其以蓄长须为荣，胡须常编成复杂的样式，既是装饰也是氏族的标志。他们的皮肤偏粗粝，常年被炉火烘烤得泛着红褐。矮人通常在25岁左右成年，寿命可达350岁上下，但许多人会一直劳作到生命的最后一天。

**社会**

矮人大多生活在群山之中的要塞或矿坑城镇里，以氏族为单位聚居。他们的社会高度崇尚工艺：一个矮人的地位往往取决于他作为矿工或工匠的本事，而非出身。矮人热爱烈酒、锻造和热闹的争执，他们的节日常伴随着锻锤的节奏与豪迈的歌声。矮人与精灵的关系历来不睦——前者嫌后者矫情，后者嫌前者粗俗——但与人类、可可洛等种族却经常建立起稳固的贸易与盟友关系。矮人极少背叛承诺，也极其看重荣誉，如果你得罪了一个矮人，他会与你正面较量；如果你帮助了一个矮人，他会用一生来回报。与此同时，矮人极其痛恶那些**离经叛道之人**——无论是背叛氏族、亵渎传统，还是抛弃工匠之道。每个矮人氏族都有一本代代相传的**仇恨之书**，上面以铁与血的字迹记录着所有需要被铭记的背叛、耻辱与罪行。仇恨之书从不轻易翻开，但也从不被遗忘；一旦某个名字被写进书中，那个人的所作所为便会成为整个氏族的公敌标记，甚至数代之后仍会被提起。矮人不会用阴谋诡计去报复，但他们会光明正大地把这份仇恨传承下去，直到对方做出偿还。



### 矮人特性

- 体型：中型。
- 速度：步行15尺，特殊的，矮人不会因为铠甲降低移动速度。
- 天生语言：通用语、矮人语与额外一门自选语言

**山岳矮人**

世代居住在雪线之上的高地要塞，陡峭的山路与稀薄的空气把他们的肺活量与肌力锤炼到了极限。他们是矮人中最高大的一支，肩膀宽得几乎进不了自家矮小的门扉。山岳矮人习惯背负着整袋矿石上下悬崖，视平原人的“长途跋涉”为饭后散步。

- 岩壁行者（1点数）：你获得15尺攀爬速度，且你的负重翻倍。
- 山岳体魄（2点数）：你获得奖励专长：强健体魄。

**雪地矮人**

胡须上永远结着白霜的北方支系，常年生活在极夜与暴风雪笼罩的冰原，在冰海上凿洞而居、在风雪中狩猎巨兽。他们的血液仿佛掺了防冻的烈酒，越是酷寒越是精神，反而在温暖的地方会昏昏欲睡。雪地矮人的要塞一半凿在冰川里，他们说冰比石头诚实——会裂就是会裂，从不假装坚固。

- 雪原行者（1点数）：积雪与冰面不视为困难地形，你不会在冰面上失去平衡。
- 暴雪之躯（2点数）：你获得5点寒冷抗性，且免疫严寒环境带来的负面影响。
