# 龙人

龙人是古老而稀有的种族，他们身上流淌着源自太古巨龙的血脉。龙人成年的时间与寿命差异极大，完全取决于血脉的纯度与基因的优劣，寿命短则五百年，长则可逾万年，传言还有更长寿命的龙人。男性龙人身材魁梧壮硕，体格结实如山；女性龙人则小巧可人，体态纤细玲珑，与男性形成鲜明对比。无论男女，身上都覆盖着不同程度的龙鳞——这些鳞片的颜色、纹理与光泽，如实映照着他们体内**龙魄**的本源力量与属性。龙人天性孤高，大多选择与世隔绝地生活，隐匿于深山、遗迹或龙脉交汇之地。他们对其他种族的态度因血脉而异，但无一例外都带着一种**居高临下的视角**：例如有些龙人认为与其他种族交流纯属浪费时间，不屑一顾，而又有一部分龙人抱着怜悯之心，将短命种视为需要关照的“可怜小东西”。无论哪种，龙人骨子里都从未将其他种族视作对等的存在。

如果你想要塑造一个身负远古血脉、孤高但不傲慢的探索者，一个对世俗纷争兴致缺缺、却对一件古物或一卷残籍痴迷千年的角色，你应该选择龙人。

**你也许……**

- 骄傲自大——你并不是真正的巨龙，但你血液里仍然流着龙的血脉！
- 愿意花一百年去破译一块上古石碑上的铭文，却懒得花一分钟去参加王国的宴会。
- 囤积某种东西——可能是黄金、一种喜爱的小饰品，或者是朋友。

**其他人可能……**

- 一开始觉得你冷若冰霜、拒人千里，但慢慢会发现，你其实只是不太擅长社交。
- 惊讶于你对“垃圾”的定义：一块锈迹斑斑的破铜烂铁，在你眼中可能是千年前某位名匠的绝笔，价值连城。
- 发现你对同族或真正志同道合者会展现出令人意外的温和，甚至愿意主动分享你珍藏的知识。

**体貌描述**

龙人的外貌因血脉与个体差异极大。男性龙人通常身高180至210厘米，肩宽背厚，四肢粗壮，即便穿上宽松的衣袍也遮掩不住那压迫性的体格。女性龙人则多在130至150厘米之间，体态轻盈，曲线柔美，与男性的粗犷形成奇妙的对照。两者的共同点是体表覆盖着龙鳞——鳞片并非全身密布，而是呈斑块状分布于前额、颧骨、肩臂、后背及小腿外侧，鳞片大小、形状与色彩因龙魄属性而异：赤红如焰、苍青如冰、琥珀如电、墨黑如渊……鳞片会随着力量涌动而微微发亮。龙人的瞳孔是竖直的，虹膜色彩往往与鳞片呼应。他们的寿命从五百年到上万年不等，但外表衰老极其缓慢——一个三千岁的龙人看起来可能只相当于人类的中年。

**社会**

尽管龙人的生活方式因他们的血脉不同而存在显著差异，但它们通常具有一些共同的社会特征。龙人倾向于与其他族裔友好相处（指在互不打扰的意味上），而在同类之间，龙人们的居住地点都相隔较远，这可能是来源于他们天生的领地意识，他们往往只与恋人共享巢穴，即便是自己的孩子，在孩子能独立生活后也往往会赶出自己的巢穴。



### 龙人特性

- 体型：中型。
- 速度：步行20尺
- 天生语言：通用语、龙语与额外一门自选语言



### 龙人血统

- 天生护甲（1点数）：你身体上的鳞片给你带来了一定的防护，你的天生护甲获得+2加值。
- 特殊加护（2点数）：星之加护 / 龙气之翼：你可以控制你体内龙气，使其聚集成一对虚幻的翅膀，持续时间1分钟。在持续时间内，你获得60尺飞行速度（一般）。使用此特性后，你在完成一次短休前不能再次使用。

**霸龙血脉**

继承了巨龙的力量与压迫感的血脉，鳞色浓烈如火如渊。他们崇尚力量本身，解决问题的方式通常只有一种——正面碾过去。霸龙血脉的龙人喜欢占据高处俯瞰领地，对弱者的耐心极其有限，但对认可的对手会献上近乎顽固的尊重。他们的巢穴堆满战利品，而每一件背后，都是一场堂堂正正的胜利。

- 霸龙血统（1点数）：你的力量+2，敏捷-2。
- 吐息武器（2点数）：你可以使用动作呼出破坏性的能量。你的血脉决定了吐息。（复用充能机制多次使用）

**灵龙血脉**

继承了巨龙的魔力与灵性的血脉，鳞色清冷，瞳中仿佛藏着星光。他们痴迷于古物与知识，一件残破的遗物足以让他们驻足百年。灵龙血脉的龙人是天生的学者与收藏家，巢穴里堆满古籍、星图与谜之造物。他们极少动怒，但如果你敢弄坏他们的藏品——你会见识到龙类的愤怒究竟可以有多长寿。

- 灵龙血统（1点数）：你的魅力+2，敏捷-2。
- 龙之威仪（1点数）：你免疫龙之威仪效果，你的恐吓熟练等级从普通提升至受训。
- 真实视觉（2点数）：你拥有龙一般敏锐的感知力，你获得10尺真实视觉。
