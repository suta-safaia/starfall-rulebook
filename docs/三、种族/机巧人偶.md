# 机巧人偶

机巧人偶是前文明遗留下来的谜之造物。从外表看，他们与各式各样的类人生物几乎没有区别——有五官、有体型、有服饰，甚至能像常人一样进食与睡眠。然而，除非他们主动展露，否则你很难发现端倪：例如一只手变形成刀刃，或者在深水中安然行走，又或者连续数日不眠却毫无倦意。没有人知道机巧人偶是如何被创造出来的，唯一确定的是，他们体内那颗核心中寄宿着**真正的灵魂**——与任何生灵一样会喜悦、会悲伤、会爱上某个人。可这灵魂不知为何无法回归天国净化，为了不被世间污秽所侵蚀，机巧人偶被设下了一道残酷的枷锁：**每二十年，绝大部分记忆便会清空，** 除了基础沟通能力与基本常识之外，所有经历、所有情感、所有刻骨铭心的羁绊，都会在二十岁“生日”那天化为乌有。大部分机巧人偶被封存在地下迷宫的深处沉睡，只有少数仍在世间游荡。而那些记忆清除程序发生故障的机巧人偶，亦或者是不愿意消除所有记忆想留下哪怕一丁点记忆的机器人，则逐渐被污秽侵蚀心智，沦为癫狂的危险存在。

如果你想要塑造一个背负着“注定遗忘”之宿命的角色，一个在短暂二十年的清醒时光里拼命寻找存在意义、却又知道一切终将归零的悲剧旅者，你应该选择机巧人偶。

**你也许……**

- 某刻突然回想起不属于你但是属于之前的你的记忆
- 拥有初始化时或者上一个自己留下的任务，例如守护某个家族之类
- 时间的短暂让你觉得做什么事都 ***拼尽全力/没有意义***

**其他人可能……**

- 认为你十分可悲，试图和你成为朋友或者是寻找不清除记忆的方法
- 认为你十分危险，不知何时你就会成为癫狂的不能沟通的危险分子
- 变形金刚很酷

**体貌描述**

机巧人偶没有统一的体貌特征。他们可以模仿任何种族的外形——人类、精灵、可可洛、史莱姆、甚至是哥布林——只要制造者当年选择了那种外观。他们的“皮肤”大多是柔软的仿真材料，只有在破损时才会露出内部的关节或空腔，也有一些人偶并非是类人生物的模样。他们的真实年龄无从得知，而外表永远定格在被激活那一刻的模样。机巧人偶的“核心”通常位于胸腔中央，是一颗散发着微光的多面体结晶，那是灵魂的居所——也是唯一无法更换的部件。一旦核心破碎，机巧人偶便真正死去。

**社会**

机巧人偶没有属于自己的社会。他们是前文明的遗孤，散落在世界各地，极少聚集。大部分同类沉睡在地下迷宫的某处类似棺材的家具中，等待一个永远不会来的唤醒者。少数清醒的机巧人偶会尝试融入其他种族的社会，伪装成普通人生活，知道记忆消失都无人知道你真正的身份。机巧人偶之间的相遇极其罕见，而即便相遇，也往往因为各自的记忆周期不同而难以建立持久的联系。至于那些因程序故障而癫狂的机巧人偶，他们失去了理智与约束，成为了冒险者需要讨伐的危险存在。



### 机巧人偶特性

- 体型：中型。
- 速度：步行20尺
- 天生语言：通用语与额外一门自选语言
- 古语回路：你习得法术阅读魔法（无论你是否会施法），且在解读加密咒语和检定物品的检定中获得+4加值。

### 机巧人偶血统

- 机器学习（1点数）：你的一项属性获得+1提升。
- 不死本质（1点数）：你的能量来自于一块独特的能源核心。因此你无需进食，睡眠，呼吸就能维持生命。但你仍然需要长休进行维护并充能。
- 特殊加护（2点数）：星之加护 / 电涌核心：当你受到闪电伤害时，你将其转化为治疗。

**战斗机体**

以前文明的战争为目的制造的机体，肢体中封存着武器机构，骨骼里刻着战斗程式。他们苏醒时往往还保持着戒备的姿态，许多机体至今仍在执行早已无人记得的命令——巡逻一座化为废墟的要塞，或守护一位早已化为尘土的主人。战斗机体大多沉默而警觉，和平年代的喧闹，反而会让他们无所适从。

- 硬化机体（1点数）：你的机体按战时规格做过强化处理，外壳与关节都远非民用造物可比。你的天生护甲获得+2加值。
- 天生武器（1点数）：你的肢体可以被改造成武器，你获得一套天生武器，该武器可以是隐藏的，你可以使用一个整轮动作变形来展开/收起武器。

  - 近战武器：1d8挥砍/钝击/穿刺武器。
  - 远程武器：1d10闪电/火焰/冷冻/雷鸣，60尺。

**侍从机体**

以辅佐、记录与侍奉为目的制造的机体，体内寄宿着精密的演算回路。他们往往对前文明的生活方式留有零星的记忆碎片——一首摇篮曲的调子、一套茶具的摆法、某个人回眸时的微笑。侍从机体举止得体、心思细腻，许多人流落至贵胄之家充当管家或书吏，在侍奉他人的过程中，重新拼凑自己存在的意义。

- 子程序（2点数）：你的回路深处封存着前文明录入的专业知识。你可以随时唤醒其中一道：任选一项工具或技能，其受训等级临时变为专家。子程序一经唤醒便持续运转，直到你在短休的静默维护中将它关闭，此后方可再次唤醒。
