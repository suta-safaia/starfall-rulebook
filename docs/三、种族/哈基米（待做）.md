# 灵猫

灵猫是大陆上最轻盈的种族。他们身形纤细、动作无声，耳尖与长尾泄露了血脉里的猫性。灵猫的寿命与人类相仿，约六十年至九十年，但他们的白天似乎总比谁都慢——打盹、晒太阳、追一只蝴蝶都能耗掉一下午。可一旦夜幕降临，或是有什么东西勾起了好奇心，灵猫便会展露出截然不同的一面：黑夜是他们的领地，好奇心是他们的罗盘。灵猫没有宏大的抱负，却拥有最令人羡慕的天赋：**落爪无痕，起身无惊**。

如果你想要塑造一个来无影去无踪的探险者，一个白天慵懒入夜后精神抖擞的夜行者，一个被好奇心牵着鼻子走却总能全身而退的角色，你应该选择灵猫。

**你也许……**

- 在屋顶和围墙之间穿梭抄近路，从不理解为什么有人要走大路。
- 对会动的小东西毫无抵抗力——飘落的树叶、滚动的线团，还有敌人晃动的刀尖。
- 明明只是路过，却顺手摸走了摊上的小鱼干，还觉得自己付过钱了（用微笑付的）。

**其他人可能……**

- 觉得你懒洋洋的毫无干劲，直到夜里守营时发现你睁着眼睛。
- 惊讶于你总能出现在不该出现的地方，而且没有人看见你是怎么进去的。

**体貌描述**

灵猫身形轻盈纤细，身高150至180厘米，体重远比看上去要轻。他们的耳朵尖耸微颤，瞳孔会在光线变化时收成竖线，身后拖着一条用于保持平衡的长尾。发色与瞳色多样，部分灵猫的发间或面颊上生有淡淡的斑纹。灵猫的脚步几乎不发出声音，从高处跃下也总能稳稳落地。他们十五岁左右成年，寿命约八十岁。

**社会**

灵猫没有自己的国度，散居在港口、市集与千家万户的屋顶之上。他们多以信使、侦察者、舞者与窃贼为生——最后一项多半是名声所累，但灵猫从不辩解。灵猫的聚落没有围墙，唯一的标志是屋顶上挂着的一串风铃：有风经过时，整条巷子都知道自己人在家。他们的领地意识很弱，好奇心却重得惊人，用人类的话说："每个灵猫都欠着一屁股好奇心债，而且从不打算还。"



### 灵猫特性

- 体型：中型。
- 速度：步行25尺
- 天生语言：通用语与额外一门自选语言



### 灵猫血统

- 昏暗视觉（1点数）：你获得30尺黑暗视觉能力。
- 猫之轻足（1点数）：你坠落时受到的伤害减半，且不会因坠落而倒地；你在保持平衡的检定上获得+2加值。
- 无声步（1点数）：你在隐匿检定上获得+2加值。
- 特殊加护（2点数）：星之加护 / 九命：猫有九条命——至少传说是这样。当你的生命值将要降至0时，你可以改为保留1点生命值。此加护在你完成一次长休后可再次使用。

**山猫血脉**

栖居于山林雪地的支系，体型较家猫更为壮硕，耳尖生有标志性的簇毛。山猫血脉的灵猫是沉默的猎手：能在雪地上一动不动潜伏半日，只为等猎物踏进跃击的范围。他们离群索居，领地观念比其他灵猫强得多——那片山林是他们的，只是他们懒得立牌子而已。

- 山猫血统（1点数）：你的力量+2，敏捷-2。
- 攀爬利爪（1点数）：你获得20尺攀爬速度。
- 猫之轻灵（1点数）：当你本回合没有移动过，你可以免费使用一次五尺快步，随后本回合的移动速度降为0。

**家猫血脉**

与人类共居了不知多少代的支系，昼伏夜出的习性被驯化得温和了许多，警觉却刻进了骨子里。家猫血脉的灵猫是城市里最灵通的消息贩子：哪家的屋顶能晒太阳，哪家的厨房半夜不锁门，哪位贵族在偷偷养金丝雀——他们全知道。别问消息哪来的，问就是"路过"。

- 家猫血统（1点数）：你的魅力+2，力量-2。
- 警戒反射（1点数）：你的察觉检定获得+2加值，且你在对抗恐慌的豁免上获得+2加值。
- 顺爪（1点数）：你在巧手检定上获得+2加值。
