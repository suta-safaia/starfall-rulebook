# 凯莫

凯莫是大陆上最招人疼的种族。他们看上去与常人无异，唯有头顶那对令人喜爱的兽耳，和身后那条毛茸茸的尾巴，泄露了血脉中的动物本性。凯莫天性直率，喜怒从来不绕弯子：喜欢就凑上来，讨厌就呲牙，开心了尾巴会自己摇起来——不是他们不矜持，是身体比嘴诚实。这类刻在骨子里的本能怎么教育都压不住，至于是哪一套本能，则要看他们体内流着哪种动物的血。凯莫的寿命与人类相仿，约六十年至九十年，但岁月似乎格外优待他们——无论长到多少岁，那双耳朵和那双眼睛都还是亮晶晶的。

如果你想要塑造一个被身体里的动物本能牵着走的乐天派，一个喜怒全写在耳朵和尾巴上的直率伙伴，一个走到哪里就把欢乐带到哪里的角色，你应该选择凯莫。

**你也许……**

- 耳朵比嘴先回答问题——紧张时耳朵贴平，开心时尾巴自己摇起来，心里那点事全写在头顶上。
- 夸人脱口而出，骂人也脱口而出——等你想起该闭嘴的时候，大家已经都听见了。
- 能从口袋里摸出不知什么时候藏进去的零食，并真诚地认为是它们自己长出来的。

**其他人可能……**

- 觉得"摸摸头"是打招呼的正常流程，直到被你一口咬在胳膊上。
- 从不用猜你在想什么——你的耳朵、尾巴和表情已经联合开过三次发布会了。
- 争论你到底算人还是算兽，而你正蹲在椅子上认真啃一根骨头，无意参与讨论。

**体貌描述**

凯莫的体态与人类相仿，藏不住的是血脉的印记：头顶立着一对兽耳，身后拖着一条尾巴，耳朵与尾巴的形态随血脉各异——猫耳纤巧、犬耳挺直、鼠耳圆软、熊耳敦厚。部分凯莫的瞳仁会随光线收缩成竖线，犬齿微微外露，掌心生着软软的肉垫，发间或面颊上带有淡淡的斑纹。凯莫的身高随血脉差异很大，从一百四十厘米到一百九十厘米都有；相同的是，他们都远比看上去结实——或者远比看上去圆。凯莫十五岁左右成年，寿命约八十岁，但多数凯莫一辈子都长着一张显小的脸。

**社会**

凯莫没有自己的国度，散居在其他种族的港口、市集与街巷之间，靠本能吃饭：鼻子灵的做追踪者与品酒师，耳朵灵的做信使与斥候，力气大的做护卫与搬运工。凯莫的聚落没有围墙，唯一的标志是屋檐下挂着的一串风铃：有风经过时，整条巷子都知道自己人在家。与凯莫打交道是件省心的事——他们学不会、也懒得学那些拐弯抹角的社交辞令，喜欢就直说，讨厌就走开，跟他们做交易从不需要猜合同背面写着什么。用人类的话说："凯莫的脸上没有阴谋，只有晚饭想吃鱼。"

> 关于凯莫族的起源，正史讳莫如深，酒馆的醉话里倒是流传着一个完整版本。据说在久远到没有纪年的年代，大陆上存在过一个如今已经失传的施法职业——德鲁伊。他们修习自然之道，能与走兽交谈，能化身飞鸟游鱼。问题出在后来：某位（一说某几位）德鲁伊在变形期间与真正的动物日久生情，诞下了一批半人半兽的孩子——这便是最早的凯莫。诸神对此的反应有记载说是不予置评。但总之德鲁伊这个职业自此消失了，直至今日。如今古老的法术典籍里还留着标注着"德鲁伊"的法术，但已经没有任何人能告诉你该怎么成为一个德鲁伊。而凯莫族被保留了下来。



### 凯莫特性

- 体型：中型。
- 速度：步行20尺
- 天生语言：通用语与额外一门自选语言
- 天生武器：你的指尖生有可伸缩的利爪，视为天生武器，造成1d4穿刺伤害，重击范围19-20/×3。



### 凯莫血统

- 昏暗视觉（1点数）：你获得昏暗视觉能力。
- 野性本能（1点数）：你的察觉与求生熟练等级从普通提升至受训。
- 特殊加护（2点数）：星之加护 / 求生本能：野兽被逼入绝境时最为危险。当你的生命值将要降至0时，你可以改为保留1点生命值。此后1分钟内你的全属性+2；效果结束时，你获得2层力竭。若你的生命值再度降至0，此效果提前结束。此加护在你完成一次长休后可再次使用。

**灵猫血脉**

凯莫中最轻盈的一支，耳尖尾长，昼伏夜出。他们是屋顶与墙头之间的君王，白天打盹晒太阳能晒掉一整个下午，入夜之后整条街巷都是他们的猎场与游乐场。灵猫血脉的凯莫独处时像一阵风，凑成群时像一地打滚的毛团，没收到邀请的话，最好不要试图加入——你追不上。

- 灵猫血统（1点数）：你的敏捷+2，体质-2。
- 猫之轻灵（1点数）：计算坠落伤害时，你的坠落高度视为减少30尺；你的体操与隐匿熟练等级从普通提升至受训。
- 猫之迅捷（1点数）：你的反应和敏捷允许你在短时间内让自己的移动速度翻倍，持续至回合结束（充能8-10）。

**忠犬血脉**

与人类混居最久的一支，耳挺鼻灵，忠诚刻进了骨头里。忠犬血脉的凯莫是天生的护卫、猎手与追踪者，认下一个人就是一辈子的事。他们聚群而居，夜里轮流守营从不懈怠——当然，白天补觉的时候也谁叫不醒。

- 忠犬血统（1点数）：你的感知+2，智力-2。
- 灵敏嗅觉（1点数）：你获得灵敏嗅觉，在依赖气味的察觉检定上获得+4加值，并能循着气味进行追踪。
- 守望本能（1点数）：你的先攻检定获得+2加值，且你在对抗恐慌的豁免上获得+2加值。

**鼠鼠血脉**

城市里最有生存智慧的一支，圆耳朵，精明又节俭。鼠鼠血脉的凯莫是街巷里的万事通：哪家的厨房半夜不锁门，哪条暗渠能绕过城门，哪位贵族在偷偷养金丝雀——他们全知道。别问消息哪来的，问就是"路过"。

- 鼠鼠血统（1点数）：你的智力+2，力量-2，你的体型变为小型。
- 钻营（1点数）：你的巧手与逃脱熟练等级从普通提升至受训。
- 盲感（1点数）：你灵敏的第六感让你能察觉到周围潜在的危险，你获得30尺盲感，当你耳聋时，此能力失效。

**巨熊血脉**

栖于山地与针叶林的一支，块大、毛厚、觉多。巨熊血脉的凯莫看上去是全族最凶的，实际上是全族最困的：他们走路慢吞吞，说话慢悠悠，一天能睡够十个时辰。但如果你动了他们认准的人——你会理解为什么山里的猎人宁愿绕路三里，也不踩进熊的领地。

- 巨熊血统（1点数）：你的体质+2，敏捷-2。
- 厚茸（1点数）：厚实的毛皮与脂肪为你提供保护，你的天生护甲获得+2加值。
- 熊罴之力（1点数）：你的运动熟练等级从普通提升至受训，你的负重能力翻倍。
**耄耋血脉**

凯莫中最凶的一支，以橘色居多，脑袋滚圆。耄耋血脉的凯莫性格阴戾、欺软怕硬、独来独往，无论喂多少顿都喂不熟，惯于用冷冷的眼神盯着人看。最有名的一只耄耋曾闯入人类家中偷吃猫粮，赖着不走，与屋主展开旷世大战——雨伞、水枪、拖把轮番上阵均未能将其驱赶，史称"圆头耄耋事件"。他们的处世哲学是：得挠人处且挠人。

- 耄耋血统（1点数）：你的力量+2，魅力-2，你周围有巨型敌对生物时，每回合开始时，你需要通过一次DC=15的魅力豁免，否则你至少花费2AP靠近该生物。
- 哈气（1点数）：消耗1AP发出威慑性的哈气。每哈气一次，直到你的下个回合结束前，你的天生利爪攻击伤害获得1d4加值。
- 脊背龙形态（2点数）：你炸毛弓背进入脊背龙形态，持续1分钟：期间你的恐吓检定获得+2加值，AC获得+2闪避加值，并解锁老吴撼地掌。
  - 老吴撼地掌：你发动冲锋时可以随时将其打断——你并不需要真正扑到目标面前。目标须进行一次感知豁免（DC=10+你的感知调整值），失败则对你畏缩；豁免成功的目标在24小时内免疫此效果。
- 嚼口香糖回血（1点数）：你可以用整轮动作原地嚼一嚼，恢复5%的最大生命值。此能力在你完成一次短休后可再次使用。
- 得挠人处且挠人（1点数）：当对方对你的近战攻击未命中时，你可以消耗1RP，用利爪对其发动一次借机攻击。
