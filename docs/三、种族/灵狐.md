# 灵狐

灵狐是继承了妖狐血脉的种族，天生拥有迷惑人心的容貌与变幻身形的异能。灵狐族中男性极其稀少，世人所见几乎皆是女子，因此民间素有"狐女"之称。灵狐的寿命可达五百年，最显著的特征是身后的狐尾——尾巴的数量随着年龄与修为增长，初生一尾，而后每百年方有可能再分一尾，三尾便已是一方名物，至于传说中的九尾天狐，只存在于古籍与酒馆的醉话里。

灵狐的血脉在漫长岁月中分化为两支：一支行走红尘，一支避世清修。两支血脉互不相扰，偶尔相逢也只是隔着岁月遥遥一礼。

如果你想要塑造一个以巧言幻术布局天下的魅狐，或是一个遗世独立、执掌妖术仙法的仙狐，你应该选择灵狐。

**你也许……**

- 习惯性地用三个不同的身份在同一座城市里生活，连自己都记不清哪个才是"真正的你"。（魅狐）
- 把每一次撒谎都当作艺术品来打磨，坚信"被拆穿的谎言才是失败的谎言"。（魅狐）
- 在山中一坐便是十年，出关时发现山下已经换了王朝，而你并不在意。（仙狐）
- 每闭关悟道一次，尾巴上的妖纹便深一分。（仙狐）

**其他人可能……**

- 在谈正事前下意识地检查契约条款三遍——与魅狐打交道的基本礼仪。
- 敬畏地在你（仙狐）面前放下一枚供果，然后才想起来你其实不吃这个。
- 好奇你真正的容貌，但永远得不到确切的答案。

**体貌描述**

灵狐的真实形态介于人与狐之间：尖长的狐耳立于发间，身后拖着一条或数条蓬松的狐尾。魅狐瞳色多为琥珀金或绯红，笑时眼角微挑，容貌总会停留在最艳丽张扬的年华；仙狐则多为银发，气质清冷，尾尖与耳尖凝着一层淡淡的辉光，年岁越久越是出尘。灵狐极少以真容示人——借助天生的变化之能，她们可以化作寻常人类女子的模样行走于市，唯有耳朵与尾巴的轮廓会在晨光或烛影里偶尔露出破绽。灵狐二十岁成年，寿命约五百年，每多一尾，瞳色便深一分。

**社会**

灵狐没有自己的国度，散布于其他种族的疆域之间，以家族或小型结社为单位生活。她们极少以真容示人，往往化作寻常人类女子的模样行走于市，因此世人对灵狐的印象大多来自传说而非亲历。灵狐对“缘分”与“因果”有着近乎信仰般的重视——一段未了的牵绊，足以让她们守候百年。两支血脉对彼此的态度颇为微妙：魅狐嫌仙狐“活成了庙里的泥像”，仙狐嫌魅狐“把天生灵性贱卖给了红尘”。

### 灵狐特性

- 体型：中型。
- 速度：步行20尺
- 天生语言：通用语、狐语与额外一门自选语言

### 灵狐血统

**魅狐血统**

继承了妖狐狡诈善变一面的血脉，行走于诸国宫廷与市井之间，以言语为刃、以笑靥为局，是天生的外交家、密探与骗子。各国法典里那些针对灵狐的提防条款，几乎都是为她们而写。魅狐以家族为单位经营商会、艺馆与情报网络，极为重视“故事”——她们的成年礼便是独自出门，带着一个足够精彩的故事回来。

- 魅狐血统（1点数）：你的魅力+2，力量-2。
- 变化身形（1点数）：每日一次，你可以使用一个整轮动作变化为一名与你体型相同的类人生物的样貌，或变回真实形态。该变化为幻术效果。
- 巧言如簧（1点数）：你在欺瞒与交涉检定上获得+2加值。
- 特殊加护（2点数）：星之加护 / 倾国：你每日可各一次施展魅惑人类与定身类人（如同同名法术），施法者等级等于你的职业等级总和，施法主属性为魅力。

**仙狐血统**

继承了妖狐通灵近神一面的血脉，避世隐居，吐纳山川灵气、修习仙术，视红尘纷扰为过眼云烟。民间传说里那些在山中神庙显灵、实现祈愿的“狐仙大人”，大多是她们的手笔。仙狐结庐于深山灵脉，每位仙狐都有自己的洞府与信徒，她们以修为论长幼、以还愿结善缘，偶尔下山也只为了一桩百年未了的因果。

- 仙狐血统（1点数）：你的感知+2，体质-2。
- 狐火（1点数）：无论你是否会施法，你习得戏法舞光术与妖火术，它们视作神术戏法，施法主属性为感知。
- 仙术（2点数）：你每日可免费施展一次疗伤术与次等复原术（如同同名法术），视作神术，施法者等级等于你的职业等级总和，施法主属性为感知。
- 特殊加护（2点数）：星之加护 / 仙狐显圣：每日一次，你短暂显现狐仙真身，持续1分钟：身后狐尾尽数舒展，期间你的神术施法者等级视为+2。
